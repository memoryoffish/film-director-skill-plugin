# Wan 3.0（`wan3.0-video`，快队列 `wan3.0-video-prime`）

一句话：百炼的视频模型，喂法最全，参考视频可以直接给本地文件（白模预演就这么喂）。

官方文档：[万相3.0视频生成 API 参考](https://help.aliyun.com/zh/model-studio/wan3-video-generation-api-reference)，2026-11-22 查；下表「官方」都指这一页。

| 项 | 经这个后端 | 出处和日期 |
|---|---|---|
| 后端、单子里写 | `scripts/bailian.py`；`"model": "wan3.0-video"`，不写 `model` 也是它；快队列写 `"wan3.0-video-prime"` | bailian.py；官方 |
| 喂法 | 文生、首帧、首尾帧、参考图、参考视频（参考视频可以带参考图） | 官方「素材组合」 |
| 不能一起用 | 首帧、尾帧和参考图、参考视频互斥；尾帧要配首帧，只给尾帧不行 | 官方「素材组合」；bailian.py |
| 单条时长 | 后端只收 2–15 秒（`MAX_CLIP_S`，这个后端的上限）。官方：没有视频输入时 2–30 秒，有视频输入时输入 + 输出不超过 30 秒，不写是 5 秒 | bailian.py；官方 |
| 分辨率 | 480P、720P、1080P，不写是 1080P；输出 30 fps；21:9 在 1080P 下实际是 2206×946 | bailian.py；官方；作者实测，2026-11（最后一句） |
| 画幅 | 带媒体时 `ratio` 默认 adaptive（跟输入走），不带时 16:9；官方可选 adaptive、21:9、16:9、4:3、1:1、3:4、9:16 | bailian.py；官方 |
| 参考图 | 最多 10 张；单边 240–8000 像素，长宽比不超过 8:1，单张不超过 20 MB；JPEG、PNG（不带透明通道）、BMP、WEBP（后端只认 png、jpg、webp） | bailian.py；官方 |
| 参考视频 | 后端一次传一段，先传到百炼的临时存储（48 小时有效）。官方：最多 5 段，单段 1–15 秒、合计不超过 15 秒，不低于 16 fps，mp4 / mov，单个不超过 100 MB | bailian.py；官方 |
| 提示词里怎么叫 | 参考图按传入顺序叫图1、图2……，参考视频叫视频1（图和视频分别计数） | 官方 |
| 拒收 | 内容审核会拦下部分写实人脸参考图（`FaceDetectionSuspect`），换种子不一定能过；没有「写实人脸一律拒」 | 作者实测，2026-11 |
| 声音 | 有，单子里 `audio`，默认开；开不开声音价格一样 | bailian.py；官方 |
| 别的参数 | `prompt_extend` 默认关（官方默认开），`seed`，水印固定关 | bailian.py；官方 |
| 价格 | 元/秒，按分辨率（华北2 北京）：普通队列 480P 0.3、720P 0.6、1080P 1.2；快队列 0.45、0.9、1.8。输入视频和输出视频都按秒计（续写 = 输入 + 输出）；请求失败不计费；新加坡地域更贵。数据在 [prices.json](prices.json) 的 `wan3.0-video`、`wan3.0-video-prime` | [百炼模型价格页](https://help.aliyun.com/zh/model-studio/model-pricing)，2026-11-22 查 |
| 出片时间 | 720P 中位：文生约 135 秒、首帧约 157、首尾帧约 156、参考图约 215、续写约 309；1080P：文生约 210、参考图约 304。大致每秒成片 17–27 秒 | 作者实测，2026-11 |
| 这个后端实测 | 2 秒、480P 文生一条：2026-11-20 用 `filmgen.py send` 送到服务器跑完，2026-11-22 用 `filmgen.py run`、key 从 `DASHSCOPE_API_KEY` 读再跑一次，见 [examples/smoke](../examples/smoke/overview.md) | 2026-11-22 |

一处说法不一样：单条时长，这个后端定的是 15 秒，接口到 30 秒。

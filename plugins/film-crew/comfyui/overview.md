# comfyui：把每一镜放进 ComfyUI

一句话：拍片的方法交一份镜头清单，这里照着把每一镜「用了什么、出了什么」放进 ComfyUI。一镜一个工作流，只放这一镜必要的：这一镜关键帧用到的几张图（白模静帧、参考图、别的镜头的关键帧写「S20 的尾帧」）→ 这一镜的关键帧（标题先写首帧 / 尾帧）→ 按喂法一个视频节点（文生 / 首帧 / 首尾帧 / 参考图），视频节点上直接放成片里这一镜。人从左边栏点开就看得全、看得懂，想接手有东西可拿，要调整就告诉 agent。节点包只回放已经出好的图和片，不调任何生成接口。路径都相对本目录。

## 核心思路

1. **拍片 skill 和 ComfyUI 分开，中间只有一份清单。** 这里给拍片 skill 一个接口（清单的格式 + 一条命令）。skill 不用知道 ComfyUI 的任何事；这里也不认识 skill 的目录，不调它的生成工具。清单的格式在 `../formats/shots-manifest.md`，拍片运行目录由 `../formats/read_run.py` 读成清单。
2. **进得去的是「算」，进不去的是「想」。** 出关键帧、生成视频是调一次工具，能做成节点；写镜头表、定哪几镜上白模、看片决定重抽，是 agent 的判断，图里放不下。ComfyUI 官方自己的白模片也是这样：白模在 Blender 里做好，图里只剩「喂 + 生成」。
3. **每镜只放必要的，像人自己搭的一样。** 这一镜的关键帧用到的几张图、这一镜的关键帧、一个视频节点，外面一个框写这一镜拍什么。别的镜头的关键帧只当一张输入图（写「S20 的尾帧」），不往上追链。同一张图只放一次，同一个画面只摆一遍。全片的白模预演、没喂进去的白模、站位描述、单独的成片节点都不放。
4. **一眼看出喂法和每个输入。** 视频按喂法分节点，口只有这种喂法要的，空口收起来。首帧、尾帧那张图的标题先写角色（首帧 · k_S3）；关键帧的口叫图1、图2（提示词里的 Image 1/2）。节点找文件用的参数（film、name、执行方式、seed……）藏起来。标题说人话：白模 · S3 开头、s01 的首帧、基准画面 · k_base。
5. **照人的开法，打开就看得全。** 人是从左边栏点开一镜的，侧栏挡着画布左边一块。打开时把整镜摆进看得见的那块，最大 100%。输入图多了排成格子、线走横缝，不从节点背后过。每个节点有图，视频自己播，不用点 Run。
6. **留下的就是人接手要用的；人只看、只拿，要调整告诉 agent。**
   - 留什么，照人自己做完这一镜会留下、接着要用的来定：这一镜的工作流、这一镜的关键帧和视频、跨镜头用的参考图。用 ComfyUI 自己的存法，人从 Assets 面板就能拿去接着用、点回这一镜。
   - 不多留：中间预览不留，只属于某一镜的白模静帧留在那一镜的图里，再跑不重复。
   - 不碰人的：这里放的文件都带 filmkit 记号，人存过的工作流不盖。
   - 人不在 ComfyUI 里改：ComfyUI 里显示的名字就是拍片 skill 自己的名字。人说「S3 的首帧」，agent 改完把这一镜再交一次。
7. **以真 ComfyUI 为准，自己打开看、照人的路走一遍。**
   - 口叫什么、参数怎么存、节点实际多大，都在真前端里读回来核对。
   - 检查脚本照人的开法查一遍：看得全不全、线藏没藏、该留的留没留、多没多留。
   - 人会怎么接手（拿一张图去用、改了再跑、存自己的版本），也照着走一遍。
   - 最后挑一镜在 8188 上截图自己看，连旁边的面板一起看。

## 怎么接（四步）

1. **起 ComfyUI**：放在读得到图和成片的服务器上。CPU 模式就够，带资产系统启动（重启后资产还在），tmux 里常驻，本机用 ssh 隧道看。见 [methods/02-server.md](methods/02-server.md)。
2. **装节点包**：`nodes/comfyui_filmkit` 链进 `custom_nodes`。见 [methods/03-nodes.md](methods/03-nodes.md)。
3. **交清单**：
   - 拍片运行目录先读成清单：`python3 ../formats/read_run.py <films.json> --out <清单目录>`。别的流程照格式自己写一份也行，例子是 `../formats/examples/manifest/demo.shots.json`。
   - 然后一条命令：`python3 scripts/shots2comfy.py <清单…>`。它登记，每镜写一个工作流（文件名带上拍什么），把跨镜头用的参考图放进 input，再把每镜排队跑一遍，关键帧和视频就留在 Assets 面板里了。
   - 只改了几镜，就用 `--shots` 再交那几镜。
   - 接口和清单见 [methods/00-interface.md](methods/00-interface.md)；怎么摆、放哪见 [methods/04-workflow.md](methods/04-workflow.md)。
4. **在真前端里像人一样看一遍**：这是这一块自己的验收，改了节点包、排法，或 ComfyUI 换了版本以后跑。点开侧栏、打开、查连线和参数、看得全不全、线有没有藏、回放、该留的有没有卡片。见 [methods/05-check.md](methods/05-check.md)。

节点怎么对、口和参数的约定，见 [methods/01-mapping.md](methods/01-mapping.md)；`../viewer` 节点图视图的「导出 ComfyUI」导出的也是这一份。留什么、留在哪、人拿到以后能干什么，见 [methods/06-handover.md](methods/06-handover.md)。

## 一镜在 ComfyUI 里是什么样

外面一个框，标题是这一镜：`S3 · 0:08.0–0:12.0 · 她把杯子放到桌上`。里面从左往右：

| 位置 | 节点 | 节点上看到的 |
|---|---|---|
| 左 | FilmKit 图（1～3 列的格子） | 白模静帧（蓝，「白模 · S3 开头」）、参考图（紫）、别的镜头的关键帧（黄，「s01 的首帧」「基准画面 · k_base」） |
| 中 | FilmKit 关键帧（首帧在上、尾帧在下） | 标题「首帧 · k_S3」；口图1、图2、图3；提示词；出出来的关键帧；重画过的写「画了 2 次」 |
| 右 | FilmKit 首帧生视频（或文生、首尾帧、参考图） | 只有这种喂法的口；模型、提示词、时长；标题写「生成 2 次，1 次报错」；下面直接放成片里这一镜，静音循环 |

一镜只有几个到十来个节点。在 1600×900、左边栏开着时，简单的一镜按 100% 整个放下，输入图多的也保持在 0.6 以上（再小前端不画字）。工作流在 Workflows 面板里的名字是 `S3 她把杯子放到桌上`，一列下来就是镜头表。

## 人怎么接手

| 人想做的 | 在 ComfyUI 里怎么做 |
|---|---|
| 看一镜是怎么做出来的 | Workflows → `filmkit/<片>/` 点开，整镜都在，视频在放 |
| 按画面找一镜 | Assets → Generated，每镜的视频后面跟着它的关键帧，从第一镜往下排 → 卡片右键 Open as workflow（重启以后也打得开） |
| 把关键帧、这一镜的视频、参考图拿去自己的工作流 | 卡片 → Insert as node（得到 LoadImage / LoadVideo）；白模静帧在这一镜的图里，直接从节点的口接出去 |
| 换自己的模型重出这一镜 | 从关键帧节点的口接到自己的节点上，和平常一样跑 |
| 想调整这一镜 | 告诉 agent 哪一镜、哪张图（就用 ComfyUI 里看到的名字：S3、k_S3）；agent 改完把这一镜再交一次，刷新页面就是新的 |
| 存了自己的版本 | agent 重出时不盖，留成 `S3（人改过）…` 并报出来 |
| 在回放的节点上改了提示词再点 Run | 只是回放，不会重出；前端提示一句「这是回放……把改动告诉 agent」 |

## 局限

- 只回放：出图、生成、重抽都是拍片 skill 那边的事，这里不调生成接口。人在工作流里改了什么，这里也不读；要调整是告诉 agent。
- 拍片 skill 还不会自己出清单，靠 `../formats/read_run.py` 从运行目录里读。重抽、哪张关键帧是哪一镜的，都是按文件名认的。
- 改过的图和片，卡片要等有人打开或刷新一次页面才换成新的。
- 资产要跨重启留着，ComfyUI 得带 `--enable-assets` 启动；没带时，Generated 只列这次启动以后跑过的。
- 重抽只写次数。每一次为什么重抽、被弃的那几条长什么样，没有：运行目录里没有统一的记录，被弃的片段也常常不留。
- ComfyUI 里没有时间线。Assets 面板从第一镜往下排（按文件写出来的时间，哪一镜重写过就跑到最上面），一次只加载 100 张。要按时间线看，用 `../viewer` 的展示台。
- 能转着看的 3D 白模还没做（ComfyUI 自带的 Load 3D 能放 GLB）。
- 在 ComfyUI 0.46.0、前端 1.59.6 上核对过。前端换版本，先重跑检查：藏参数、收空口、摆进窗口、找侧栏的位置，都靠前端脚本。

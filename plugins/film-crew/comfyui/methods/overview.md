# methods

先看接口（00），其余按先后排。每篇写思路、伪代码、实测的数字和踩过的坑。运行目录怎么读成清单，在 `../formats/read_run.py`。

- [00-interface.md](00-interface.md)：接口。拍片 skill 交一份镜头清单，一条命令放进 ComfyUI；两边各管什么、名字怎么共用、人要调整时怎么走、怎么撤掉一部片。
- [01-mapping.md](01-mapping.md)：拍片的步骤和 ComfyUI 节点怎么对，口、参数、标题的约定，哪些能换成官方节点。
- [02-server.md](02-server.md)：在服务器上起 ComfyUI：代码、虚拟环境、tmux、隧道。
- [03-nodes.md](03-nodes.md)：节点包：回放读什么、留什么（这一镜的关键帧和视频；资产系统开着时只写文件不上报）；前端脚本管显示（藏参数、收空口、图和视频、摆进窗口、跑完不变样）；生成模式以后怎么接。
- [04-workflow.md](04-workflow.md)：清单 → 工作流：怎么摆（输入图的格子、拐点走线）、文件名、放哪；跨镜头用的参考图放进 input；每镜排队跑一遍；人存过的工作流不盖。
- [05-check.md](05-check.md)：这一块自己的验收，在真前端里像人一样看一遍：连线、看得全不全、线有没有从节点背后过、图和视频、回放、该留的留没留、多没多留；人接手的几条路也走一遍。
- [06-handover.md](06-handover.md)：人怎么接手：照「人做完一镜会留下什么」定留什么、留在哪，人拿到以后能干什么；要调整时告诉 agent、agent 再交一次。

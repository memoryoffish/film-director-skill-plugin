# 06 人怎么接手：留什么、留在哪

一句话：agent 做完一镜，留在 ComfyUI 里的照人自己做完这一镜会留下、接着要用的来定——工作流、这一镜的关键帧和视频、跨镜头用的参考图，都用 ComfyUI 自己的存法；人打开 Assets 面板就能拿去接着用、点回这一镜。人在 ComfyUI 里只看、只拿；要调整就告诉 agent，agent 改完把这一镜再交一次。不多留，不碰人的东西。

## 推荐

**照「人做完一镜会留下什么」来定**，不照「越少越好」：

| ComfyUI 里的地方 | 人做完一镜会留下 | 我们留下 | 谁留的 |
|---|---|---|---|
| Workflows 面板 | 这一镜的工作流 | `filmkit/<片>/<镜头名 拍什么>.json` | shots2comfy.py |
| input → Assets · Imported | 上传的参考图、白模静帧 | 跨镜头用的：参考图 `filmkit__<片>__refs__girl_front.png`、基准画面 `…__keys__k_base.png` | shots2comfy.py |
| output → Assets · Generated | SaveImage / SaveVideo 存的关键帧和视频，文件里带着工作流 | 这一镜的关键帧 `filmkit__<片>__k_S22.png`、这一镜的视频 `filmkit__<片>__S22.mp4`，文件里带着这一镜的工作流 | 节点包，跑这一镜时（shots2comfy 交清单时就把每镜跑了一遍） |
| 队列、历史 | 每跑一次一条 | 一样 | ComfyUI |

不留：每个节点的中间预览、temp 里的文件、别的镜头的东西、全片预演。白模静帧不进 Imported：它只是那一镜的输入，留在那一镜的图里（从节点的口就能拿）；两百多张放进去，十来张参考图就找不到了。

- **人拿到以后能干什么**（都是 ComfyUI 自带的，卡片上右键）：
  - Insert as node in workflow：图变成 LoadImage、视频变成 LoadVideo，接到自己的节点上就能用；
  - Open as workflow in new tab：回到做出它的这一镜；
  - Download、Inspect；
  - 在这一镜的图里，直接从我们节点的口接到自己的节点上（口是真的 IMAGE、VIDEO）。
- **名字是两边共用的话**：工作流名、节点标题、文件名里都是清单里的名字，也就是 skill 自己的名字（k_S22、S22、wm/S22_a）。人说「k_S22 手不对」，agent 不用懂 ComfyUI 就知道是哪张；agent 说「S22 重抽了」，人在面板里搜得到。
- **要调整，告诉 agent**：人说哪一镜、哪张图、怎么改；agent 用 skill 自己的工具改（重画关键帧、重抽、重剪），把这一镜的清单再交一次（`shots2comfy.py … --shots S22`）。源头变了的关键帧、视频会重写，工作流重出；人刷新一下页面，这一镜就是新的，改过的那张排到 Generated 最上面。
- **我们放的都带 filmkit 记号、放最上层**：
  - 带记号：清理只动 `filmkit__<片>__*` 和 `workflows/filmkit/` 里没人动过的，碰不到人自己的文件；
  - 放最上层：资产系统开着时，前端把卡片插成节点会丢掉子目录，子目录里的文件插出来读不到；LoadImage 的下拉列表也只列最上层。
- **再跑不多**：文件已经在、源头没变，再跑不重写——人顺手点一下 Run，面板里不会多一张一样的卡片。源头变了（关键帧重画、成片重剪、这一镜的长度改了）才重写。
- **带资产系统启动**（`--enable-assets`），节点只写文件、不报给前端：ComfyUI 跑完以后自己扫一遍 output，把新文件登记上，开着的面板自己多出卡片。这样重启以后卡片还在，而且还点得回这一镜（读的是文件里带的工作流）。报给前端的卡片挂在那一次 Run 上，重启以后 Run 的记录没了，就点不回了。
- **每一镜跑一遍，资产才在**：出完工作流，照人的做法把每镜排队跑一遍（交清单的命令自己做，不用开浏览器）。面板按文件时间从新到旧排：倒着跑（最后一镜先跑），从上到下就是第一镜到最后一镜，每镜的视频后面跟着它的关键帧。
- **人存过的不盖**（保底：人一般不在 ComfyUI 里改）：重出工作流时，人在 ComfyUI 里改过、存过的那份留着，挪成 `S3（人改过）她把杯子放到桌上.json`，再写新的，并报出来是哪几镜。人自己另存进来的文件一律不动。
- **做不到的当场说**：这一头只回放。人在我们的节点上改了提示词、模型、时长，前端提示一句「这是回放，改了也不会重新生成……把改动告诉 agent」。悄悄不生效，人会以为改动起作用了。
- **打开不算改**：载入时收空口、摆视图，都不让工作流被标成「已修改」；关标签页不会问要不要保存。

## 伪代码

```
agent 把一部片带进 ComfyUI（skill 交清单 → shots2comfy）:
    for 镜: 旧文件对得上自己的 sha1 → 换掉；对不上 → 挪成「镜头名（人改过）拍什么.json」，报出来
            写工作流（里面记 sha1）
    参考图、基准画面 → input/filmkit__片__相对路径
    把每镜排队跑一遍（倒着排）；人以后点 Run 也是走这里:
        关键帧节点: output/filmkit__片__关键帧文件名 不在或比源头旧 → 写（带工作流）
        视频节点:   output/filmkit__片__镜头名.mp4 不在、比成片旧、长度对不上 → 从成片裁 t0–t1 写（带工作流）
        已经在、没变 → 不写
        不报给前端：ComfyUI 跑完自己扫 output，把新文件登记进库（没开资产系统时才报）
    --prune: 只删带 filmkit 记号、已经用不到的

人:
    看 → Workflows 点开；找 → Assets 卡片 → Open as workflow
    拿 → 卡片 → Insert as node，或从节点的口接出去
    要调整 → 告诉 agent「S22 的首帧，手不对」

agent 调整:
    用 skill 的工具改（重画 k_S22 / 重抽 / 重剪）→ shots2comfy 清单 --shots S22 → 告诉人刷新页面看
```

## 实测（ComfyUI 0.46.0 / 前端 1.59.6）

- 留下的：output 里每镜的关键帧和视频，每个文件里都带着工作流；input 里是跨镜头用的参考图和基准画面；temp 里什么都没有。Generated 一个文件一张卡片：最上面是第一镜的视频，下面是它的关键帧，再下面是第二镜的。
- 头一回跑，每镜 2～5 秒（要存关键帧、裁视频），裁出来的视频长度和这一镜的 t1 − t0 最多差一帧。再跑，文件一个不重写，卡片一张不多。重启 ComfyUI 以后卡片都在，视频卡片、关键帧卡片右键 Open as workflow 都打开了这一镜。
- 把一镜留下的两个文件删掉再跑：几秒就重写出来，ComfyUI 自己那遍扫描把它们登记上，卡片排到最上面。
- Assets 面板开着点 Run，让视频节点写一个新文件：跑完后不到一秒，面板最上面自己多出这张卡片；紧接着再来一次要等几秒（ComfyUI 的扫描最多 10 秒一次）。
- 一张关键帧被两镜的视频任务直接用（比如 k_S4b 喂了 S2 和 S4）：文件只有一份、卡片只有一张，排在先跑的那一镜后面。倒着跑，就是靠后的那一镜：k_S4b 在 S4 的视频下面。
- 卡片插成节点真跑过：Generated 的 `LoadVideo: filmkit__zz_demo__S3.mp4 [output]`、Imported 的 `LoadImage: filmkit__…png`，都成功。
- 在一镜的图里，把关键帧节点、视频节点的口直接接到别的节点上跑（用预览节点试的）：成功。
- 人在一镜的关键帧上改提示词、存下，再重出工作流：人的那份留成 `S3（人改过）她把杯子放到桌上.json`，新的照写，输出里报了这一行。
- 调整一轮：换掉首帧的图、改一句提示词，把这一镜再交一次，0.8 秒。刷新页面，关键帧节点是新图、新提示词；Generated 里这张关键帧排到最上面，旧卡片没了；视频不重写。
- 试过、放弃的：
  - 留在 `output/filmkit/<片>/` 子目录里 → 资产系统开着时，卡片插成节点丢了子目录，读不到；
  - 每次跑都报给前端 → 同一镜两张一样的卡片；
  - 只在第一次落地时报 → 一镜一张卡片很整齐，但重启以后 Open as workflow 点了没反应；
  - 喂进去的图全放进 input → 白模静帧占了大半，Imported 一次只加载 100 件，参考图搜不到。
- 没开资产系统时也试过：照常能用，卡片插成节点的值一样；但每跑一次多一张卡片，重启后 Generated 是空的。

## 不做的，和还没有的

- **不做：在 ComfyUI 里改了就重出、读出人在工作流里改了什么。** 人不在 ComfyUI 里改；要调整是告诉 agent，生成是 skill 那边的事。
- **改过的文件，卡片要等刷新**：ComfyUI 跑完那遍扫描不认原地重写的文件，有人打开或刷新页面时才重新登记。
- **按时间线找**：Assets 面板的卡片按文件登记的时间排，不是时间线。再跑不重写，次序不变；哪一镜改过，它的卡片就跑到最上面。要按时间线看，用 `../viewer` 的展示台。
- 人自己在 ComfyUI 里做出来的图和片，要人告诉 agent 用哪一个。

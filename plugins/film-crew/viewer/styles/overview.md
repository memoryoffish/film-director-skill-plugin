# styles

风格：给页面换一身样子和排法，页面上的事实和能做的事不动。不选风格时页面一个字不变；选了也随时能切回去。

| 风格 | 是什么样 | 主要照着谁 |
|---|---|---|
| `fancy` | 深色放映厅：玻璃面板、沿边跑的一道光、渐变字、点阵底纹；数字和状态做成发光的小牌 | Magic UI |
| `warm` | 摊在桌上的拍片手账：纸、胶带、手写字、手画的线和印章，白模小人说一句现在拍到哪了 | Excalidraw |
| `plain` | 页面本来的样子（没有文件） | — |

## 一套风格有什么

`styles/<名字>/` 一个文件夹：

| 文件 | 做什么 |
|---|---|
| `tokens.css` | 这套风格的颜色、字体、圆角、阴影。每一页都带上。可以没有 |
| `<部分>.css` | 一页由一个或几个部分拼成，每个部分一份。现在有的部分：进度页 `progress` |
| `<部分>.js` | 要挪节点、加元素、改排法时才有 |

[switch.js](switch.js)、[switch.css](switch.css) 是页面上「原样 / Fancy / 暖心」那个切换；装进页面的是 [scripts/styles.py](../scripts/styles.py)。

## 怎么用

- 进度页：`progress.py … --style warm`。给几套（`--style plain,fancy,warm`）页面上多一个切换，第一套是默认，选了哪套记在浏览器里；地址后面加 `?style=fancy` 直接开成那一套。
- 别的页面：`styles.dress(页面, [风格…], [部分…], facts, hosts)`。`facts` 是页面上没写成标签的事实（更新时间、花费……），风格的脚本从 `<script id="style-facts">` 读；`hosts` 是切换放进哪几处。

## 写一套新的

1. 建 `styles/<名字>/`，先写 `tokens.css`：自己的颜色、字体、圆角、阴影，各部分的 CSS 都从这里取。
2. 每个部分一份 CSS。每条规则以 `:root[data-style="<名字>"]` 开头；`@keyframes`、`@property` 的名字以 `<名字>-` 开头；不用 `@import`、不引外面的字体和图（图标画成行内 SVG）。
3. 要改排法才写 JS，登记 `FilmStyles["<名字>"]["<部分>"] = {on(), off()}`。`on` 里做的每一件事——加的元素、挪的节点、挂的监听、改的字、写的行内变量——`off` 里都还原：切回原样后，页面的节点要和没切过时一个不差。
4. 页面自己的脚本还在跑，别挡它的路：
   - 它按类名、id 找的元素不改名、不删；要藏就用 CSS 藏。
   - 它会挪动或重画的节点不包进新加的元素里。
5. 状态一律用页面已有的那几种颜色的意思（合格、要重抽、在生成或检查、失败、还没查），换色不换意思；动效在 `prefers-reduced-motion` 下关掉。

## 查什么

- `python3 -B -m unittest tests.test_styles`：每条规则都在自己的名字底下，动画名带前缀，脚本登记在自己的名字和部分上。
- 浏览器里照人的开法看：1440 宽和 520 宽各一遍，都不横向溢出；有视频的格子能点开放；每种状态（出好了、在生成、失败、要重抽、还没查）都看到。
- 来回切两次：原样 → 这一套 → 原样，页面的节点、文字、行内样式和没切过时完全一样。
- 页面有自己的检查脚本的，选了这套风格再跑一遍，照样全过。

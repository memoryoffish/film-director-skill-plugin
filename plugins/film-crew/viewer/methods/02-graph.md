# 节点图：一镜一张 ComfyUI 式的图，照 `../comfyui` 写出的工作流画

一句话：展示台的另一个视图，顶栏按钮切换，共用底下的时间线和成片。每一镜嵌一份 ComfyUI 工作流（`../comfyui/scripts/shots2comfy.py` 从同一份清单写出来的文件），页面照它画：节点的位置、大小、标题、颜色、口，外面的框，线过拐点画成直线；图放进节点，视频节点里放成片的这一镜。「导出 ComfyUI」下载的就是那份文件，和 ComfyUI 工作流目录里的一个字节不差。

只借 ComfyUI 的样子，不借代码；「我们的节点 → ComfyUI 节点」的规矩只在 `../comfyui` 一处，页面不另写一套。

## 什么时候用

- 拍片运行有白模、关键帧、重抽，要回答「这一镜的首帧是拿什么画的」「这张图是从哪一镜带过来的」「重抽了几次」，或者要把一镜拿进 ComfyUI。
- 和展示台一起用：展示台按一条生成看喂进视频模型的是什么，节点图看这一镜谁喂给了谁。
- 不合适：没有出图记录、每镜只有一条提示词的片子，图只剩一两个节点，展示台就够。

节点图只擅长「结构」：用了哪几张图、哪句提示词，出了哪一条。「过程」（第几次、为什么重抽）只在节点标题上写次数、点「↻ ×N」看每一次；「时间」看底下的时间线。

## 步骤

1. **同一份清单交给 `../comfyui`**：`shots2comfy.py manifests/*.shots.json --comfy <ComfyUI 目录>`（只要文件加 `--no-run`；`--out` 可以另指工作流目录）。它在 `<工作流目录>/<film>/` 下一镜写一个文件。
2. **做页面时指给它**：`console.py manifests/*.shots.json site --workflows <工作流目录> [--view graph]`。`--view graph` 打开先看节点图。
3. **页面读工作流**：每个文件认 `extra.filmkit` 里的 `film`、`shot`，对上清单里的镜头；同一镜有几份（人在 ComfyUI 里存过的那份会被挪成「S22（人改过）…」留在旁边），用 shots2comfy 写的、没人动过的那份（`extra.filmkit.sha1` 对得上）。原文照搬进页面，不解析了再写回去（Python 写的 `61.0` 会变成 `61`，导出就差了）。
4. **一部片有哪一镜找不到工作流**，这部片就不做节点图（打一行说缺哪几镜），展示台照旧。没给 `--workflows` 时整页都没有节点图。
5. **照用户的开法看一遍**：首页点片卡 → 节点图 → 点时间线上的镜头；查什么见末尾。

## 一镜里有什么（排法是 `../comfyui` 定的）

- 外面一个框，标题就是这一镜：`S22 · 1:01.0–1:05.0 · 她推门进屋`。
- 左边，输入图排成 1～3 列的格子：白模静帧（`白模 · S22 开头`）、参考图（`参考图 · girl_front`）、别的镜头的关键帧（`s01 的首帧`；对不上哪一镜的写 `基准画面 · k_D`），不再往上追。同一张图只有一个节点。
- 中间，这一镜的关键帧上下叠，首帧在上：标题先写角色（`首帧 · k_S22`），口是图1、图2……，下面是出图提示词和出的图。
- 右边，按喂法一个视频节点（首帧生视频、首尾帧生视频、参考图生视频、文生视频），口只有这种喂法要的；重抽写在标题上（`首帧生视频 · v22r · 生成 2 次`）。
- 不放：全片白模预演、没喂进去的白模静帧、站位描述、单独的成片节点。

## 页面上怎么画

1. **节点**：照工作流里的 pos、size（不算标题栏，标题栏 30 画在 pos 上面）、color（标题栏）、bgcolor（底）、title。口一行 20：只画接了线的输入口和输出口。关键帧是 112 高的提示词框，视频节点是 model、132 高的提示词框、duration 各一行；剩下的高度放图或视频，四周留 6。这样节点在页面上和在 ComfyUI 里一样大，照着摆不会叠。
2. **外面的框**：groups 里那一项，bounding 定位置，标题照 font_size 写在框里左上。
3. **线**：直线。出口 → 拐点 → 入口：linkExtensions 记着每根线最后经过的拐点，顺 reroutes 的 parentId 倒着找，再反过来。拐点画成小圆点。
4. **图和视频**：图按 `graph.media`（运行目录里的路径 → 页面里的媒体名）放，点了放大。视频节点里放的就是展示台那个成片 `<video>`：切到节点图时挪进来，换镜只挪位置；放到这一镜末尾回到开头（拖动、点别的镜头时 `film.seeking` 是真，不回）。白模预演在节点图里不加载。
5. **页面另加的**：
   - 重抽、重画：标题栏右头一个虚线小圈「↻ ×N」，悬停或点开看每一次叫什么、用没用上、报没报错、和用上的那次比改了什么；有一次报错，小圈是红的。
   - 提示词框点了看全文（大框）。
   - 画布顶上一条：左边有问题的那一句和图例，右边「适应窗口、−、+、导出 ComfyUI」。量它实际多高，适应窗口时整镜摆在它下面。
   - 时间线下面按阶段分三行（只在节点图视图）：白模（实心 = 喂进去了，空心 = 有白模静帧没喂进去）、关键帧（往上一共几张）、生成（×N，报过错的加红框），点一格跳到那一镜。
6. **适应窗口**：整镜放进顶上那条下面的地方，最大 100%；拖动平移，滚轮或两指缩放。成片放到哪一镜，节点图就换成哪一镜。拖出 4 px 以后才算拖动，不然点图、点提示词都不灵。
7. **一屏放下**：1440×820 里顶栏、节点图、时间线都在；节点图视图里时间线收紧一点，把高度让给画布。手机上按高度放、从左边开始，横着拖。

## 数据

每部片的 `graph` 字段：

| 字段 | 是什么 | 从哪来 |
|---|---|---|
| `wfz` | 各镜的 [文件名, 工作流原文]，整个列表 JSON → gzip → base64 | `--workflows` 下的文件 |
| `media` | 工作流里图的 file → 页面里的媒体名 | 同上 |
| `img`、`key`、`job`、`shot` | 一张实体表：图（白模静帧带镜头、首尾、站位）、关键帧（出图的输入、当过谁的什么、重画）、视频任务（参数、切成哪几镜、这一次的结果、重抽的每一次）、每镜按名字的白模静帧 | 清单：`pictures`（`keyframe` 为真的往上追 `image_jobs`）、每镜的 `video.sent`、`status`、`attempts`、`named_stills` |

```
构建（console.py，每部片）:
    实体表: for 每一镜: 从 video.sent 的首帧、尾帧、参考图往上追
                         pictures[图].keyframe 为真 → 记关键帧（image_jobs 里的 inputs、size、ok、attempts），再追它的 inputs
                         否则 → 记一张图（白模静帧带 still、note）
                       视频任务记一次：sent 里的参数、status、attempts；切成哪几镜
    工作流: 读 <工作流目录>/<film>/*.json，按 extra.filmkit.shot 对上每一镜（没人动过的优先）
            记 [文件名, 原文]；工作流里每个图的 file → 转成页面的图，记进 media
    graph.wfz = base64(gzip(上面的列表))

页面，第 i 镜:
    第一次：解开 wfz
    画框；画每个节点（pos、size、颜色、标题、接了线的口、提示词框、图）
    每根线：出口 → 顺拐点链 → 入口，直线
    成片的 <video> 挪到视频节点的图那块；适应窗口
放的时候（节点图视图）: 到这一镜 t1 就回 t0，除非正在拖或刚点了别的镜头
导出: 下载第 i 镜的原文，文件名就是那个文件的名字
```

## 好用的规则（实测 162 镜）

- 每镜最多 10 个节点、平均 6.6；98 镜用了拐点，最多 8 个。喂法：首帧生视频 105、首尾帧 54、参考图 3。
- 1440×820 适应窗口后的缩放：抽看的六镜在 0.52–0.83 之间。同一镜在 ComfyUI（1600×900、左边栏开着）里打开要大一些：页面上方有顶栏、下面有时间线，画布矮。
- 162 镜的工作流原文 1.34 MB，压完 0.18 MB；整页 HTML 1.3 MB（不带节点图 0.9 MB）。媒体一个没多。
- 节点类型、口、参数、标题、颜色、框和拐点的约定以 `../comfyui` 为准（它的 `methods/01-mapping.md`、`04-workflow.md`）。约定改了，页面不用改，重出工作流、重跑 `console.py` 就行；要改的只是画法（比如节点里多了一种控件）。

## 做完后检查

- 1440×820 和 390：没有脚本报错，整页不横向溢出；1440 时顶栏、画布、时间线都在一屏，顶上那条不压住框的标题。
- 每部片各开几镜（要有首尾帧、参考图生视频、带拐点的）：标题、口、线和 ComfyUI 里同一镜一样；↻ ×N 对得上清单里的 `attempts`；提示词能看全文；图能放大。
- 放成片：节点图里只在这一镜里转；切回展示台，成片回左栏、连着放。
- 导出几镜，和工作流目录里同名的文件逐字节比；在真 ComfyUI 里打开、回放归 `../comfyui`（`scripts/check_in_comfy.py --run`）。

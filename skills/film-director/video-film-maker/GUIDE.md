# video-film-maker

一句话：先把片子设计好（剧本、镜头、时长、人物），再一个单元一个单元地生成，单元之间想好每一刀怎么接，最后在剪辑里统一节奏、画面和声音，逐层对照着验收。路径都相对本目录。

## 核心思路

1. **一部片分四层**：镜头、单元（一次生成调用）、衔接（单元之间）、整片。镜头管画面和动作，单元管分镜和一致性，衔接管每一刀怎么接（把剪点藏起来，还是露给观众看），整片管节奏、画面和声音的统一。
2. **能在生成前定的，都先定**：剧本、镜头表、时长，人物和道具长什么样。定得越多，结果越可控，要重抽的也越少。想要模型给的意外，就有意留几处不定，先拍小样试。
3. **一致性靠参考，不靠文字**：人、道具、画风用参考图或续写锁住，文字只写参考里没有的东西；锁的是样子，表演和状态要留出变化的余地。
4. **生成先求对，关键镜头再求好**：重抽用来淘汰拍错的。最要紧的几镜（高潮、情绪最重的、开头结尾）有意用几种不同写法各拍一条，看片挑最好的。节奏、变速、画幅、调色、声音、局部修补，都在后期统一做，不靠同一种写法一遍遍重抽去碰运气。
5. **每一层都对照着验收**：有原片就逐镜对原片，没有就对镜头表；工具说合格的，也要人眼再看一遍。
6. **镜头语言要有来处**：可以从零设计，可以借鉴多部电影的处理，也可以复刻一场戏、逐镜对照原片。学的是规律，不照搬画面。
7. **这份 skill 是起点，不是上限**：片子要什么感觉由这部片自己定，默认电影感。照推荐做，得到的是稳：这些做法在做过的片子里管用，结果可控、重抽少。失去的是意外和这部片自己的味道：推荐的做法偏向可控、做对，反复用，片子会彼此相像。所以支持探索：想到不一样的拍法就拍小样，和推荐的并排放，自己比、自己定，怎么试、怎么记见 [explore.md](stages/common/explore.md)。
8. **一部出彩的片，比五部稳但不出彩的片都值；错多的片会被直接丢掉**：先保证片子没有明显的错，稳了以后把剩下的预算往出彩上花；预算怎么分，边拍边调（见 [预算](stages/common/budget.md)「钱往哪花，边拍边调」）。

## 做一部片的 4 步

开工前先读 [几步都要守的规矩](stages/common/rules.md) 和 [几个词的意思](stages/common/terms.md)：几步都要守的规矩只写在那里；只在一步之内几篇共用的规矩，写在那一步 overview 的「这一步几篇共用的」。每一步的 overview 都按同一个顺序写：这一步交出什么（包括没通过就不能进下一步的检查）、什么情况用哪种做法、常见错和怎么查、按类型。**开始生成之前**，先按 [stages/common/budget.md](stages/common/budget.md) 估出时间和花费，拿去问用户。同时问两件事：这部片要不要配乐（见 [声音设计](stages/4-edit/audio.md)），重活（剪辑、转码、抽帧、语音识别）在哪台机器上做。用户有服务器，重活就放在服务器上做，脚本和素材也跟着放过去，本机只留成片。开始生成后开一个进度页，每一次生成的视频都能在上面直接播，见 [stages/common/visualize.md](stages/common/visualize.md)。

1. **分镜**：剧本 → 节拍 → 镜头设计 → 镜头表 → 时长；镜头可以从零设计、借鉴几部电影、或逐镜复刻一场戏；全片靠它撑起来的那一刻，要先想清楚怎么拍得出来。在这一步把全片的接缝过一遍：换场、换时间、进出回忆、首尾呼应各用哪种接法，从接法库里挑。每一刀怎么接、每镜开头结尾是什么状态，都写进镜头表。[1-storyboard](stages/1-storyboard/overview.md)
2. **定妆与关键帧**：人物、道具、场景的参考图，每种状态一套。开头画面要固定下来的镜头，先把定妆图转画成这一镜的关键帧；关键帧画完先自己看一遍，对了再拿去生成视频。[2-casting](stages/2-casting/overview.md)
3. **生成与检查**：一次调用放哪些镜头、提示词（先用我们的结构起草，再按所用模型的官方写法适配：Wan 3.0、Seedance 2.5 各有一套）、表演、台词；每条生成完马上检查，能改好的问题当场重拍。[3-generation](stages/3-generation/overview.md)
4. **剪辑与成片**：照镜头表的「接」一列剪；再处理节奏、画幅、调色、声音、修补；逐镜对照原片或镜头表看，做成片检查；最后给用户盲选，按用户的选择接着改，结果记进 [经验账本](refs/practical/experience.md)。[4-edit](stages/4-edit/overview.md)

**接法库**（[transitions/](transitions/overview.md)）：两次生成之间怎么接。这是这份 skill 里方法和案例最全的一块，每种接法都有实拍案例和生成后检查。

- 同一场戏里大多硬切；换场、换时间、进出回忆、首尾呼应这些地方要专门设计：全片用一种接法做主干，两三种做点缀，开头和结尾互相呼应（见 [怎么搭配](transitions/movie.md)）。
- 库里有遮挡、穿门洞、推镜穿越、续写、首尾帧过渡段、媒介转变、闪白、匹配剪辑，这八种都有实拍案例；甩镜、两极镜头两种少用，只有写法，没有实拍案例。
- 这些接法在生成时就要照它的要求拍，所以要在分镜时定下来，写进镜头表的「接」一列，剪辑时照着接。
- 旅程和一镜到底、回忆、科幻大场面这几类片子以接法为主干，分镜之前先读接法库。

## 两个可选的搭档

都是单独的 skill。装了就接上；没装或这部片不想用，这份 skill 自己也能把片拍完。

- **blender-previz（白模）**：一场戏空间上容易错（几个机位要认得出是同一个地方、谁在谁左边、门往哪开、间距、东西落在哪），先在 Blender 里搭成白模，量清楚再拍。它在四个地方接进来：[镜头表](stages/1-storyboard/shot-list.md) 的「空间」一栏定哪些镜头要用白模，白模静帧和定妆图一起转成这些镜头的 [关键帧](stages/2-casting/keyframes.md)，这些镜头按白模关键帧喂给模型的方式（当首帧、首尾帧，还是放进分镜单元）[分组生成](stages/3-generation/shot-unit.md)，[成片检查](stages/4-edit/final-check.md) 时对着白模查位置。用了白模，每一步多做什么，写在那一步文件夹里的 `blender_extra/`，那一步的 overview 有一节「用了白模」；几步都要知道的在 [common/blender_extra](stages/common/blender_extra.md)。不用它时，空间只能靠文字交代：在镜头表里把左右、朝向、间距写成固定的说法，全片每次都逐字照抄。
- **refsound（找现成的声音）**：视频模型配的曲子或音效不满意、要从网上找现成的时候，照它的做法挑（见 [声音设计](stages/4-edit/audio.md)）。不用它时，声音全由视频模型生成，或者自己找版权许可清楚的。

## 每种类型的片子应该是什么样

- **动作、打斗**：快而有分量。镜头短、动作拆细，谁在攻谁在挡一眼看清；撞击那一下要慢下来，声音先压低，再突然放响。
- **悬疑**：慢而紧。信息一点点给，靠声音和细节制造不安；线索前后对得上，结尾的揭示看得懂。
- **科幻、大场面**：有尺度。从远到近、从外到内的空间关系要看明白，巨物靠周围的东西显出大小。
- **旅程、一镜到底**：连续。人一直在走，空间一路连下去，方向统一，看不出剪点。
- **回忆、故事里的故事**：分得清层次。现在和过去一眼分得开，进出回忆有明确的过渡和不同的画面质感。
- **剧情、多人对戏**：清楚。谁在哪、谁看谁不乱，同一个人的脸前后不变。
- **二维动画**：统一。画风从头到尾一样，人物和关键道具不变形。

# 配置和检查门槛（默认值）

方法正文只写思路和做片的经验；调用参数、检查门槛、容差都记在这里。这些都是在 Wan 3.0 上用过的值，换模型、换片子时要重新定。「脚本」一栏是 [scripts/](../../scripts/overview.md) 里对应的常量或参数，改默认值就改那里。每次实际用的值和实测结果写在案例里。衔接用的门槛（「衔接检查」、光学类、和方法不一致的地方）在 [config-transitions.md](config-transitions.md)。

## 调用

| 项 | 默认 / 用过的值 | 脚本 |
|---|---|---|
| 单次调用时长上限 | ≤ 15 秒（接口本身最长到 30 秒；15 秒是我们定的）；续写的时长按「输入 + 输出」算 | `wan.py` `MAX_CLIP_S` |
| 分辨率 | 测试片用 720P；大片和复刻用 1080P | `wan.py` 默认 1080P（job 里写 `resolution`） |
| 画幅 | 16:9；宽银幕先按 21:9 生成（1080P 下实际输出 2206×946），再裁成 2.39:1 的 1920×804，放进 1920×1080 的画面，上下各留 138 像素黑边 | job 里写 `ratio`；带参考图时 `movie.py` 在代码里固定用 16:9 |
| 帧率 | 30 fps | — |
| 并发 | 同时 2–3 个任务 | `occut.py gen --workers`（默认 4，比我们用的多） |
| 其他参数 | audio 开、prompt_extend 关、watermark 关；参考图按传入的顺序，在提示词里叫图1、图2…… | `wan.py` |
| 种子 | 重抽：基础种子 + 10 ×（第几次 − 1） | 案例里写 |
| 重抽上限 | 首轮每个单元 3 次；修复每处 5 次 | plan 里写 |

## 分镜单元

| 项 | 默认 / 用过的值 |
|---|---|
| 切点核对容差 | ±0.3 秒以内直接算合格（经验阈值；Wan 3.0 实测单元内多在 ±0.06 秒以内，拳馆 ±1 帧）。超过的不按数字判：切点都在、没有多切，每一镜都拍全了，照实测切点剪得出要的时长，就算合格（一镜实测 5.42 秒、表上 5.0 秒，能用）；只有某一镜被挤短到拍不全，才重抽。Seedance、HappyHorse 没有系统测过的数（见过一个切点晚 0.76 秒），先照这条判 |
| 检测器报的切点 | 可能比新镜头真正的第一帧早几帧（一次报 2.90 秒，实际从 3.00 秒开始）：剪点以画面为准，往镜头里面挪 2–3 帧 |
| 找实测切点的范围 | 计划切点前后 0.6–1.0 秒 |
| 自带切镜候选 | 颜色分布距离 ≥ 0.25（`occut.py` `JUMP_FLAG`） |
| 分镜表写的剧情时长比生成时长短 | 约 0.4 秒（3 秒的单元 0.2 秒） |
| 第一镜最短 | 约 1.1 秒 |

## 声音

| 项 | 默认 / 用过的值 | 脚本 |
|---|---|---|
| 接缝声音交叉 | 0.25 秒；声音搭桥 0.12 秒；短促单声 0.03 秒 | `occut.py` `XFADE_S` |
| 配乐 | 频谱上一组窄峰连续出现 ≥ 1.5 秒、在音符之间跳，就是配乐。`peaks.py` 会把房间底噪当成窄峰，持续的和弦会漏掉。拳馆用的判法：180–2000 Hz 里至少 2 个窄峰高出中位数 44 dB 以上。这个判法实测偏松：《雨季未完》原声里有配乐的 4 段，它只抓到 1 段，另外 3 段是看频谱图才发现的。所以频谱图必须看，数字只当初筛 | `peaks.py` |
| 人声 | 用语音识别（Whisper large-v3）转写，再对照频谱。只把有人说话的那几秒喂给它，因为整条喂进去，它会在安静段编出词来 | `asr.py` |
| 次声高通 | 35 Hz | — |
| 响度 | 动作段约 −17 LUFS、安静段约 −23 LUFS；全片 −17 到 −21 LUFS，限幅约 −2 dBFS。只用单遍 loudnorm 再编码成 AAC，真峰值会超过 0 dBFS（测到 +0.8）。所以要先测响度，用固定增益加限幅，编码后再量一次真峰值 | — |
| 片头片尾 | 淡入 0.5 秒，淡出 1.5 秒；最后一个动作做完后，留 1.5–2 秒再开始淡出；从结尾截短到目标时长 | 分镜表 `fade_in_s` `fade_out_s` `trim_from`（`occut.py` 默认不淡入淡出、从结尾截） |

## 补人声（参考视频重拍）

下表是补人声的试点（3 小段）和生产那一轮（4 部片的台词段）用的值，见 [补人声](../../stages/3-generation/revoice.md)。

| 项 | 默认 / 用过的值 | 脚本 |
|---|---|---|
| 片段 | 一个镜头，≤ 5 秒（前 2.5–5 秒能和原镜头保持一致，之后画面会偏离原镜头）；最好固定机位（和原镜头的相似度：固定机位 0.75–0.88，跟拍、推拉 0.35–0.48） | — |
| 生成时长 | 取整秒，比片段长 0.5–1 秒，多出的尾巴剪掉 | job 里写 `duration` |
| 调用参数 | 参考视频不带声音；`audio` 开、`prompt_extend` 关、无水印、固定 `seed`；分辨率和画幅同成片（试点 1080P） | `wan.py` job 的 `reference_video` `audio` `prompt_extend` `seed` |
| 计费 | 输入 + 输出秒数（10 秒片段计 20 秒） | `budget.py` 用 `extension` + `input_s` |

# 衔接的检查门槛（默认值）

只在做专门的衔接（遮挡、续写、门洞、色彩匹配、声音搭桥、光学类）时用；通用的调用参数和门槛、这些值怎么用，见 [config.md](config.md)。

## 衔接检查

| 项 | 默认 | 脚本 |
|---|---|---|
| 盖满（4×8 格里最偏的一格和中间值的色差） | ≤ 12 | `occut.py` `LEAK_MAX` |
| 参考图模式下 B 开头盖满 | ≤ 16（和上一条不统一；漏一条窄缝时常在 14–25） | `occut.py` `HEAD_LEAK_MAX` |
| 盖满会误判的场景 | 夜雨铆钉 13–23、水彩 15–24、带黑边 26.8–28.8（裁掉黑边后 11.4–12.0） | — |
| 遮挡接缝叠化 | 4–6 帧（不多于 B 开头盖满的帧数） | `movie.py` `DISSOLVE` |
| B 开头加速 | 速度比 < 0.85 才加；倍数 = 1 / 速度比，最多 2.5；1.2 秒内降回原速 | `occut.py` `RAMP_BELOW` `RAMP_MAX` `RAMP_S` |
| 接缝附近不许有模型自带的切镜 | 方法里写约 1.2 秒；代码里查接缝旁 1.0 秒；遮挡接缝之后，查的是 B 开头加速的那 1.2 秒 | `occut.py` `SEAM_GUARD_S` |

| 续写的复述段和输入对得上 | PSNR ≥ 24 dB（画面缩到 480 像素宽再算） | `movie.py` `EXT_MATCH_MIN` |
| 续写接缝亮度差 | ≤ 10% | — |
| 门洞最暗处 | 最后 1 秒平均亮度 ≤ 15（0–255），亮于 100 的像素 ≤ 1%；从暗（< 20）到亮（> 80）≥ 2 秒，单帧跳 ≤ 10 级；亮度补偿用 1–1.5 秒逐渐撤掉 | — |

## 光学类：叠化、淡入淡出、空镜头（30 fps）

从 [光学类转场](../../transitions/optical.md) 挪来的原文；这三种还没有单独的案例。

叠化与淡入淡出：

- 叠化约 **1 秒（30–36 帧）**。
- 淡出 15 帧 + 黑 6 帧 + 淡入 15 帧。
- 形状叠化时先对齐两边的形状，再在约 **2 秒**内退回原样（smoothstep）；两边大小差得多就要放大，放大后画面会变软。
- 要查形状叠化两边的主体大小、位置差多少（差 2 倍以上就放大来补，放大后太软就重抽），以及固定机位的画面有没有漂移。

空镜头：

- 空镜约 **3 秒**。
- 空镜前后两处都硬切，声音交叉约 0.3 秒（前一段多留 0.15 秒、后一段提前 0.15 秒）。

## 和方法不一致的地方（代码还没改）

- 遮挡剪点：方法写「从盖满段开头往后留够叠化的帧数就剪」；`occut.py tail` 选的是尾部窗口里盖满帧中信息最少的一帧（并列取靠后）。用时手动指定剪点。
- 盖满门槛两处不统一（12 / 16），也不区分没盖住的缝在画面哪一侧。
- 光晕：方法写在光晕最亮时硬切，或只叠一两帧；`optical_edit.py` 的 bloom 默认 `overlap` 4 帧。

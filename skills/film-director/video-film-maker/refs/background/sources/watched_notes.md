## 1. 杰瑞Chang《AI视频总翻车？问题根本不在提示词》

- 链接：https://www.bilibili.com/video/BV12Sc2zbE8X
- 时长：3:00
- 转写质量：口播清楚，Whisper 可用（「首尾帧」被转成「手尾针」）

### 作者讲的方法（按步骤）

背景：他想复刻自己以前在 Higgsfield 上做过的「地球推进」转场（太空 → 地球 → 海滩上的人），说「翻车了至少二三十次」，提示词越改越长，结果越来越差。后来想起来，当初在 Higgsfield 做好的素材「其实我是倒放的」（语音 0:57–1:02）。

1. 每次做转场之前先问一个问题：这个运动方向是在做**加法**还是**减法**。（语音 1:37–1:45）
   - 加法：从太空往下推，一开始只给 AI「一个地球加几片云」，地形、街道、建筑、人物都得靠它自己补，「越往后越具体，越具体就越容易猜错」。（语音 1:11–1:23）
   - 减法：反过来，从具体往抽象走。
   - 作者说做了 A/B 测试，「做减法的成功率是明显更高的」。（语音 1:45–1:50）**视频没给测试次数和成功率数字。**
2. 实际做法：按减法方向生成（海滩人物 = 首帧，地球 = 尾帧，镜头拉远），要「太空落到海滩」的效果就后期把视频**反转**，再加 **speed ramp**。（这条出自画面上 Qwen 筛选器的输出，口播只说了「反过来试了一下，一下就成功了」）
3. 两张图摆在面前有时看不出是加法还是减法，所以他做了一个「首尾帧筛选器」：把首尾帧丢给它，它会告诉你加法还是减法、哪张放第一帧、值不值得跑，「不合格的直接不跑」。（语音 1:50–2:09）
4. 完整流程：筛选器通过 → 把首尾帧丢进「地球转场指令生成器」→ 拿到指令放进你用的视频生成器。（语音 2:09–2:22）
5. 拿到指令后「还是要自己先过一遍」：他第一次生成的「云的这个遮盖效果看起来就很假」，第二次生成时「把那段描述删了」，第二次「好了很多」。（语音 2:22–2:34）**删后的完整提示词画面没给全。**

### 提示词要点（原文在视频画面上）

- **首尾帧筛选器**（千问「编辑指令」，画面 1:55–1:58，只露出一部分）：给它两张图（Frame A、Frame B），它判断两帧之间的运动是加法还是减法、哪张放第一帧、值不值得跑、值得跑的话怎么跑。露出来的第一个维度是「画面信息密度」：主体数量和复杂度、环境细节层次、前中远景的信息分布、有没有要 AI 凭空生成的大面积未知区域；后面的维度没露出来。完整指令视频里没给。
- **筛选器的两次输出**（Qwen3-Max-Thinking，画面 2:02–2:10）：
  - 地球俯瞰 → 地面上背对镜头的人：判成加法（AI 要一路补出地面细节），建议反过来放、按减法生成，要「从地球落到地面」就后期反转再加 speed ramp；总分 6.0 / 10，结论「跑」。
  - 海滩人物背影 → 地球：判成减法，两帧共享「海 / 海岸线」这个天然连接件；总分 7.0 / 10，结论「跑」。
  - 两次都附了「怎么跑更稳」（起始帧主体和路径清楚、留一个中间路标、时长 2–3 秒别硬拉）和「风险提醒」（拉远途中冒出不合理的建筑或地形、天地衔接或云层过渡处纹理跳变、人物提前消失或变形）。
- **「地球推进镜头」指令生成器的输出**（画面 2:12–2:17，输入「海滩人为第一帧，地球为第二帧」）：结构是「写实电影感、单镜头、不跳切不传送 → 开场 → 镜头运动 → 云层遮罩转场 → 按顺序必须出现的路标」。画面上写的是推进（zoom-in），和下面实际用的拉远方向相反，视频没解释两者的关系。
- **实际放进可灵 3.0 的提示词**（首尾帧，首帧 = 海滩人物，尾帧 = 地球，画面 2:20–2:24）：同样的结构，写成拉远（zoom-out）：开场写清人物的样子 → 平滑拉远、逐渐加速 → 低空路标至少 1 秒 → 穿云时短暂遮挡、镜头不停 → 结尾地球完整入镜；再加一行速度曲线（起始慢 → 加速 → 云层时最快 → 进太空后略减速）和约束（不切镜头、不闪白、不跳帧、不出现飞行器、不出文字水印）。
参数（画面）：Kling 3.0 · 标准 · 自适应 · 8s；第二次生成是 7s。

### 判断标准 / 检查方法
- 加法还是减法：看哪一帧信息更多、更具体。从信息少的帧生成到信息多的帧是加法，风险高；反过来是减法，更稳。
- 筛选器的打分维度：维度一「画面信息密度」（4 条见上）；维度二画面没露出来。输出里还用到「空间层级（近景/具体/地面 ↔ 远景/抽象/高空）」和「两帧有没有共享的天然连接件（如海岸线）」。
- 生成前人工通读指令；生成后看遮挡效果（云层蒙版）假不假，假就删掉那段描述再跑。

### 工具 / 模型
- 千问 Qwen3-Max-Thinking（用「项目 + 编辑指令」做了「总控」= 筛选器，和「地球推进镜头」= 指令生成器两个项目）
- 可灵 Kling 3.0 首尾帧，跑在一个节点画布工具里；画布名称左上角只露出「…ema Lab (copy)」，**视频没说是哪个平台**
- 原效果出自 Higgsfield（画面上的预设名是「EARTH ZOOM OUT」）
- 离开具体工具能不能做：筛选器只是一段 LLM 指令，换任何能看图的模型都能用；生成用的是普通首尾帧，反转和 speed ramp 在任何剪辑软件里都能做。没看到离开某个工具就做不了的步骤。

### 讲了多少
- 核心就一条「按减法方向生成再倒放」，外加一个说得出维度的筛选思路。筛选器指令视频里只露了一部分。

## 2. 刺猬星球super-i《全网独家！一招解决AI视频续写穿帮！》

- 链接：https://www.bilibili.com/video/BV1LjVZ6REMD
- 时长：1:55（竖屏 720×1280）
- 转写质量：口播清楚（「Seedance 2.0」被转成「SIGNES 2.0」，画面上写的是 seedance2.0）

### 作者讲的方法

先说为什么首尾帧不行（语音 0:16–0:36）：首尾帧「是在强行把两个独立生成的视频拼在一起」，首尾画面虽然一样，但运动状态不一样，「第一段视频的最后一帧是运动中的结果，第二段视频的第一帧是重新生成的开始」，所以接起来会有明显的停顿感。

1. **视频延展法**（语音 0:39–0:59）
   - 用视频（而不是图片）去延续画面，因为「图片只能记录一个瞬间，视频记录的是完整的运动过程」。
   - 截取上个视频结尾的 3 秒，直接丢给 Seedance 2.0，「再把需要的信息写给它」。
   - 画面上实际上传的片段标着 2.1s，不是 3 秒。用的是 Seedance 2.0 的「多模态参考视频编辑」模式，720P，16:9。
   - 作者的评价：「如果你不在乎积分的消耗，这个方法确实不错。」
2. **故事版**（语音 0:59–1:12）：工具只能生成 15 秒，就别把一个长镜头硬拆成好几段，「直接在分镜阶段把镜头都设计成 15 秒以内能完成的小剧情」，这样不卡顿，节奏感也更好。
   - 画面：在 ChatGPT 5.5 Thinking 里贴剧本，输入「帮我把脚本按照15秒为一个故事版生成」。
3. **动作重叠法**（语音 1:15–1:32）：第二段视频开头不要直接进新剧情，先重复上一段最后的动作，比如上一段结尾是人物转头，下一段开头就让她继续完成这个转头，再进新剧情。这样剪辑时「就能找到一个更顺的衔接点」。
   - 画面：可灵 V3 Omni，图生视频，上传图片 1 张。
4. **直接剪掉**（语音 1:32–1:45）：两段中间卡了一下就不要硬修，「直接把卡顿的那一帧剪掉，必要的时候再加一点点运动模糊，或者一个转场」。作者原话：「但这个方法不能商用。」**为什么不能商用，视频没讲。**
   - 画面：在剪辑软件时间线上剪掉衔接处（界面像剪映，视频没说是哪个软件）。

### 提示词原文
- 视频延展法，Seedance 2.0 输入框（画面 0:55–0:56；右侧被裁掉，每行行尾都缺字）：
  ```
  帮我按照这个视频持续做下去，提示词是完整中文图[…]
  古装剧电影感镜头。身着白底金纹华丽古装、头戴精[…]
  光影幽暗的宫室中。她似乎突然听到了屏风后传来的[…]
  缓慢地向她的面部推进，浅景深。在第1至2秒，她的[…]
  不易察觉地轻咽一下，流露出内心的极度警觉；第3秒[…]
  地向侧方偏转一毫米以凝聚听力，双肩因紧张而微微[…]
  产生极其细微的摇曳；第4至5秒，她迅速收敛情绪，[…]
  与克制，仿佛将秘密压在心底，整个人静止在一种蓄[…]
  ```
- 故事版，ChatGPT 输入（画面 1:07）：`帮我把脚本按照15秒为一个故事版生成`
- 动作重叠法，可灵 V3 Omni 输入（画面 1:28）：`人物向镜头左边转头过去，然后四下看了看站起来走了`

### 判断标准 / 检查方法
视频没给检查方法。只在演示里放了「拼接效果」对比，说首尾帧那段「中间就会出现明显的停顿感」。

### 工具 / 模型
- Seedance 2.0（多模态参考视频编辑）、可灵 V3 Omni（图生视频）、ChatGPT 5.5 Thinking、剪辑软件
- 节点画布是哪个平台，**视频没说明**
- 离开工具就做不了：视频延展法要求模型能接收视频作为参考（演示里是 Seedance 2.0 的视频参考模式），只支持图片首尾帧的模型做不了。其余三条和工具无关。

### 讲了多少
- 4 个方法每个只有一两句话，没有参数，也没有检查标准。最具体的是「截上一段结尾 2–3 秒视频当参考续写」和「下一段开头重复上一段最后的动作」。

## 3. 无名NonameS《我用AI复刻了3种苹果发布会的神级无缝转场！》

### 作者讲的方法

**① 钻入式转场**（镜头直接往东西里面钻）
1. 准备两个画面：一个是要钻进去的地方，一个是进去之后看到的画面。（语音 0:25–0:28）
2. 用 LibTV 的画板把这两个画面用 AI 首尾帧连起来。「提示词别乱写，重点是把镜头怎么钻进去描述清楚。」（语音 0:28–0:38）
3. 演示：首帧 = 深色木质竖条纹格栅墙，尾帧 = 台灯下看书的人；模型 Kling O3，智能 · 标准 · 5s。
4. 作者举的可以钻的东西：包、钢琴、相机。

**② 玩具屋转场**（语音 0:56–1:35）
1. 准备三段素材：
   - 素材一：拍一个用来转场的物体（画面是用手机实拍桌上的相机）；
   - 素材二：绕到这个物体后面，再拍一张物体背后的画面；
   - 素材三：俯拍房间全景，后面要做成玩具屋一样的微缩场景。
2. 把素材三截一帧，在 LibTV 画板里用图片模型改成微缩景观（Lib Nano Pro，自适应 · 2K）。
3. 把微缩房间放进素材二的场景里（Lib Nano 2，自适应 · 2K，一次出 4 张）。

5. 把素材简单拼接到一起。
6. 作者说这个玩法可以拿来做循环视频，「一层一层往里绕，做出那种一直走不完的感觉」。

**③ 空间平移转场**（语音 1:38–1:46）：任意两段视频截出首尾帧，套他的提示词。演示：首帧 = 房间里拿着鸡腿的人，尾帧 = 另一个房间的人；模型 Hailuo 02，自适应 · 1080P · 6s。

## 4. 地质大学博士说AI《AI运镜小课堂-如何彻底消除首尾帧视频的"刹车感"》

- 链接：https://www.bilibili.com/video/BV16fEgztEYt
- 时长：2:21（口播到 1:39 就结束了，后面是无口播的案例展示；Whisper 在这段出了幻觉，以画面为准）
- 转写质量：前 1:39 清楚（Sora 的「Blend」被转成「brand」）

### 作者讲的方法
- 定义（语音 0:13–0:21）：刹车感是拼接不同首尾帧素材时，「因为素材之间的运动速度、方向差异，导致衔接处明显的停顿」。
- 如果只是速度不同，可以「通过贝塞尔曲线调整播放速度」来救（画面是剪映「曲线变速」面板）；但通常不同素材的方向、内容也不一样，「所以刹车感用拼接的方法无解」。（语音 0:21–0:33）

步骤（语音 0:43–1:16，画面是 sora.chatgpt.com 和剪映）：

## 6. 栗子也该开点脑洞《AI视频拼接的详细教程 | AI动漫新手教程》

- 链接：https://www.bilibili.com/video/BV15B766nELy
- 时长：18:14
- 转写质量：大部分清楚（Seedance 被转成「C-Dance / Cdance」，「切镜」被转成「切近」）；17:20–17:50 案例对白那段 Whisper 出了乱码，以画面为准

### 作者讲的方法

**问题演示**（0:13–1:00）
- 例 1：用上一条的尾帧当下一条的首帧，衔接处「整个画面跳切了一下」——「这个思路是不正确的」。
- 例 2：拼接感明显，原因是「人物动作没有做衔接，人物对白没有留气口」。

**核心观点**（1:36–4:22）
- 「下一个 15 秒是没有前面 N 个 15 秒的任何数据的」，所以要「把下一个阶段的完整数据都呈现给 AI」。
- 例子：第一段结尾女儿从坐着站了起来，那么做下一段时，女儿的状态要更新成站着；母亲跟她说话时要抬头，面朝方向也会变。作者为此做了一张新的参考图（女儿站着、母亲坐着回头），「方便 AI 去进行空间位置关系的理解」，再按剧本跑下一段。
- 数据分两类：
  - **基础数据**（不变）：人物资产图（三视图）、场景图，照样传入；
  - **变动数据**：人物站位、身高比例、与场景的交互等。具体形式是提示词、图片、视频、音频，取决于模型能接收哪些输入；最常用的是提示词和图片。
- 关键是「在每一个视频中精确输入变动数据」。很多人只写提示词不做图片，「缺少了图片就是一条腿走路」。

**技术手段**（画面总结页：1. 做分镜图 2. 拼接处切镜 3. 去 BGM 与字幕）

1. **做分镜图（优化变动数据 = 写好提示词 + 做好图片）**：「你做了分镜图，你才可以控制对应的画面」。
2. **拼接处切镜**（6:04–8:17）
   - 切镜 = 换一个机位角度，把两段视频连接在一起。「我们在拼接处一定要使用切镜。」
   - 拿尾帧当下一段首帧，和切镜的思路「恰恰相反」：你想把衔接处拼成一个完整的镜头，作者建议做成两个镜头。
   - 原因：参考图不是被 AI 直接拿来用的，而是「理解数据之后重新生成的」，所以会和原图有细微差别，放在一个连贯镜头里就会出现明显的跳切感。
   - 怎么做下一段的分镜图（两种都行）：(a) 用生图模型，输入三视图 + 场景图来做；(b) 抽取 Seedance 2.0 视频里对应的帧，再用图生图修改。
   - 抽帧注意：「最好不要用一些截图工具去操作，因为截图工具本身它会压缩图片」，会把纹理压掉。画面：「抽帧：不损失画质，是视频本身的原始像素」「截图：分辨率、可能会压缩」。她用的是小云雀故事板里的抽帧工具（截取当前帧 / 截取片段首帧 / 截取片段尾帧），抽完直接传入无限画布，「方便二次改图」。
3. **去 BGM 与字幕**（8:21–9:06）
   - 提示词里写明「不要字幕、不要BGM」。
   - 带字幕的片段「大部分情况下只能扔垃圾桶」；带 BGM 的话，「音效会被一起剥离，还要单独做音效」。
   - 如果还是生成了字幕：小云雀有去字幕功能（画面上的按钮像是「智能擦字幕」），作者评价「几乎看不出原本有字幕的存在…远远超出了我个人的意料」。

**导演思维**（画面总结页：1. 相邻景别不切景 2. 安全角度 30° 3. 过渡镜头 4. 留气口接动作 5. 动作匹配剪辑）

1. **相邻景别不切镜**（9:29–10:25）：五个景别是远景 / 全景（人物全身入画）/ 中景（膝盖以上）/ 近景（胸部以上）/ 特写（局部）。相邻景别通常不切，比如中景切近景「可以，但是同样会让你的画面会有一个跳切感」。中景的下一个镜头「最好直接给到一个特写」。
2. **切镜角度 > 30°**（10:26–10:55）：切镜时，摄像机水平视角至少转 30 度，小于 30 度观众会觉得跳切。30 度叫「安全角度 / 安全镜头」，也可以更大，比如 45 度、90 度。
3. **使用过渡镜头**（10:56–12:58）
   - 在母女争执的剧情里加一只猫：输入视频提示词给 Seedance，得到一段完整的 5 秒猫视频，再手动切成两段（第一段抬头，第二段打哈欠）分别插进去。
   - 为了不让猫的画面太枯燥，作者把画面截掉了一部分，并且「放到猫猫的画面时让声音同步入画」；不这样做的话，「整个画面的割裂感一下就上来了」。
   - **猫的视频提示词原文视频没给**，画面上只有「视频提示词」四个字。
4. **留下气口**（12:59–13:50）
   - 气口 = 台词之间的停顿。第一个和最后一个镜头都要「留下一点余地」（画面：「在尾巴或者开头留空白」）。
   - 检查：把上一段放进剪辑软件，看到「声音波峰戛然而止」，就意味着下一段开头必须留气口；不留的话，「人物没留气口直接开讲，画面感觉很糟糕」。
   - 正确做法：先做下一段的分镜图，再写提示词，开头「特意留下了一个动作衔接以及不说台词的气口」，得到一段 6 秒的衔接画面（提示词见下）。
5. **动作匹配剪辑**（14:20–15:00）：前一段结尾，人物动作只做了一半；下一个镜头对着别的主体完成后半段，「这个后半段也可以只是肢体的部分，就像我这里的一条腿」。演示是女生抬腿，切到男生特写时腿已经踢到他脑门上（画面标着 X0.3 倍速）。

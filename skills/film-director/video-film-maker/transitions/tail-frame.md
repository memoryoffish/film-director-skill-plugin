# 尾帧怎么挑（接龙之前先检查这一帧）

一句话：拿 A 的一帧当 B 的首帧之前，先确认这一帧装得下 B 要的东西、人是停住的、声音没切在半句；随手拖到最后一帧，B 只能靠猜。

四问只从视频学来（82年の汽水），未单独实测；「首帧带运动线索」一条是我们的实验观察。

## 四问

1. **下一段要出现的东西，都在框里吗？** 脸、全身、手里的道具。不在，模型就自己编，「编出来的脸，大概率不像她」。不行就用**再前一镜（A 前面那一镜）的末帧**，甚至调镜头顺序。
2. **这张脸是停住的还是半截的？** 从末尾往回退 0.05 / 0.4 / 0.8 秒比较，AI 视频里「还在动的常常是表情，不是身体」。
3. **手里那个东西完整吗？** 被切掉一半，下一段会把它猜成别的东西。
4. **声音切在句子中间没有？** 比较声音结尾和画面结尾。

## 伪代码

```
for t in [end, end-0.05s, end-0.4s, end-0.8s, ...]:
    f = frame(A, t)                                   # 原始像素抽帧，不要截图（截图会压缩纹理）
    if has_all(f, B.needs) and face_still(A, t) and not mid_sentence(A.audio, t):
        return f
```

## 好用的规则

- 抽帧用原始像素，不截图。
- **首帧里要有运动线索**：首帧是正在走的人、或带运动模糊的甩镜帧，B 起步速度和 A 对得上；首帧是一片没纹理的遮挡物，B 只用一半速度起步，要后期加速补（见 [遮挡转场](occlusion.md)）。

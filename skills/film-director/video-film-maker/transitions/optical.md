# 光学类转场：闪白（光晕）、媒介转变、叠化与淡入淡出、空镜头

## 闪白（光晕）

一句话：在剪点上让画面泛起一层柔和的光晕再落回来，光晕把前后两个镜头隔开；多用在进出回忆、跳时间。不用纯白。

（示例视频：ex-flash-01.mp4，没有放进仓库。书房老人 ↔ 麦田回忆（3.0–10.87 s））

书房里的白发老人和旧怀表 ↔ 金色麦田里举着同一块怀表奔跑的小男孩（回忆） · 2 次调用 · 光晕在 4.50 秒进回忆、8.37 秒回书房

### 什么时候用
呈现脑海里的记忆碎片（回忆、梦境、幻觉）；快速闪白加音效调整节奏。

### 思路
1. #1「现在」：后半段要有回到现实后的反应（抬眼、微笑）。回来时直接用 #1 的后半段，「现在 → 回忆 → 现在」三段只花两次调用。
2. #2「回忆」：用 #1 截的人物或道具当参考图，让它们的样子不变；回忆写得亮、暖、略过曝。
3. 剪辑：光晕 = 曝光提亮 + 高光泛开 + 向暖白的径向雾，峰值不到纯白；**调用边界藏在峰值里**：峰值处直接硬切，或只叠很少几帧（叠多了看得见两层画面）。声音只用原声交叉淡化。

### 好用的规则
- 光晕峰值不到纯白；纯白太硬，别用。
- 进回忆（暗 → 亮）的光晕短，回到现实（亮 → 暗）的要比进去慢。因为从亮回到暗时，光晕一退画面就暗了，看着短。帧数见 [闪白的细节](../examples/transitions/flash/notes.md)。
- 声音里不要混进合成的风声、快门声（剪辑工具默认会加，要关掉）。

### 生成后检查（不合格就重抽）
- 回忆段里的人、道具和现在的一致。
- 两段有没有配乐（见 [生成后检查](../stages/3-generation/checks.md)）。
- 光晕峰值那几帧有没有露出两层画面：露了就减少叠化帧数，或改成硬切。
- 提示词里描述道具细节的词有没有被画成场景里的东西（表盖上的燕子飞上了天）：道具交给参考图，提示词少写细节。

## 媒介转变（media change）

一句话：从照片、画、电视屏幕这类媒介里的画面转到实景：镜头推近媒介，画面活过来成了真实场景；反过来从实景变成照片也算，正好做首尾呼应。

（示例视频：ex-media-change-01.mp4，没有放进仓库。美术馆风车油画活过来（2.2–10.2 s））

美术馆白墙上的风车麦田油画，推近后活过来成了真的麦田 · 2 次调用（#2 续写 #1） · 转场在 2.60 秒

### 什么时候用
照片、画、屏幕里的画面变成真的；故事里的故事。例：桌上的旧照片 → 真的站台（成片开头），海边日出 → 变回桌上的照片（成片结尾），美术馆的油画 → 真的麦田。

### 思路（两次调用：推近 + 续写）
1. #1：推近媒介，媒介里的内容先写好、一切静止；结尾媒介占满画面，白边或画框开始滑出。
2. #2 续写 #1 的最后几秒（接法见 [视频续写](extension.md)）：
   - 白边、画框是**不透明的实物，只能被推出画面**，不会变透明、不会淡出。
   - 「活过来」写成**同一个画面里的逐渐变化**：真实感从画面一角（最下方）开始一路蔓延，始终只有一个画面、没有两层、没有重影。媒介越风格化（厚涂油画比照片难）越要这样写。
   - 要换景别时，**靠镜头连续后拉完成**，不是叠化。
3. 反过来（实景 → 照片）：续写，镜头连续后拉、升高，画面四周出现相纸白边，整幅画面停住成了一张照片，再继续后拉露出书桌。

### 好用的规则
- 换景别给一个连续的镜头运动，不给就会整幅叠化。
- #2 的动作照 #1 **实际**生成的写（照片里的人已经提着东西在走，就写「提着」，不写「提起」）。
- #1 **默认提前结束**：续写常把输入放慢重画：常常是 #1 最后约 1 秒对不上，也见过喂进去 3 秒、复述段只有开头约 1 秒和 #1 对得上（风车油画换种子的那 4 次都这样）；#1 就剪在还对得上的最后一帧。
- 准备多抽几次：「变」得干净的不多。
- 别写「一条分界线往上扫」：会变成划变，线上线下是两个不一样的画面。

### 生成后检查（不合格就重抽）
- 「变」是局部、逐渐的（从下往上蔓延、颜色慢慢变真、白边滑出），还是**整幅两层画面同时半透明**（画的叶片和真叶片叠着、白边半透明地叠在画面上、近景叠化成远景）：后者就重抽。转动的东西刚转起来时一点局部重影可以。
- 变完整幅都变真了没有（只有近处变真、天空还是画）。
- 续写接缝：复述段对得上 #1 吗；接过去镜头还在推吗（快停住就不行，门槛见 [refs/practical/config-transitions.md](../refs/practical/config-transitions.md)「媒介转变续写后停住」）。
- 转动的部件（风车叶片）变真时没有淡掉、数目没变；一个东西两层叠着太久就重抽。

## 叠化与淡入淡出（dissolve / fade to black / shape dissolve）

一句话：叠化是 A 慢慢消失、B 同时出现；淡出淡入是 A 渐暗到全黑、停一下、B 再从黑里亮起，分隔感更强；形状叠化是叠化的两段主体形状、位置、大小相近，交叠时像一个东西变成另一个。○，时间流逝、蒙太奇时用。

- 叠化：第 k 帧 = (1−a)·A + a·B，a 线性从 0 到 1；声音按同样时长交叉淡化。
- 淡出淡入：亮度线性乘到 0 → 插几帧纯黑 → 线性乘回 1；声音跟着画面，全黑时静音。
- 形状叠化：两段主体都写居中、同样大小、固定机位；逐帧找两边的形状，把 B 缩放平移到 A 的形状上，叠化完再慢慢退回原样。
- 时长、帧数的默认值见 [refs/practical/config-transitions.md](../refs/practical/config-transitions.md)「光学类」。形状叠化要查两边主体的大小、位置差多少，还要查写了固定机位的画面有没有在慢慢移动。

## 空镜头（cutaway / empty shot）

一句话：两场戏之间插一个没有人物的景物镜头，交代时间或地点变了，也让节奏喘口气。少用。

- 第一场结尾让人物出画，切在出画时。
- 空镜写明没有人；交代新的时间、地点（夜 → 清晨、城市 → 海边小镇）。
- 第二场就在空镜交代的地方。
- 两处都硬切，声音短短交叉一下（默认值见 [refs/practical/config-transitions.md](../refs/practical/config-transitions.md)「光学类」）。

# transitions：接法库（分镜时挑，生成时照着拍）

两次生成调用（两个 clip）之间怎么接。分镜时把全片的接缝过一遍：同一场戏里大多硬切；换场、换时间、进出回忆、首尾呼应这些地方，在这里挑接法，写进 [镜头表](../stages/1-storyboard/shot-list.md)「接」一列。先看 [movie](movie.md) 第 0 节「什么场景用哪种接法」那张表，再读挑中的那几篇。

- 剪辑里做的接法（切镜拼接、动作匹配、动势剪辑、声音转场）在 [4-edit](../stages/4-edit/overview.md)。
- 模型自带的切镜怎么管、怎么查，在 [3-generation/own-cuts](../stages/3-generation/own-cuts.md)。
- 每篇都有生成后检查和「动手前查」。案例在 [examples/transitions/<方法>/](../examples/transitions/overview.md)，每种方法一个文件夹；细节（伪代码、具体数字、试过不好的做法）在同一个文件夹的 `notes.md` 里。检查门槛在 [config-transitions](../refs/practical/config-transitions.md)「衔接检查」。

## 什么情况用哪种

- 什么场景用哪种接法，一张表在 [movie](movie.md) 第 0 节。
- 这里的接法在分镜时定，不在剪辑时定：生成那一步要照它的要求拍（遮挡物几秒盖满；要续写的，上一段结尾留几秒给下一段当输入），拍完再想就来不及了。
- 调用边界用遮挡、续写、匹配剪辑藏住；接缝要用的那几秒里不能有模型自带的切镜。
- 一种接法做主干，两三种点缀，首尾呼应；剧情片的接缝大多是单元之间的切镜。见 [movie](movie.md)。

## 按类型

- 旅程、一镜到底：遮挡做主干；色彩匹配、声音搭桥点缀；首尾用媒介转变呼应。
- 动作、打斗：单元之间剪在动作上（动作匹配、动势）；首尾可以用遮挡。
- 悬疑：连续动作接力做主干（动作匹配、续写、穿门洞）；点缀全用声音类接法（反差转场、J-cut、声音搭桥）。
- 科幻、大场面：首尾帧过渡段做主干，在满屏的云里接；续写、图形匹配点缀。
- 回忆：光晕、媒介转变进出。
- 二维动画：续写做主干。

## 文件

藏住剪点：
- [occlusion.md](occlusion.md)：遮挡转场。大物体贴着镜头盖满画面，剪点藏在盖满的那几帧里。
- [doorway.md](doorway.md)：穿门洞。走进越走越暗的过道，接缝藏在暗处，推开门出来就是新地方。
- [zoom-through.md](zoom-through.md)：推镜穿越。冲向隧道尽头的光，急速放大加径向模糊。
- [whip-pan.md](whip-pan.md)：甩镜（少用）。

接着拍：
- [extension.md](extension.md)：视频续写。把上一段最后几秒喂给模型接着拍；连续走得到的新地点也行。
- [tail-frame.md](tail-frame.md)：接龙前，尾帧怎么挑。

跨空间 / 时间：
- [bridge.md](bridge.md)：首尾帧过渡段。两地差得远时单独生成中间的运镜，拆成几次调用。
- [optical.md](optical.md)：光学类。媒介转变、闪白（光晕）、叠化与淡入淡出、空镜头。

形状 / 颜色：
- [match-cut.md](match-cut.md)：匹配剪辑。图形匹配、色彩匹配。
- [extremes.md](extremes.md)：两极镜头、特写转场（少用）。

怎么搭配：
- [movie.md](movie.md)：什么场景用哪种接法（★ 首选 / ○ 看场景）；一种做主干，几种点缀，首尾呼应；每次调用在 plan 里写清时间线和接法。

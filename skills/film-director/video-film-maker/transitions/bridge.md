# 首尾帧过渡段（两个地方之间，让镜头真的「走」过去）

一句话：两个地点差得很远时，单独生成中间那段运镜（升空、穿云、降落、钻进物体），让镜头真的走过去；每个调用边界要么帧级一致（下一次的首帧 = 上一次的最后一帧），要么藏在满屏的云、雾里。

（示例视频：ex-bridge-01.mp4，没有放进仓库。晨雾松林 → 云海 → 雪山顶（0.5–4.5 s））

晨雾松林 → 升过树冠到云海之上 → 扎进云里 → 落到日出雪山顶 · 3 次调用 · 调用边界在 2.00 秒、9.97 秒（满屏的云里）

## 什么时候用

- 跨越很大的空间：地面 ↔ 天空、城里 ↔ 海边。
- 想要设计感强的转场（这几种只从教学视频学来，未实测；前三种的提示词见案例细节「苹果式三种」）：钻进物体（镜头钻进一面格栅墙、一个包或一架钢琴，穿过它的内部，出来就是新场景）、微缩房间（镜头绕到一个物体背后，那里是一个模型一样的小房间）、穿过地板（镜头垂直往下穿过楼板，从二楼到一楼）、从地面拉到太空（从海滩上的人一路拉远到整个地球；要反过来落下来，见下面「好用的规则」里的倒放）。

## 思路

一次「首帧 + 尾帧」两头差别大时，模型常在中间偷偷叠化来凑尾帧，过渡就没了。所以**拆成几次调用、只给首帧**：

1. **#1 起点**。结尾不必已经在上升。
2. **#2 首帧 = #1 最后一帧，只给首帧**：镜头真的升上去、飞过云层，**结尾一头扎进云里、满屏是云**。
3. **#3 落到终点**：
   - 不需要人物不变时：#3 首帧 = #2 满屏是云的最后一帧，边界帧级一致，不用叠化。
   - 要让前面出现过的人保持不变时：#3 用人物参考图，第一帧写「一片云」，#2 → #3 在满屏的云里叠化几帧。
   - 从一片没纹理的云起步，#3 开头会几乎不动：开头加速，或首帧挑云还在往前冲、有纹理的那一帧。云在原地散开、露出下面，是画面里的变化，可以用。
4. 拼：首帧接的那一段从第 1 帧起（第 0 帧就是上一段的最后一帧）。

## 好用的规则

- 两头差别大就拆：**过渡调用只给首帧，不给尾帧**。要接的两段已经做好、过渡必须落到后一段的第一帧时，只能首尾帧都给、一次生成：实测成过一次（公园 → 天上 → 海边，接得很顺），也有两次在中间偷偷叠化；生成后照下面查有没有两层半透明，有就重抽。
- #2 结尾留一小段**满屏是云**（或雾、烟、水下气泡），下一次调用从这里接。
- 从信息少的画面生成到信息多的画面（太空 → 海滩）风险高。要「落下来」，就生成「拉远」再**倒放**；两头的画面里要有同一样东西把它们连起来（如海岸线）。
- 提示词只写**镜头怎么走过去**和中间经过什么。

## 生成后检查（不合格就重抽）

- 过渡调用的中间有没有**两个画面同时半透明**（人影在云里浮现、和终点叠在一起）：有就是被叠化掉了，重抽或再拆。
- #2 结尾是否真的满屏是云（漏出天空、地面就接不住）。
- #3 开头是否长时间不动：加速补；补不回来就换首帧那一帧。
- 要人物不变时，人物前后一致。

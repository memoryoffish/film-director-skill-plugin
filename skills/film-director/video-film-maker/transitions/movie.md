# 衔接怎么搭配：一个方法做主干，几种方法点缀，首尾呼应

一句话：一部片里的转场不要每个都换花样。选一种方法贯穿全片当主干，在几个关键节点换用别的方法，开头和结尾用同一种（或镜像的）方法前后呼应。拍什么类型选什么主干，先看 [GUIDE.md](../GUIDE.md) 的类型表；这一篇讲衔接本身怎么搭。

## 0. 什么场景用哪种接法

★ 首选，直接用；○ 看场景用，满足条件才好用。一格里写了两种方法、两个记号的，前一种方法对前一个记号，后一种对后一个。

| 场景 | 用哪个 | 优先级 |
|---|---|---|
| 一个人一路走过好几个地方，想要一镜到底的感觉 | [遮挡转场](occlusion.md) | ★ |
| 同一地点的连续动作被单次时长拆开；连续走得到的新地点 | [视频续写](extension.md) | ★ |
| 同一场景换机位或景别，接着做同一个动作 | [动作匹配](../stages/4-edit/match-on-action.md) | ★ |
| 一场戏很多镜头（剧情片、动作片） | [分镜单元](../stages/3-generation/shot-unit.md)，单元之间[切镜拼接](../stages/4-edit/cut-not-chain.md) | ★ |
| 跨越很大的空间：地面 ↔ 天空、城里 ↔ 海边 | [首尾帧过渡段](bridge.md)（两头差别大就拆成几次调用） | ★ |
| 照片、画、屏幕里的画面变成真的；故事里的故事 | [媒介转变](optical.md) | ★ |
| 进出回忆、时间跳跃 | [闪白](optical.md)（光晕，不用纯白；从亮回到暗时更长）；叠化与淡入淡出 | ★ / ○ |
| 前后两个地方有满屏的同一种颜色，或相似的形状 | [色彩匹配](match-cut.md)；图形匹配 | ★ / ○ |
| 前一段有个响亮的声音，后一段能接上相似的声音 | [声音搭桥](../stages/4-edit/sound.md)；声音延续到下一段画面用 L-cut | ★ / ○ |
| 走进门洞、隧道、暗巷，从另一头出来到新地方 | [穿门洞](doorway.md)；[推镜穿越](zoom-through.md)：镜头跟在主体身后、隧道要长 | ○ |
| 同一个人、景别和角度都相近的两个镜头 | [动势剪辑](../stages/4-edit/momentum.md)：视角要明显变、两边都在动 | ○ |
| 从极静到极吵（或反过来）的情绪转折 | 反差转场（[声音类](../stages/4-edit/sound.md)）：情绪上说得通才用 | ○ |
| 任何一次接龙之前、拼好之后 | [尾帧怎么挑](tail-frame.md)；[查接缝附近有没有模型自带切镜](../stages/3-generation/own-cuts.md) | 必做 |

少用：[甩镜](whip-pan.md)、[两极镜头](extremes.md)、J-cut（悬疑片例外：可以和反差转场、声音搭桥一起当声音类点缀，见 [接法库](overview.md)「按类型」）、空镜头。

## 1. 主干、点缀、首尾呼应

- **主干看片子是什么**：旅程、一镜到底感用 [遮挡](occlusion.md)；同一场景的连续动作用 [续写](extension.md)，换机位用 [动作匹配](../stages/4-edit/match-on-action.md)；回忆、故事里的故事用 [媒介转变、闪白](optical.md)；大空间跨越用 [首尾帧过渡段](bridge.md)；剧情片、动作片用 [分镜单元](../stages/3-generation/shot-unit.md)，单元之间切镜。
- 旅程类的主干占全片转场的一半以上。剧情片、动作片的接缝大多是单元之间的切镜，专门做的转场只放在换场、进出回忆这些节点上。
- **点缀放在节点上**：时间跳跃用闪白、叠化；情绪或空间转折用声音搭桥；画面呼应用色彩匹配、图形匹配。
- **首尾呼应**：开头和结尾用同一种（或镜像的）接法，比如「照片 → 实景」对「实景 → 照片」、开头闪白进回忆对结尾闪白回现实。

## 2. Plan：每次调用一个条目，生成后检查接缝

先按 [时长预算](../stages/1-storyboard/shot-list.md) 排好每段几秒，再每段写清：
- **时长**（不超过单次上限）和**时间线**：几秒到几秒发生什么，衔接用的东西几秒出现。
- **和前后怎么接**：遮挡 / 色彩 / 续写 / 首帧 / 参考图，以及衔接窗口。
- **生成后检查**：按每种接法那篇的「生成后检查」查它参与的接缝；不合格换种子重抽；重抽次数到了上限（上限在 config 里）还不行，就停下来报告。

## 好用的规则

- 专门做的转场别太密（一分钟几个见 [时长预算](../stages/1-storyboard/shot-list.md)）；相邻两次不用同一种点缀；点缀的种类不超过三种。
- plan 里写上目标时长，拼片脚本才会把成片截到这个时长（不写的话片子会长出几秒）。
- 自动检查抓不到整幅叠化和同色叠化，接缝两侧还要人眼逐帧看。
- 全片一致：每段用同一组人物参考图；镜头运动方向全片统一；没有台词的段，提示词里写不要音乐和人声（有台词见 [台词](../stages/3-generation/dialogue.md)），要配乐就后期统一加；片段中间模型自己的切镜可以留，接缝附近不行（见 [模型自带的切镜](../stages/3-generation/own-cuts.md)）。

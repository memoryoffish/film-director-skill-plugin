# 用了白模：分镜这一步多做的

一句话：镜头表「空间」一栏填了「上白模」的戏，排完镜头表先把这场戏搭成白模、自己看明白，再把白模里量出来的东西填回镜头表；后面三步照的是填回去以后的表。要有 blender-previz skill。

## 什么时候用

- [镜头表](../shot-list.md)「空间」一栏有镜头写了「上白模」。全填「只用文字」的片子不看这一篇。
- 值得上白模的镜头：俯、仰、贴地这类特殊角度；过肩和正反打要换边；同一个地方连着几个机位；人和道具、门的相对位置有讲究；揭示和视线；人和巨物的大小比。平视、两三个人、常规动作的镜头只用文字就拍得对，不上。

## 思路

1. **镜头表先照常排完。**「空间」一栏开头写下的那两三件最容易错的事，就是白模要管的事。
2. **一场戏搭一个场景**，所有镜头的机位都架在里面。镜头表里反复出现的机位，在白模里是同一台。
3. **出平面图和每镜的首帧静帧，逐张看。** 查越轴、视线、间距。静帧看不懂的镜头，成片也拍不对：先改镜头表，不往下走。
   也查人偶做不做得到：关节有没有反着弯，手去够的东西是不是在身前、够不够得着（blender-previz 的「查人偶的关节、朝向和手」）。人确实做不到的，在剧本和镜头表里补一个过渡动作（先转过身、先站起来、先走近一步）或一个状态变化（东西先放到够得着的地方），让它做得到；镜头表「状态」一列跟着改。
4. **把白模里量出来的填回镜头表**：
   - 「画面」：左右、朝向照白模念出来的站位句子逐字写，不凭印象；反打换边的镜头写明「现在阿杰在画面右边」。
   - 「状态」：白模会列出每镜开头和结尾哪里变了，照它排。白模里没有的东西（包在哪一侧肩上、耳机摘了哪一只）自己补进这一列。
   - 「空间」：每个上白模的镜头再写一句怎么喂（关键帧当首帧、首帧 + 尾帧、放进分镜单元、替身预演当参考视频），开头和结尾有变化的镜头标上要出尾帧。
   - 时长：走到门口要几秒在白模里量；镜头给的时间不够动作做完，改镜头表。
5. **再照 [镜头表](../shot-list.md)「排完检查」查一遍**，然后进定妆。

```
scene = build(这场戏)                                    # 一个场景，所有机位
for shot in 上白模的镜头:
    still[shot] = render_first_frame(scene, shot); look(still[shot])
    shot_list[shot].画面 = describe(scene, shot)          # 左右、朝向照它写
    if changes(scene, shot): shot_list[shot].空间 += "要出尾帧"
shot_list.状态 = state_table(changes(scene), 白模里没有的小道具)
```

## 好用的规则

- 打斗和连续的肢体戏：白模只定每一招开始和结束时两人在哪、谁在左谁在右，写进「画面」；不为它出首帧关键帧。
- 观众没见过的东西别直接上特写：中间补一个交代的全景，机位在白模里试。
- 出静帧、渲预演是重活：开工前定 Blender 在哪台机器上跑，有服务器就放服务器；没人回答时见 [规矩](../../common/rules.md)「没人回答时」。

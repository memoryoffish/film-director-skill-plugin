# 关键时刻（片子靠哪一刻被看懂）

一句话：每部片都有一两刻撑着全片的意思。先写观众必须看懂什么，再找靠哪个细节看懂；看着简单、却要拍得准的细节默认算冒险：给它一个只拍它的大特写，状态的变化放在两镜之间的剪点上。这一刻比全片其他镜头先拍，几种拍法并排比，都不行就回到节拍换一种讲法。

## 什么时候用

节拍排好、设计镜头之前，定下关键时刻是哪一两刻；镜头表写完，按这里再查一遍；生成时最先拍这几镜。

## 思路

1. **先写意思，再写细节**：节拍里先写观众必须看懂的那件事（「他本可以杀她，却停住了」），再写它靠哪个细节被看懂（篙尖停在她喉前一指）。
2. **找出要拍准的细节**，三种最难：
   - 两样东西之间的精确关系：指着哪、离多远、碰没碰到；
   - 前面的事留下的状态：劈成两半、点着没有、灯灭没灭；
   - 数量。

   这些细节不管看着多简单，都在 [能不能拍](shot-design.md) 里标冒险。花哨的大场面反而常常拍得出。
3. **给细节一个只拍它的镜头**：大特写，画面里只有那个细节（篙尖和喉咙、水面上的两半叶子）。中景只交代谁在哪、在做什么，不靠中景讲细节。
4. **状态的变化放在剪点上**：前一镜是完整的，后一镜已经是两半；不要求一个镜头里拍出变化。镜头里拍不出的变化（灯灭、蜡烛点着），交给后期，或者切到下一镜时已经变了。
5. **精确的那一帧先做成图**：用图像模型（比如 [gpt-image](../../refs/practical/gpt-image.md)，画质默认 high；用之前先问用户，要问的几项见那一篇）或修图把那一帧做准。这张图当首帧，或当首尾帧里的尾帧，让视频动起来、停在这一帧（尾帧能定下结尾的样子，定不了中间怎么动）。
6. **最先拍，并排比**：关键时刻在全片其他镜头之前拍，几种拍法各一条（上面第 3–5 步：只拍细节的大特写、把变化放在剪点上、先做成图当首帧或尾帧），在进度页上并排看，挑没看过剧本的人也看得懂的。都不行就回到节拍换一种讲法，别拍完全片再补。
7. **意思别只挂在一个镜头上**：画面、声音（一声钢鸣、一滴水）、人物的反应，三样里有两样在传达这个意思就够。

```
key = what_audience_must_get(climax_beat)               # 意思
detail = carried_by(key)                                # 靠哪个细节
if precise(detail): mark(detail.shots, "冒险")           # 关系、状态、数量
ways = [close_up_only(detail), change_at_cut(detail), keyframe_image(detail)]
takes = shoot_first(ways)                               # 在全片之前
if not any(readable_by_fresh_eyes(t) for t in takes): rewrite(climax_beat)
assert carriers(key, among=[picture, sound, reaction]) >= 2
```

## 好用的规则

- 难拍的细节不是躲开，而是拆成几个拍得出的镜头。
- 大特写里只放一件东西，写「极近：画面里只有……」（见 [提示词](../3-generation/prompts.md)）。
- 关键时刻的几镜在镜头表里标成关键镜头（见 [镜头表](shot-list.md)「关键」）。
- 关键时刻的小样，算进开工前报给用户的时间和钱的预算（见 [预算](../common/budget.md)）。

## 生成前检查

- 每个关键时刻都写得出：观众必须看懂什么、靠哪个细节。
- 要拍准的细节都标了冒险，都有只拍它的镜头。
- 状态的变化落在剪点上，或者写了后期怎么做。
- 关键时刻排在最先拍；意思至少有两样东西撑着。

## 动手前查

- [能不能拍](shot-design.md) 的难镜头清单；[refs/practical/wan3-notes.md](../../refs/practical/wan3-notes.md)「生成时常见的毛病」（变身先给局部大特写再切全貌，镜头里开关灯拍不出来）。
- 首尾帧：[首尾帧过渡段](../../transitions/bridge.md)。尾帧能定下结尾的样子（人停在哪、东西落在哪），定不了中间怎么动；首尾差得多时中间会叠化。装了 blender-previz 看它的 `stages/3-feed/first-frame.md`（哪些镜头必须加尾帧）。
- 拉片：`../../refs/background/film-refs/breakdown/creed_final/beats.md`。看击倒那一拍（「Beats」表第 6 拍，镜头 #41–43）怎么拍：全片只有倒下这一镜是慢动作；「Editing grammar」第 7、8 条：只用一处慢动作，高潮之后镜头长度翻倍。

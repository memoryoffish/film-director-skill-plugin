# 1-storyboard：分镜

剧本 → 节拍 → 镜头设计 → 能不能拍 → 定接法 → 镜头表 → 时长，生成之前做完。镜头从哪来有三种做法：从零设计、借鉴几部电影、复刻一场戏。

## 这一步交出什么

- 分段剧本和节拍。
- 镜头表：一镜一行，后面三步都对着它。见 [shot-list](shot-list.md)。
- 时长预算，加总不超目标。
- 往下走之前，照 [shot-list](shot-list.md)「排完检查」把镜头表从头到尾查一遍。

## 什么情况用哪种做法

| 情况 | 做法 | 细节 |
|---|---|---|
| 只有故事 | 从零：镜头全靠自己设计，参考只用来找感觉 | [shot-design](shot-design.md)「从零到一」 |
| 有相近的电影场面可学 | 借鉴：找几部电影里相近的场面拉片，学规律，不搬画面；可以同时学几部 | [from-films](from-films.md)「借鉴」 |
| 要对标、学习、检验 | 复刻：照搬一场戏的剧本和原片的镜头切分，人换成新面孔。原片只用来拉片和对照 | [from-films](from-films.md)「复刻」 |
| 全片靠某一刻撑着 | 先写观众必须看懂什么、靠哪个细节看懂；要拍准的细节给只拍它的大特写；状态的变化不指望一个镜头里拍出，放在两镜之间的剪点上；这几镜最先拍 | [key-moment](key-moment.md) |
| 设计一场戏的镜头 | 先交代空间再推近，守住轴线和视线，换机位换得明显，每镜只做一件事，长度快慢交替 | [shot-design](shot-design.md) |
| 镜头排完 | 生成之前先排时长预算，超了就拆段或删动作。生成以后再靠剪辑，没法把总长缩回目标 | [shot-list](shot-list.md)「时长预算」 |
| 定接法：把全片的接缝过一遍 | 同一场戏里大多硬切。换场、换时间、进出回忆、首尾呼应这几处，从接法库挑接法：一种当全片主要用的接法，另选两三种做点缀。都写进镜头表「接」一列，生成和剪辑照着做 | [接法库](../../transitions/overview.md)、[怎么搭配](../../transitions/movie.md) |
| 镜头表「空间」一栏有镜头上白模 | 排完镜头表先搭白模、自己看明白，把白模里量出来的左右、状态、喂法填回镜头表 | [blender_extra](blender_extra/overview.md) |

## 常见错和怎么查

都出在镜头表上，排完照 [shot-list](shot-list.md)「排完检查」查：一个动作演了两遍、结果先于原因、一镜塞了几个动作、跨场景接不上、定好的接法后面没做。

## 按类型

- 动作、打斗：动作拆细，一两秒一镜；撞击单独成镜，留出慢动作的时间。
- 悬疑：线索分批出现，首尾用同一件道具呼应。
- 科幻、大场面：先远后近，先交代尺度再进细节。
- 旅程：每段一个地点，人一直在走。
- 回忆：现在和过去分段写清，进出回忆的那一镜单独写。
- 剧情、多人对戏：每镜写清谁在画面左右，正反打守住轴线；台词逐字写，写清是谁说的；不要人声时，把台词改成动作。
- 照电影复刻：照原片逐镜拆开；每个单元从原片的一个切点开始，到一个切点结束。

## 用了白模（blender_extra）

镜头表「空间」一栏有镜头上白模时（要有 blender-previz skill），这一步多出来的：

- **多做的**：排完镜头表，把这场戏搭成白模，出每镜的首帧静帧逐张看；把白模里量出来的左右、状态、每镜怎么喂填回镜头表。
- **多交出的**：白模场景、每镜的首帧静帧、填回去的镜头表。
- **往下走之前**：每张静帧一眼看得懂；看不懂的镜头先改镜头表。

做法在 [blender_extra/](blender_extra/overview.md)；几步都要知道的（白模管什么、不管什么）在 [common/blender_extra](../common/blender_extra.md)。

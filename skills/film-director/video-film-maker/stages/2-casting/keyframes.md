# 关键帧：定妆图转成每镜的开头画面

一句话：要定住开头画面的镜头，先用图像模型把定妆图画成这一镜的关键帧（一张成片质感的画面），再当首帧交给视频模型；画完先自己看，对了才拿去生成视频。

## 什么时候用

- [关键时刻](../1-storyboard/key-moment.md) 里要拍准的那一帧。
- 暗场：只用参考图生成，画面会被画亮；用首帧生成，画面能保持暗。
- [镜头表](../1-storyboard/shot-list.md)「空间」一列写了上白模的镜头（要有 blender-previz skill）。
- 接着上一镜演、人和道具要接得上的镜头。
- 别的镜头不出关键帧，照 [分镜单元](../3-generation/shot-unit.md) 用参考图生成。打斗和连续的肢体戏也不出：每一招配一张首帧，拍出来动作僵硬、镜头零碎。

## 思路

1. **输入是定妆图**：这一镜出现的人、道具、场景的 [定妆图](references.md)，加一段文字：谁是图几、各在画面哪边、朝哪、此刻什么状态，照镜头表的「画面」「状态」两列写。
2. **上了白模，多带一张白模静帧**：它只管机位、构图和站位，长相仍然照定妆图，提示词里写明每张图各管什么。交给视频模型的是画出来的这张关键帧，不是白模图。多画哪几张、提示词多写什么，见 [blender_extra](blender_extra/overview.md)。
3. **先出一张主帧，其余从它派生**：主帧挑看得最全的那一镜，把场景的样子定下来；别的镜头带上主帧或最近的一张关键帧当样子，只改机位和状态。
4. **接着演的镜头，从上一镜的成片派生**：上一镜生成好以后，从它最后几帧里截一张当输入，人、道具、光都照成片接。换了地方或机位变化很大，才回到主帧。
5. **首帧画动作开始之前的样子**：门还没开，手还没碰到，沙发还没动。动作画了一半，视频会把它从头再演一遍。
6. **派生时写明不一样的地方**：这个机位看不到的东西（走廊在镜头背后），状态已经变了的东西（桌上已经没有橡皮），逐样写；不写的话，源图里有的东西会被照样画进来。
7. **画完就看，一张一张看**（见下面「出图后检查」）。没通过检查的重画，不拿去生成视频。

```
key[主镜] = image_model(定妆图 + [白模静帧 if 上白模], "谁是图几、在哪、朝哪、什么状态；场景；质感")
for shot in shots_needing_keyframe:
    src = pick_frame(tail(clip[prev])) if continues(prev, shot) else nearest(key)
    key[shot] = image_model([src] + 定妆图 + [白模静帧 if 上白模],
                            "沿用图1里这个机位看得见的东西；机位和站位照镜头表（或白模）；和图1不同：…；这个机位看不到：…")
    line = look(key[shot], shot_list[shot], 白模静帧)      # 一镜一张放大了看，写一句「该有什么、画了什么」
    if wrong(line): redraw(key[shot])                      # 没过不生成视频
```

## 出图后检查（不合格就重画）

- 一镜一张放大了看，不看缩成一格格的联系表。上了白模的，和白模静帧并排。
- 每张写一句：镜头表（或白模）里该有什么，这张画了什么。按这个顺序看：
  1. 机位和景别；
  2. 背景里的大结构：门、门洞、走廊、窗、墙角、楼梯，家具的行列和朝向；
  3. 谁在画面里、在哪边、多大、朝哪；
  4. 门窗开着还是关着、往哪开，道具的状态；
  5. 是不是这一镜动作开始之前的样子。
- 有一样不对就重画这一张，别的不动。上面每一项都要对上，只对上道具状态不算通过。
- 自己看，不拿边缘重合、相似度这类分数判：试过一次，画错的那张和别的分数一样。

## 好用的规则

- 成片里最扎眼的空间毛病，多数出在这一步，不出在视频那一步：三部两分钟的片里最明显的三处（比如门后的墙角画成了走廊、教室的桌子排乱了），都是关键帧就画错了，视频只是照着首帧拍。
- 看的方法不对，等于没看：一部 38 镜的片，拍的时候看的是缩小的联系表，只看了人和表演；事后一镜一张放大了再看，26 张的背景或站位不对。
- 出图要用图像模型（比如 gpt-image）；用之前先问用户，要问的几项见 [gpt-image](../../refs/practical/gpt-image.md)。

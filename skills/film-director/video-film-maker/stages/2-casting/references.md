# 定妆：人物、道具、场景的参考图

一句话：先拍一段专门的设定单元（镜头环绕人物，截正面、侧面、背面和脸），把截下来的图当参考图，让人物和道具前后一致；也可以先用图像模型画一张角色设定图（见 [gpt-image](../../refs/practical/gpt-image.md)，用之前先问用户）。参考图只放这一镜出现的东西，背景抠掉，每种状态一套。

## 什么时候用

人物要出现在不止一次调用里；有要前后一致的道具、怪物、建筑。

## 思路

1. **设定单元**：只用文字生成一段短片：柔和均匀的光、灰色或简单的背景，镜头匀速环绕人物（或从左前转到右前），可以再接一个脸部特写。截正面、侧面、背面全身，再截脸（正脸和 3/4 侧脸），按视频的原始分辨率抽帧（不截屏；不够大再放大）。侧脸截主机位看得到的那一侧。设定单元和定妆图的提示词不照抄全片的风格段：只留讲画风、质感的那几句，讲地点、时间、天气、光色的句子去掉（风格段里有「橘红晚霞」，灰背景就被画成了晚霞，还有一次在 2.8 秒处叠化成了太空）。
2. **每种状态一套**：参考图和文字写的状态不一样时，模型照参考图画（图里面罩挂着，文字写「扣好」也没用）。状态要在图里一眼看得出；不够明显，模型会退回它默认的样子（袖子捋起要露出整段前臂），必要时再加一张局部裁图。戴面罩 / 摘面罩、头套戴上 / 摘下各备一套；一镜里状态有变化时给前后两套，注明各对应哪一段。某种状态的参考图没拍对、要重拍这种状态的设定单元时，提示词先把做完以后的样子写具体（面罩上沿压在鼻梁上、紧贴眼睛下面），再写戴上的动作。
3. **只放这一镜出现的人**：多放了这一镜没有的人，他会被叠化进画面，或者和别人弄混。人多的单元每人只从这些图里放三张：正脸、正面全身、背面全身，顺序固定（图1、图2……）。
   - 数人的时候数全：中途入画的、背景里的、只露背影或一只手的都算出现。
   - 分镜单元按整个单元来数人：单元里任何一镜出现的人都放，每一镜的画面里写清这一镜有谁。
   - 出现了但不给图的人（小人物、背影），在那一镜的画面里用文字写上；不写，成片里就没有这个人（只放了主角的图，驾驶座就空着）。
4. **小人物、背影的全景不放人物图**：放了会叠化出一个脸部特写，或把参考图的背景带进来；只靠文字。
5. **背景要抠掉**：在参考图说明里写「not their background」，背景还是会被带进画面，所以参考图的背景要涂灰或抠掉；设定单元里冒出来的人和东西也抹掉。
6. **换角度时只放人物图**：放了场景图，机位会被锁成那张图的样子。反过来，想让下一段从同一机位接着拍，就放一张整幅画面。
7. **道具、怪物、建筑**：从第一个露出全貌的单元截（这个单元排在前面生成），裁到只剩它。状态会变的道具（罐子里有没有种子）不靠参考图定状态：变化放进续写里做，或截变化以后的样子。
8. **参考图说明**：每张写明只用来锁什么（「只锁外形，不照搬构图、背景、光线、姿势和视线」）。
9. **上白模的镜头**（用了 blender-previz skill 才有）：定妆图照常做。白模转成写实关键帧时带上这一镜的人物图和道具图；生成这一镜时，关键帧管位置、机位和构图，人物图仍然管长相，说明里写清每张图各管什么。关键帧是一张整幅画面，会把机位锁成它的样子（第 6 条），这里要的就是这个。

```
setup = generate(text("灰背景、柔光，镜头匀速环绕 <人物> 一圈，最后脸部特写"))
refs[person][state] = gray_background(crop_native(setup, front, side, back, face))
for shot in plan:
    shot.refs  = [refs[p][shot.state(p)] for p in shot.people if not shot.tiny_or_back(p)]
    shot.refs += [refs[x] for x in shot.props]                     # 裁到只剩道具
    shot.note  = "图N 只用来看 <脸 / 衣服 / 道具>，不照搬图里的背景、构图、姿势和视线"
```

## 好用的规则

- 设定单元按成片画幅生成，它的正面特写可以直接当成片素材（叠在湖面上的脸）。
- 写实的少年脸当参考图可能被内容审核拦下：这个人只用文字描述；没有参考图，分开的几次调用会把他画成不同的人，所以露他脸的镜头都排进同一个单元。
- 场景参考图（尤其是自己画的）先对剧本里的空间事实逐项核：楼梯往上还是往下、是不是顶层、门往哪开、出入口在哪一侧。错一项，带这张图的每个单元全错。
- 场景参考图会带进天气和构图（晴天的灯塔图让暴雨镜头成了蓝天）：场景只在构图和天气相近时才给图，否则用逐字复用的文字。
- 场景参考图也会带进图里道具的状态（图里沙发已经摆在垃圾桶前，开场它就在那了）：道具的位置或状态会变的场景，每种状态备一张，或者图里不放这件道具。
- 一个单元里远景和中景混着拍：带场景图，中景可能被拍成那张图的远景（2 个单元出过这种情况）；不带，场景里的东西样子会变（竖的灯箱变成横的）。带着场景图、把中景那一镜的景别和机位写明确，试了 2 个单元，1 个拍对了（另一个的中景还是拍成了远景）。
- 两个年纪、体型相近的同性主角容易被对调（一部五分钟的片 4 个单元第一条都对调了）。每镜第一次提到名字时带上外貌标签（见 [台词](../3-generation/dialogue.md)「按画面位置和外貌指认」）；带了也还会对调，查出来就重抽，这 4 个单元第二条都对了。台词给错了人、重抽也改不过来的，把这个单元里说话、做事的那个人的参考图排到第一张：模型容易把动作和台词派给排第一的人（1 个单元，前两条都是另一个人说了这句，第三条这样排以后对了，同一条还改了别的写法）。
- 补拍一个局部时，参考图说明写「只锁拳套和胶布」这种局部。
- 一部片用同一组人物参考图。
- 定妆用中性光，脸截正脸和 3/4 侧脸（全身截哪几张见上面思路第 1 步），不要贴脸大特写再加皮肤词：参考图会直接决定片里的脸，定妆以后先看脸的质感（见 [人物肖像](faces.md)）。

## 生成后检查（不合格就重抽）

- 人、衣服、道具和参考图一致；没有换错人、没有两个人的脸和衣服配错。
- 参考图里的背景、姿势、视线没被照搬进来。
- 状态对：面罩扣好、头套戴着、罐子是空的……
- 生成的视频开头，有没有先插进一段照搬参考图构图的画面（插了就不用那一段；要不要预先留时间见 [分镜单元](../3-generation/shot-unit.md)「第一镜多长」）。

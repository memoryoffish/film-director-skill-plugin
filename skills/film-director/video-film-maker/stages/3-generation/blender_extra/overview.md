# 用了白模：生成这一步多做的

一句话：上白模的镜头，多了三样能喂给视频模型的东西：照白模画的关键帧、尾帧、只放替身的预演。一镜挑一种喂法；人物图、道具图和文字照这一步原来的做法。带参考图、参考视频的喂法，一定带上这一镜的关键帧（彩帧）当参考图。要有 blender-previz skill。

## 什么时候用

- [镜头表](../../1-storyboard/shot-list.md)「空间」一栏写了上白模、[关键帧](../../2-casting/keyframes.md) 已经画完看过的镜头。
- 只用文字的镜头照 [分镜单元](../shot-unit.md) 原样做，不看这一篇。

## 思路

1. **一镜挑一种喂法。** 分镜时已经记在镜头表「空间」一栏，这里对着关键帧再对一遍：

| 镜头 | 喂法 | 参考图 |
|---|---|---|
| 空间、走位戏里单独生成的镜头：特写、近景双人、暗场、反应镜头 | 关键帧当首帧 | 带不了：首帧和参考图不能放进同一次请求，长相靠首帧里的那张脸 |
| 要落到一个确定的状态：开门、东西落在哪、转头、有人进画；升、摇、拉露出新东西 | 首帧 + 尾帧 | 同上 |
| 亮场里两三个人连着演的两三镜 | 分镜单元，每镜的关键帧当参考图 | 人物图、道具图照带，每镜的关键帧一定带，接在后面 |
| 人一直在移动、要卡全程路线和时刻：走位、跟拍、复杂运镜 | 只放替身的预演当参考视频 | 人物图、道具图照带，这一镜的关键帧一定带 |
| 打斗、推搡、抬着东西较劲这类连续的肢体戏 | 不拿白模关键帧当首帧，也不给预演：分镜单元或只用文字，白模只给站位和左右 | 照带 |

2. **首帧、首帧 + 尾帧的镜头，提示词只写这一镜里动的东西、机位和声音。** 首帧已经把人、地方、光、构图定了：场景、外貌、道具外观、风格段都不写。每多写一样画面里没有的东西，镜头就多一个理由切出去拍它。只有这两种喂法这样写；分镜单元和参考视频的提示词照 [提示词](../prompts.md) 的结构，共用描述照旧逐字复用。
3. **放进分镜单元的镜头，每镜的关键帧接在参考图后面。** 分镜表照 [分镜单元](../shot-unit.md) 写，画面里的左右、朝向用镜头表里从白模抄来的句子。提示词最后用一句话给这几张图派活：依次对应哪几镜，只用来定机位、构图和站位，长相照前面的人物图。参考图总数有上限，关键帧占掉几张，一个单元就少放几镜。
4. **预演当参考视频的镜头，一定带这一镜的关键帧当参考图。** 预演只管路线、时刻和运镜；人物图、道具图管长相；关键帧管场景的样子和光。只给预演和人物图，场景是模型自己编的，和别的镜头不像。预演里只放没有四肢的替身，和要生成的视频一样长；预演已经给了运镜，文字里不再写另一套。
5. **生成，照 [生成后检查](../checks.md) 查，再多查白模带来的几样**（见下面）。

```
for shot in 上白模的镜头:
    feed = shot_list[shot].空间.喂法
    if feed in (首帧, 首帧+尾帧):
        job = shot_job(key[shot], last=tail_key[shot] if feed == 首帧+尾帧, text="谁做什么、做到什么程度；机位；声音")
    if feed == 分镜单元:
        job = unit_job(table, blocks, refs=人物图 + 道具图 + [key[s] for s in unit], guide="图N…依次是镜头1…开头的画面，只定机位、构图、站位")
    if feed == 参考视频:
        job = ref_job(text, blocks, refs=人物图 + 道具图 + [key[shot]], video=替身预演[shot], guide="视频只定机位、运镜、站位、路线；图N 是第一帧的画面，场景和光照它")
    clip = generate(job); problems = checks(clip) + against_white_model(clip, still[shot], key[shot])
```

## 生成后检查（不合格就重抽）

在 [生成后检查](../checks.md) 之外多查：

- 站位、左右、朝向、门的开向：白模静帧、关键帧、成片三样并排看。
- 白模的东西有没有进画面：人偶、纯色的占位块、胸牌、悬在半空的方块、一根柱子。
- 人有没有并脚笔直站着不动、动作一个姿势接一个姿势。
- 首帧 + 尾帧的片子：最后几帧有没有跳一下或发虚；中段有没有整幅叠化成尾帧。
- 参考视频喂出来的片子：上下有没有黑边；路线和时刻对不对得上预演。
- 同一个毛病两条都出现，就不是运气：不换种子，看是白模、关键帧还是喂法带进来的，回到那一步改（对照表见「动手前查」）。

## 好用的规则

- **白模只管位置，不管表演。** 站位都对、就是没戏，回 [表演](../acting.md) 和镜头设计；同一张首帧换一种写法多拍一条，比换种子更容易拍出戏。
- **白模静帧和预演不单独喂。** 带参考图、参考视频的任务里没有关键帧，就先回定妆把这一镜的关键帧画出来。
- **没什么移动的表演镜头不给参考视频**（站着说话、对视、吃饭、原地做动作）：替身不动，人就站成柱子。
- **首帧是动作之前的样子。** 首帧里已经出现的结果，这一镜演不出来。
- **尾帧里姿势和首帧一样的人，会整镜不动。** 要他动，只给首帧，文字写他的反应。
- 每种喂法先拍一条小样看，再铺开。
- 单独生成的镜头之间环境声不连续，留到剪辑统一铺（见 [4-edit](../../4-edit/blender_extra/overview.md)）。

## 动手前查

- 每种喂法管得住什么、管不住什么：blender-previz skill 的 `stages/3-feed/overview.md`「几种喂法」。
- 各种喂法的步骤和任务模板：同一目录的 `first-frame.md`（哪些镜头必须加尾帧、哪些别加）、`unit-refs.md`、`ref-video.md`；模板在它的 `scripts/jobs.py`。
- 毛病回到哪一步改：blender-previz skill 的 `stages/4-check/overview.md`「毛病和改法」。

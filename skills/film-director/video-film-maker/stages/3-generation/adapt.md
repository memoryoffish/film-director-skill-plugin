# 按模型适配提示词

一句话：先用我们带标签的结构化写法起草（分镜表、风格、参考图、场景、声音、要求），再照所用视频模型的官方提示词 skill，把稿子的内容分进那个模型的各节里。内容不改；每条描述只放进一节，不在几节里重复写。

## 什么时候用

每次交视频任务之前，一个单元或单镜的结构化稿写完以后。

## 思路

1. **起草用我们的结构**（见 [提示词](prompts.md)、[台词](dialogue.md)）。
2. **找所用模型的官方写法**：

   | 模型 | 官方写法 | 用哪几节 |
   |---|---|---|
   | Wan 3.0 | [wan3-pe](../../refs/practical/prompt-skills/overview.md) | 「请求模板」的五段请求结构 |
   | Seedance 2.5 | [sd25-pe](../../refs/practical/prompt-skills/overview.md) | 「带参考素材的生成」「长视频与时间段」「声音、台词和文字」；没有参考图用「基础生成」 |
   | MiniMax H3 | 官方两份写作指南（官方模型仓库 [MiniMaxAI/MiniMax-H3](https://huggingface.co/MiniMaxAI/MiniMax-H3/tree/main/docs) 的 `docs/` 下 `VIDEO_PROMPT_WRITING_GUIDE_base_en.md`、`…_ref_en.md`） | 没有参考图用 base，有参考图用 ref |
   | HappyHorse | 没有官方写法 | 结构化稿原样交 |

   按 [各节的行号](../../refs/practical/prompt-skills/overview.md) 只读用得到的那几节。官方全文不在仓库里，取不到时 Wan 照下面「官方五段各写什么」写。
3. **把稿子的内容放到官方结构里对应的位置，不照搬官方模板的全部。**

   **Wan 3.0 官方五段各写什么**（照 wan3-pe 0.2.0「五段请求结构」概括）：
   - 【核心任务】：一句话说生成一段什么题材、什么内容，参考哪个视频 / 图 / 音频里的什么（形象、动作、场景、音色），全片什么风格。所有素材的用途都集中写在这一段。
   - 【情节概要】：按先后编号的情节节点，每条写人物、动作、事件；台词逐字保留，写明谁说、用哪段音频的音色。有时间戳时每条以「镜头N xx-xx秒」开头。
   - 【音频风格】：对白的语言和质感、现场音效、配乐的情绪和节奏。
   - 【运镜与核心约束】：镜头风格、运动方式、剪辑节奏，加上硬性约束。
   - 【负面提示词】：逗号分隔的、明确要排除的东西。
   - 取舍：前两段每次都写；音频、运镜两段没东西可写就一句带过或省掉；负面提示词只在要排除东西时写。

   **Wan 3.0**（五段请求结构），我们的稿子放进哪一段：
   - 【核心任务】：一句话写这段是什么，后面接「参考图：」那一行和风格那一句。
     - 不照官方示例给每个主体单独写一大段，说它对应哪张图、采用图里什么。
     - 没有参考图的场景和物体，短描述放在这里。
   - 【情节概要】：分镜表照搬，每条以「镜头N xx-xx秒」开头，台词原样。
   - 【音频风格】：我们的「声音：」段，包括不要配乐。
   - 【运镜与核心约束】：机位、运镜，加我们的「要求：」：切点按表、不另外切镜、无字幕水印、视线方向。
   - 【负面提示词】：只放明确要排除的字幕、水印。画面里不该出现的东西不点名（否定句会画出来，见 [提示词](prompts.md)）。

   **Seedance 2.5**（「带参考素材的生成」加「长视频与时间段」）：
   - 【生成目标】：一句话写这段是什么，后面接风格那一句。
   - 【参考素材职责】：我们的「参考图：」一行，改成它的写法：`@图片N用于<谁>的<只取什么>，不采用图片背景`。只写每张图用来做什么，不写长相。
   - 【主体与关系】：谁对应哪张图，各在画面哪边，道具归谁。没有参考图的场景和物体，短描述放在这里。
   - 【事件脚本】：分镜表改成连续、不重叠的整数秒时间段（`0-3秒：…`），每段一个主要动作，写上结束时的状态（照镜头表「状态」一列）。Seedance 把时间段只当成每件事大约占几秒，不保证在那一帧切。所以生成后要量实际切点，剪辑时按量到的切点裁。
   - 声音用它的符号：台词 `{…}` 前面写语言、说话人和语气，音效 `<…>`，音乐 `(…)`。不要配乐就写明没有背景音乐；没有台词的段写「人物自然闭口、没有旁白，画面不显示字幕」。
   - 【保持一致】：我们的「要求：」：人数、服装、道具归属、左右方向不变。
   - 【未采用素材】：只有传了图却没用上时才写；我们只传用到的图，这一段不加。
4. **官方结构里没给位置、写法容易不统一的几处**：
   - 每镜开头的画面参考（关键帧当参考图）：和人物、道具的图写在同一处，注明「图4、图5 依次是镜头1、镜头2 开头的画面，机位、构图、位置照它；长相以人物图为准」。
   - 用首帧、首尾帧接口生成的单镜：不叫「图N」，写「首帧图是起始画面」「尾帧图是收尾画面」，再写两帧之间发生什么。
   - 单镜任务也带风格那一句，从同一部片的单元里逐字抄。
   - 有参考图的东西不写外观，只留一个说明它是什么的词（「三人沙发」）；嗓音描述不算外观，留在声音段里说话人后面。
   - 「画面里只有下面写到的人」「除了写明的字没有别的字」这类话，适配后改成点名的正面说法（「只有阿杰和小周两个人」「能读出的字只有墙上的『2』」）。

   **提示词用什么语言**（几处说法不一样，以有实测的为准）：
   - 遮挡转场、参考图模式：正文用英文写。Wan 3.0 上各并排比过一次，英文版比中文版稳（见 [wan3-notes](../../refs/practical/wan3-notes.md)）。
   - 续写：用中文写「将视频1向后延长 N 秒」，照 wan3-notes 的实测写法。
   - 台词照它本来的语言逐字写；英语台词写明「用英语说」（见 [台词](dialogue.md)）。
   - 没比过的：白模的几种喂法（blender-previz 的模板和实拍都是中文）、官方段名（【核心任务】这些）配英文正文、Seedance 2.5 上的中英文。这几种两种语言都可以，拿不准就同一镜各拍一条并排比。

5. **必须留下的**：
   - 切点表的秒数；
   - 每张图的身份；
   - 台词逐字；
   - 不要配乐；
   - 无字幕。

   官方模板里有、这一镜用不上的段，不加。官方 skill 主张只写用户要的、不滥加约束；镜头内和接缝处的 no cuts、no music 我们照样写，因为模型会自己切镜、加配乐。
6. **对一遍**：适配后的稿子和结构化稿比，每个镜头、每句台词、每张图的身份、每条要求都还在，也没多出外观描述。

```
draft  = structured(shot_table, style, ref_roles, scene, unreferenced_objects, sound, requirements)
guide  = OFFICIAL.get(model)                      # wan3-pe / sd25-pe / H3 guides / None
prompt = draft if guide is None else map_to_sections(draft, guide,
             keep=[cut_times, lines_verbatim, ref_roles, no_music, no_subtitles],
             drop=[appearance_of_referenced])
assert covers(prompt, draft)
```

## 实测

还没有结论。Wan 3.0 上比过三种写法：我们原来的模板（带外观描述）、只照 wan3-pe 写、照这一篇适配。4 个任务（两个三镜分镜单元、一个首尾帧、一个首帧）× 2 个种子，参考图、首尾帧、时长都不变，24 条都生成了，还没人评。Seedance 2.5 的适配写法还没实际生成过。

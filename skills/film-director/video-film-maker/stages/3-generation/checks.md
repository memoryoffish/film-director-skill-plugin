# 生成后检查和重抽

一句话：每次生成完马上查：切点对不对分镜表、有没有多出来的切点和叠化、开头有没有先插参考图的构图、有没有没要的配乐和多出来的人声、台词的口型对不对、人和道具对不对、物理和场景讲不讲得通；不合格就换种子重抽，同一个毛病连着出就改提示词或参考图。查过的只是「没错」；关键镜头还要多拍几条不同写法的，看片挑最好的。

## 什么时候用

每次生成之后、进剪辑之前。镜头多的片子，可以把这一步交给一个子 agent 专门做（每条对着分镜表和镜头表「状态」一列查），自己接着写下一个单元。每种接法自己要查的写在 [接法库](../../transitions/overview.md) 和 [4-edit](../4-edit/overview.md) 各篇的「生成后检查」里；拼好以后的检查见 [成片检查](../4-edit/final-check.md)。

## 查什么

1. **切点对分镜表**：量出实测切点（查法见 [模型自带的切镜](own-cuts.md)「怎么查」），逐个对表上的切点。表上的切点没切出来、多切了一刀、整幅叠化，都不合格。切点在、只是偏了：偏得不多，直接接受这一条。偏得多时不按数字判：每一镜的动作和台词都拍全了、照实测切点剪得出要的时长，就接受这一条，剪辑表改用实测切点；哪一镜被缩短到拍不全，才重抽（容差见 [refs/practical/config.md](../../refs/practical/config.md)「分镜单元」，实测值写在案例里）。
2. **多出来的切点和叠化**：最后一镜、只含一镜的短单元最容易出。落在要用的镜头里就重抽，落在不用的尾巴上可以留；专门做转场的那几秒里不能有。
3. **开头先插参考图的构图**：用参考图生成时，视频开头有时先有一段参考图的构图，再转到要的机位。那一段不用，剪辑时从真正的起点开始用。什么时候会有、第一镜要不要为它留时间，见 [分镜单元](shot-unit.md)「第一镜多长」。
4. **配乐和人声**：
   - 看频谱：一组窄峰连着出现、在音符之间跳，是配乐；一直不变的窄峰是嗡声、底噪，不算。
   - 持续的和弦会漏查：再看窄峰是不是正好落在一个和弦上。
   - 人声：语音识别转写一遍，再对照频谱；安静段里转写出来的几个词，多半是语音识别凭空编出来的，要人耳听一下。有台词的单元，转写结果对照台词原文，原文以外的都是多出来的人声。
   - 频谱图必看，脚本的数字只当初筛：按 config 的门槛，《雨季未完》4 段配乐只抓到 1 段。
   - 没要的配乐都要去掉：这一单元的提示词没写要音乐，模型加出来的配乐就是多余的。每个单元的配乐都是模型各自加的，剪到一起接不上。提示词里写明要的（只在这一单元里的音乐）留着，查它是不是照提示词写的时刻开始和结束。铺全片的配乐后期统一做（见 [声音设计](../4-edit/audio.md)「配乐」）。去掉时先只分离掉音乐、留下动作声，不行再重抽，或换成环境声。
5. **台词的口型**（有台词的单元）：嘴动时有声音、说完嘴停；说话的是写的那个人，别人没跟着张嘴；语言对不对；说台词的那几秒和最后一秒，画面下方有没有冒出字幕。见 [台词](dialogue.md)。
6. **人、道具、场景**：脸的皮肤纹理没过重、没凭空多出伤口和斑点（见 [人物肖像](../2-casting/faces.md)）；没换错人、两个人的脸和衣服没配错；道具前后一致、没凭空多出东西；镜子、倒影里没多出人；参考图的背景没被带进来。物理和场景讲得通：门往该开的那边开，东西没穿过别的东西，道具的状态接得上上一镜（摘下的耳机没自己戴回去）。对着镜头表「状态」一列看这一条的开头和结尾：上一镜做完的动作（拎起、放下、开门）这一条没有再做一遍。
7. **镜头**：景别、机位、运动、慢动作照不照表。

## 重抽

- 换种子重抽。但构图主要跟着提示词走：
  - 只换种子、提示词基本不变，构图也可能几乎不变：《一叶》编号 U1 的单元，第 2 次生成换了种子、只改一句共用描述，画面和第 1 次几乎一样。
  - 只改几个字、种子不变，构图几乎不变：只想把方向翻过来时正好利用这一点（一次实测）。
  - 要换构图，就改提示词里这一镜的机位、景别、前景。
- 模型对某类东西有很强的默认样子（中国河上的渡船三次都画出乌篷船舱），正面写、改写、换种子都没用：先单独生成一段这件东西，截一张参考图把它的样子定下来，像用参考图定下人物一样（《一叶》报告的建议，还没实测）。
- 同一个毛病连着出两三次，只换种子没用：改提示词（第一句写清、写成看得见的效果）或改参考图（换状态、去背景、少放人）。
- 要从前面某一段截图当参考图时，先把这一段查完再截：这一段一重抽，截出的参考图和后面的段都得重做。
- 查出毛病、次数还没用完，就接着改，不能写进报告就到此为止；动作讲不通的镜头（人往反方向走、该在门外却进了门），剪辑也补救不了。
- 每个单元最多生成几次，在配置里定；抽满还不行就停下来，要么留着这个毛病，要么交给剪辑修（见 [修补](../4-edit/fixes.md)）。

```
for take in 1..TAKES:
    clip = generate(unit, seed=base + take)
    problems  = compare(measure_cuts(clip), unit.table)               # 漏切、多切、叠化
    problems += opening_ref_layout(clip) + music_or_speech(clip, unit.lines) + lip_sync(clip, unit.lines) + people_and_props(clip, unit)
    if not problems: accept(clip); break
    if same_problem_again(problems): unit = rewrite(unit, problems)    # 改提示词或参考图，不只换种子
else:
    report(unit, problems)                                              # 留差别，或交给剪辑修
```

## 挑好（关键镜头）

合格只说明没出错。最要紧的几镜还要好：

- **哪几镜**：镜头表里标出的关键镜头：高潮、情绪最重的一两镜、开头和结尾（几镜、每镜几条见 [refs/practical/config.md](../../refs/practical/config.md)「挑好」）。
- **多拍几条不同的**：每条换一种写法：表演的大小、快慢、停顿，机位或景别，光。只换种子常常拍出几乎一样的（见上）。
- **看片挑**：
  - 人在演，不是在摆：脸上、手上有变化，动作有起因、有反应（见 [表演](acting.md)）；
  - 这一镜要讲的那件事，一眼看得懂；
  - 放进前后镜头里接得顺；
  - 几条里光和构图最好的。
- **能给用户挑就给**：候选都在进度页上能播（见 [可视化](../common/visualize.md)），或者做成盲选（见 [盲选](../4-edit/blind.md)）。
- 多拍的这几条，开工前算进预算（见 [预算](../common/budget.md)）。

```
for shot in key_shots(table):
    takes = [generate(unit_with(shot, variant=v)) for v in variants(shot)]   # 换表演、机位、光，不只换种子
    best = pick(passing(takes), by=[acting, readable, fits_neighbours, look])  # 人看；能给用户挑就给
```

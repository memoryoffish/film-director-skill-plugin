# 补人声：参考视频连声音重拍

一句话：片子已经剪好，某个镜头里有人张嘴却没声音，就把这一小段当参考视频喂给模型，连画面带声音重拍一遍；提示词开头先要求画面照参考视频不变，台词逐段给时间，生成后对着原镜头查画面、台词和嘴。

声音仍然是模型和画面一起生成的，不是后期配上去的：画面照参考视频重新渲染一遍，嘴跟着新的声音重新动。试点和一轮生产的数字都是自动量的（语音识别、能量包络、逐帧相似度、谱线），没有人耳听过，见「依据」。

## 什么时候用

- 成片里有人开口，当初生成时却没写台词，或者生成出来没声音。
- 只用在一个镜头、几秒以内的说话或喊叫（上限见 [config](../../refs/practical/config.md)「补人声」）；镜头越长，越往后画面越偏离原镜头。最好是固定机位：固定、锁定的镜头和原镜头的相似度 0.75–0.88，跟拍、推拉的只有 0.35–0.48，后半段机位还会比原片快。
- 整个镜头可以换掉时，不如照 [台词](dialogue.md) 把这一镜带着台词重新生成：台词更准、嘴型更好，只是构图会变。

## 思路

1. 从成片里切出这一个镜头，去掉声音，当参考视频。
2. 生成时长取整，比片段长一点；多出来的尾巴会被剪掉（多长见 config）。
3. 提示词按顺序写：锁画面 → 风格、场景、人物（照原来生成时逐字复用）→ 镜头 → 台词 → 声音。
4. 生成后剪回原长，查（见下）；不合格就改写重抽。
5. 估预算按续写算，输入的秒数也计费（`budget.py` 里写成 `extension`，填 `input_s`，见 [预算](../common/budget.md)）。

## 提示词怎么写

- **锁画面**，放最前面：「视频1 是一段已经剪好的 X 秒电影片段（一个镜头）。请完整复现视频1，从第一帧到最后一帧，并给它配上同步的声音和台词。画面必须严格照视频1：同样的人物（脸、发型、服装）、场景、构图、焦段、亮度和色调、机位和镜头运动、动作的时间和速度。不加切点；没有慢动作；不新增人物和物体。」
- **尾巴**：「前 X 秒必须和视频1逐帧一致、同样的速度；X 秒以后只是顺着最后的画面自然延续一点（这一段会被剪掉），不要切到新镜头。」
- **暗场**的镜头，提示词写了「亮度和视频1一样，不要提亮」，模型也照样提亮（Drive 亮了 27–68%，拳馆回忆 27–32%；亮场的变化在 ±8% 以内）。这句可以写，但生成后一定要把亮度调回去。
- **人物**写明谁在画面左边、谁在右边；**镜头**逐秒写动作，嘴的动作也写进去（「1.65 秒起他的下巴猛地张开」）。
- **台词**：一句话拆成几小段，每段给精确时间（「0.46–1.04 秒“别急。”；1.29–1.92 秒“等它回来，”」），写明嘴只在这几段里张合，其他人不说话。画面已经定了，才这样写时间；新生成的镜头照旧不写时间点。其余写法同 [台词](dialogue.md)：按位置指认说话人、嗓音描述、一字不差、两人同时喊。
  - 时间窗只能帮一半：生产那一轮里有一部情侣对话片，它那批台词段约一半的生成在 ±0.3 秒以内。Wan 会把台词挪到画面里对应的动作上：「谢谢你」三次都落在她点头微笑上，晚 0.4–0.75 秒。
  - 把台词的时间写在提示词最前面，删掉会招来多余东西的句子（写了灯，画面里就多出台灯、路灯）。编号 W11、W13 的两段这样改了一次，台词就准时了。
- **声音**和**无字幕**：同 [台词](dialogue.md)「好用的规则」。

## 生成后检查

- 画面：和原镜头逐帧比相似度；暗场先把亮度对齐再比，再把成片亮度调回原片。
- 台词：语音识别转写，对照原文，看改字和开口时间。
- 嘴：只在台词那几段里动，动的是写的那个人。
- 语音识别认不出喊叫，要人耳听；两人同时喊，听是不是两种声音。
- 有没有配乐、字幕。八音盒一样的叮咚旋律、哼的小调也算配乐。写全了「没有任何配乐」，还是偶尔会出现配乐；用陷波滤波器也滤不干净，只能重抽。

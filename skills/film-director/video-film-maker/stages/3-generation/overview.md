# 3-generation：生成与检查

一次调用怎么写、人怎么演、台词怎么放、成片缺声音怎么补；每条生成完马上查，能改的当场重拍。

## 这一步交出什么

- 每个单元一条查过的片段，关键镜头的几条候选。
- 一份记录：每条生成了几次，留下了哪些没改掉的毛病、为什么。
- 往下走之前：查出来的毛病，重抽次数还没用完就接着改，不能写进报告就到此为止。

## 这一步几篇共用的

- **镜头内只写先后，不写时间段**，台词也不写第几秒：写了时间段，模型常在分段处多切一刀。例外是补人声：那里画面已经定了，台词才逐段给时间。
- **有参考图的人和东西不写外观**：只写图N 是谁、是什么、只用图里的哪部分；没有图的才写一句短描述。
- **台词逐字写，每句绑定说话人**：说话人按画面位置指认，别人闭着嘴。两个人同时喊时，模型常分不开两人的声音（补人声里试了 3 次都没分开），尽量拆成两镜。
- **开头和结尾留余量**：生成的视频开头，画面可能先停在参考图的构图上；最后一镜和只含一个镜头的单元，最容易被模型多切一刀。生成后对着分镜表查。

- **任务怎么发**：视频任务用本 skill 的 `scripts/wan.py`（一批任务用 `occut.py gen`），它只送 Wan 3.0 和 HappyHorse 1.1。装了同一个仓库里的 film-crew 插件（仓库的 `plugins/film-crew/`）时，视频和出图任务也可以交给它的 backends：先 `filmgen.py request` 看要发的请求，再 `run` 在这台机器上跑或 `send` 送到另一台机器，任务单格式一样；Seedance 2.5、MiniMax H3 这个 skill 不带脚本，交给它，或者自己照官方接口调。各家能用的模式见 [models](../../refs/practical/models.md)。

跨步的规矩（写成看得见的效果、共用描述逐字复用、不要配乐和字幕、查出毛病接着改……）见 [common/rules](../common/rules.md)。

## 什么情况用哪种做法

| 情况 | 做法 | 细节 |
|---|---|---|
| 剧情片、动作片的一场戏 | 一次调用写一张分镜表；第一镜别太短，最后一镜一直延续到这段视频结束 | [shot-unit](shot-unit.md) |
| 修单个镜头 | 做成两镜单元，成片只用要修的那一镜 | [shot-unit](shot-unit.md) |
| 用了白模的镜头 | 一镜挑一种喂法：关键帧当首帧、首帧 + 尾帧、放进分镜单元、替身预演当参考视频；能带参考图的接着带 | [blender_extra](blender_extra/overview.md) |
| 写提示词 | 先用带标签的结构起草：风格、参考图、场景、声音、要求 | [prompts](prompts.md) |
| 结构化稿写完，交任务之前 | 照所用模型的官方写法，把稿子分进它的各节：Wan 3.0 分进五段请求结构；Seedance 2.5 写明每份参考素材的用途，分镜表改成时间段。内容不改；每条描述只放进一节，不重复写 | [adapt](adapt.md) |
| 有台词 | 生成时就写进提示词，连声音一起出；一镜一两句；同一个角色全片用同一段参考音频或同一句嗓音描述，音色才不变 | [dialogue](dialogue.md) |
| 成片剪好才发现有人张嘴没声音 | 把那一小段当参考视频，连声音重拍；提示词开头先要求画面照原镜头不变，台词逐段给时间。只用在几秒以内的单镜头 | [revoice](revoice.md) |
| 人要演，不是摆 | 先原因后反应、分成两镜；表情写变化，动作按拍子写，打斗写成一招接一招的链；演不出来就靠剪辑 | [acting](acting.md) |
| 关键时刻 | 最先拍：几种拍法各拍一条并排比，有一条让没看过剧本的人也看得懂了，再拍别的 | [关键时刻](../1-storyboard/key-moment.md) |
| 关键镜头（高潮、情绪最重的、开头结尾） | 多拍几条不同写法的，看片挑最好的，不是第一条合格就用它 | [checks](checks.md)「挑好」 |
| 每次生成后 | 对表查切点、开头插进来的参考图构图、配乐、多出来的人声和口型、物理和场景讲不讲得通（门的开向、道具状态接不接得上）；同一个毛病连着出就改写，不只换种子 | [checks](checks.md) |
| 片段要拿去接下一段 | 接缝要用的那几秒里不能有模型自带的切镜；片段中间的可以留 | [own-cuts](own-cuts.md) |

## 常见错和怎么查

- 只报告不改；一个动作演了两遍、道具状态接不上：见 [checks](checks.md)「查什么」第 6 条和「重抽」。
- 镜头一多，后面的镜头查得不仔细：见 [checks](checks.md)「什么时候用」。

## 按类型

- 动作、打斗：分镜单元，一次调用放一个回合；每镜一个动作，写碰在哪、对方怎么反应，风格段写明笨重、真实、不摆造型。用了白模的：打斗和连续肢体戏不拿白模关键帧当首帧，白模只给站位；门、楼层、谁站哪这类走位戏才用白模关键帧当首帧。
- 剧情、多人对戏：分镜单元；要说的台词逐字落在镜头上，每句绑定说话人，别人闭着嘴听；片子不要人声时，台词改成动作。
- 旅程：每段一个地点，单镜为主，结尾留出衔接要用的那几秒。
- 科幻、大场面：要跨越很大的空间时（地面 ↔ 天空、城里 ↔ 海边），单独生成一段运镜（首尾帧过渡段），拆成几次调用。
- 二维动画：每段提示词开头放同一句画风描述；续写里写明画风和上一段一样。

## 用了白模（blender_extra）

镜头表「空间」一栏有镜头上白模时（要有 blender-previz skill），这一步多出来的：

- **多做的**：一镜挑一种喂法：关键帧当首帧、首帧 + 尾帧、放进分镜单元、替身预演当参考视频。带参考图、参考视频的喂法，一定带上这一镜的关键帧。
- **多交出的**：查过的片段。
- **往下走之前**：白模带来的几样查过：位置、白模的东西有没有进画面、人有没有站成柱子、片尾跳帧、黑边。

做法在 [blender_extra/](blender_extra/overview.md)；几步都要知道的（白模管什么、不管什么）在 [common/blender_extra](../common/blender_extra.md)。

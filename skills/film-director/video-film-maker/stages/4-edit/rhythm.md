# 节奏：镜头多长、慢动作、变速

一句话：大片的节奏靠镜头长度：动作段一两秒一镜，撞击用慢动作拉长，情绪段放慢；慢动作在生成时直接写高帧率，剪辑里只抽帧加速，不插帧。

## 什么时候用

排镜头时长（[时长预算](../1-storyboard/shot-list.md)、[分镜单元](../3-generation/shot-unit.md)）和剪辑时。

## 好用的规则

- **镜头多长**（大片）：平均两三秒一镜；动作镜头 1.2–2.5 秒；慢动作的撞击镜头约 3–3.5 秒；情绪段 3–5 秒，最长约 5 秒。高潮段可以缩短到约 1 秒一镜。
- 照真实电影拍时，直接照原片每镜的长度排。
- **慢动作（升格）**：只在要慢的镜头里写「慢动作（升格，像每秒 120 帧拍摄后放慢）」，直接生成。剪辑里只抽帧加速（2 倍、3 倍），不插帧，也不把相邻帧混在一起。要「快 → 慢 → 快」，就用慢动作素材，两头抽帧加速、撞击那段原速。
- **放慢补帧**：镜头比要的短一点，可以整镜均匀重复一些帧、放慢补齐，还是不插帧。放慢一成左右看不出来，放慢三成以上就看得出一顿一顿；差得多就重拍。
- **取帧**：每镜从生成视频里量出来的实际起点开始取，取够要的时长；短了，这一镜就提前几帧结束，下一镜提前几帧开始、多取这几帧，后面的切点都不往后推，不插帧，误差不累积。
- 节奏也在声音里：撞击前把声音整体压低，高潮前留一拍安静（见 [声音设计](audio.md)）。
- 停顿：生成出来的停顿常比要的短，所以排时长时多留 1 秒；剪辑时停顿太长的再剪短（见 [时长预算](../1-storyboard/shot-list.md)）。

```
for shot in edit:
    src = clip[shot.real_start : shot.real_start + shot.len]       # 从实测起点取
    if shot.speed > 1: src = drop_frames(src, shot.speed)          # 只抽帧加速
    if len(src) < shot.len:
        src = stretch(src) if shot.len / len(src) small else carry_over_to_next(shot)
```

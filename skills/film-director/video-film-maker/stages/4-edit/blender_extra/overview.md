# 用了白模：剪辑和成片检查多做的

一句话：上白模的片子里单独生成的镜头多，剪的时候多几处要裁、要铺；查的时候多一份标准答案，就是白模。查出的毛病先分清是哪一步带进来的，回到那一步改。要有 blender-previz skill。

## 什么时候用

成片里有上白模的镜头。别的照 [edit-render](../edit-render.md) 和 [成片检查](../final-check.md)。

## 思路

1. **剪**：
   - 首帧 + 尾帧的镜头：片尾 2–3 帧一律裁掉，剪在动作刚到位的那一帧。
   - 首帧是动作之前的静止样子：片段开头常有一小段起步，取靠后的一段。
   - 分镜单元：按量到的切点裁，不按表上的数。
   - 参考视频喂出来的镜头：上下有黑边的，裁掉再放大（[画幅](../frame.md) 第 2 条，重新取景），或回去换喂法。
   - 单独生成的镜头之间环境声不连续：每段两端加很短的淡入淡出，全片统一铺一层环境声（[声音设计](../audio.md)）。
   - 撞击声比画面晚的，把这一镜的声音往前挪。
2. **查**，在 [成片检查](../final-check.md) 之外：
   - 每个上白模的镜头一行三栏对照：白模 | 关键帧 | 成片的头、中、尾。
   - 相邻两镜的接缝对着白模的时间线：上一镜最后一帧和下一镜第一帧，人在哪、朝哪、手在哪，应当是同一个时刻的样子。
   - 白模的东西有没有留在成片里：人偶、占位块的颜色、胸牌、柱子。
3. **改**：先在三栏对照里分清是哪一步错的，再回到那一步。

| 三栏里看到的 | 回到哪 |
|---|---|
| 白模里就是错的：门洞被画成门板、人坐在靠背上、东西悬在半空 | 改白模，这一镜的静帧、关键帧重出，重拍 |
| 白模对、关键帧画错了：背景、站位、人的大小、道具状态 | 重画这一张关键帧，重拍 |
| 关键帧对、视频跑偏：门开反、转头反了、有人整镜不动、镜头切到别处 | 换喂法或改提示词：加尾帧、只给首帧、首帧的提示词只留动作 |
| 人站成柱子、动作像人偶 | 预演换成只放替身的那版，或这一镜不给参考视频 |
| 站位都对，就是没戏 | 不是白模的事：回镜头设计和 [表演](../../3-generation/acting.md) |

```
for shot in 上白模的镜头: view(trio(still[shot], key[shot], clip[shot]))       # 白模 | 关键帧 | 成片
for a, b in 相邻两镜: same_moment(last_frame(a), first_frame(b), 白模的时间线)
for problem in problems: step = 哪一栏先错的(problem); 回到(step) 改; 重拍
```

## 好用的规则

- 没有白模那一栏的对照，不算查过位置：只看成片，分不清是白模错、关键帧错，还是视频跑偏。
- 同一个毛病拍了两条都出现，就不是运气：回到对应的一步改，不是换种子。
- 查出来能改的，预算还有就改掉，不只写进报告。

## 动手前查

- 三栏对照、切点、最后几帧怎么看：blender-previz skill 的 `stages/4-check/overview.md`「推荐」；工具是它的 `scripts/cut.py`（`trio`、`cuts`、`split_unit`、`strip`、`onsets`）。
- 每种毛病多半是因为什么、改哪一步：同一篇的「毛病和改法」。

# 剪辑和渲染（通用规范）

一句话：所有剪辑决定写进一张剪辑表，一个脚本照表一次渲染出成片和标注版；改剪辑只改表，不手动拼。

## 什么时候用

生成和检查做完、开始剪的时候。每部片都要自己写剪辑脚本，这是最花时间的一步（几部测试片的记录里都这么写）；照这里的格式写，下次能直接改着用。

## 剪辑表（每段一行）

- 源：哪次调用、第几次抽、哪一镜。
- 入点、出点：按帧号写，不按秒，避免差一帧。
- 在成片里从第几秒开始。
- 处理：变速（加速只抽帧，放慢补齐只重复帧，不插帧）、画幅裁切（取景带的上下位置；取景带是裁宽银幕的那条窗口）、镜像。
- 转场：硬切、叠化几帧、淡入淡出。这一栏照镜头表「接」一列抄。镜头表里定了的接法（剪在动作上、J-cut、声音搭桥），每一条都写进这一栏和下面的「声音」一栏；剪完核对一遍，每一条都做到了。
- 声音：用本段原声，还是换成哪一段的；L-cut、J-cut 延多少秒；这段声音调低多少 dB。
- 备注：为什么这么剪。

## 渲染顺序

1. 照表逐段切；变速、裁切、镜像。
2. 拼接和转场。
3. 调色：全片一套参数，分场景再微调（见 [调色](color.md)）。
4. 声音：清理、换声、补动作声、配乐、混音、响度统一（见 [声音设计](audio.md)）。
5. 编码：成片只在最后编码一次；H.264、yuv420p、faststart，帧率全片统一。
6. 另出标注版：画面角上写每段来自哪次调用、第几次抽、哪一镜。
7. 照 [成片检查](final-check.md) 从头查一遍。

```
for row in edl:
    seg = cut(row.source, row.in_frame, row.out_frame)        # 按帧切
    seg = retime(crop(mirror(seg, row)), row.speed)           # 只抽帧不插帧
    film.append(seg, transition=row.transition, audio=row.audio)
film = grade(film); film.audio = mix(film.audio)              # 调色、混音
encode(film); encode(burn_in(film, edl.labels))               # 成片 + 标注版
```

## 规则

- 按检测出的切点剪时，剪点要比切点再往这一镜里面挪 2–3 帧。检测出的切点会差 1–3 帧，照着剪，会露出上一镜的几帧（[切点检测](../3-generation/own-cuts.md)）。
- 剪完对着镜头表数一遍，每一镜都在：半秒的对视、听的人的反应，最容易在把片长凑到目标时长时丢掉。
- 借别段的环境声以前，先用语音识别把那段转成文字，确认没有人声。
- 不同模型帧率不同（Wan 30 fps，HappyHorse、Seedance 24 fps），一部片统一一个帧率，换算时只抽帧或重复帧，不插帧。
- 每一步都直接从生成出来的原始视频（源片）切素材，源片原样留着，中间不存一版又一版转码过的文件，成片只在最后编码一次；长片按段流式处理，不要把所有帧一次读进内存。

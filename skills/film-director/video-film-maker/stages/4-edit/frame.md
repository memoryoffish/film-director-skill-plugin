# 画幅：宽银幕、重新取景、稳定、镜像

一句话：要宽银幕就按宽画幅生成再裁成 2.39:1，或按 16:9 生成、用一条能上下移的取景带裁；固定机位的画面会慢慢漂移，事后做稳定来抵消；镜像能改人物朝向，代价是左右位置也跟着翻。

## 什么时候用

定画幅（生成之前）和剪辑时。

## 思路

1. **宽银幕**：
   - 按宽画幅生成，提示词写「人物头部、关键动作放在画面中间约四分之三的高度里」，剪辑时裁成 2.39:1、上下加黑边。
   - 或按 16:9 生成，剪辑时用一条 2.39:1 的取景带裁，每镜上下移动取景带（一次实测）。
   - 照真实电影拍：先量原片画幅（有没有黑边），按同样的画幅生成。
   - 模型自己加的上下黑边先裁掉，全片再统一加上下黑边。
2. **重新取景**：在取景框里放大、平移，把画面边上的毛病（镜子里多出的人、多余的道具、多露出的座舱）移出去。放大过的镜头画面会发虚、不锐利，所以别放大太多。
3. **稳定**：固定机位也会慢慢推拉、平移。在画面里不动的区域逐帧配准，拟合一条平滑的运动曲线，反过来抵消，再略微放大，免得边上露出黑边。遮挡物盖住参照区域的那一段，稳定会失效。
4. **镜像**：左右翻转能改人物朝向，让视线、运动方向接上前后镜；人物外形左右对称时，看不出画面翻转过。代价是人在画面里的左右位置也翻过去了。
5. **固定的叠加图形**（瞄准镜的光环、仪表）不让模型画：只生成干净的画面，剪辑里统一叠上去，每镜位置、大小一样。

```
crop = scope_band(frame, ratio=2.39, y=shot.band_y)               # 每镜可以上下移
if shot.hide: crop = zoom(crop, k, anchor=shot.anchor)             # 藏住边上的毛病
if shot.locked_off: frames = undo(smooth_fit(register(frames, still_box)))
if shot.flip: frames = mirror(frames)                              # 左右位置也翻了
```

## 生成后检查

- 裁切后头、手、关键动作还在框里。
- 黑边区域干净；稳定后边上没露出黑边。
- 镜像过的镜头，前后镜的左右位置还接得上。

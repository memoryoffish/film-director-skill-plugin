# 和原片逐镜对照

一句话：照真实电影（或照一张分镜表）拍时，每个单元生成后做一张「原片 | 生成」逐镜对照图：一行一镜，左边原片、右边生成视频里同一相对时刻的帧，反复看；生成视频里的切点，用量出来的时间去对表。

## 什么时候用

复刻真实电影的每个单元生成之后、每次修复之后；照分镜表拍的片子也可以拿分镜表代替原片。

## 思路

1. 量切点：两种方法一起量（颜色分布跳变 + 相邻帧画面差），量出的切点逐个和表上的切点对。
2. 做对照图：每行一镜，原片取镜头内靠前、中间、靠后三帧（离切点留一点，别取到边界上），生成视频按计划的秒数取同一相对时刻的帧；原片很暗的帧先把亮度范围拉开再贴进图里，并标出来。
3. 逐镜看：景别、机位、左右位置、朝向、视线、动作、外貌、状态（面罩扣没扣），有没有多出来的人、鬼影、文字。
4. 全片拼好后再做一张总览，查跨单元的人物、服装、光线、运动方向。
5. 能量化的就量：车的转向用车窗外景物的横移量（相邻帧相位相关累加），和原片的曲线画在一张图上比。
6. 每镜记一个结论：对上 / 大体对上 / 没对上；没对上的进 [定点修复](fixes.md)。

```
for shot in table:
    o = frames(original, shot, at=[early, middle, late]); g = frames(generated, shot.planned, at=same)
    row(brighten(o, mark="*") if dark(o) else o, g, label=shot.id)
sheet(rows); overview(film, every=2s)
if shot.turns: plot(pan_curve(original, shot), pan_curve(generated, shot))
```

## 好用的规则

- 原片只用来对照，不进模型的输入。
- 每修一次重做一张对照图，反复看；修完再用新旧成片逐帧比较，确认只改了该改的镜头。
- 上原片、下成片、时间轴相同的对照视频适合整段看节奏；对照图适合逐镜挑毛病。

# 动作匹配（剪在动作上，match on action / cutting on action）

一句话：同一个人做同一个动作，从一个景别或角度切到另一个，剪点放在动作进行到一半，后一个镜头从动作的同一阶段接着演，观众跟着动作走，注意不到这一刀。

（示例视频：ex-match-on-action-01.mp4，没有放进仓库。颠锅抛煎饼（1.77–5.77 s））

木屋厨房里的男人颠锅抛煎饼，正面中全景 → 右侧约 60° 中景 · 2 次调用 · 转场在 3.27 秒（煎饼最高点）

## 什么时候用

同一个动作要换景别或换角度时。第一个画面里动作已经做完再切，或者提前切了特写，两个画面就是独立的，没有剪辑关联。不是同一个动作、而是同方向的动势承接，用 [动势剪辑](momentum.md)。

## 思路

1. #1：固定机位，动作写清时间点和左右位置（用哪只手、在画面哪一侧）。
2. 从 #1 截人物（和道具）当参考图。
   - 只换景别、角度不变：可以再放一张空场景图，场景也对得上。
   - **要换角度：参考图只放人物**，场景用文字写（同样的木墙、铜锅、窗）；放了场景图，模型会照搬 #1 的机位。
3. #2：同样的手、同样的顺序和大致时间；**机位写成固定不动**（三脚架、不移不推不摇），抛起的东西写「一直在画面里」，不然镜头会跟着它上摇、后拉。
4. 找剪点：两段里动作的**同一阶段**，按画面里量出来的位置找，不按提示词里的秒数。
5. 硬切。比一下 B 在剪点后的动作速度和 A 的动作速度，差得多，再给 B 的开头变速。

## 好用的规则

- 剪点在动作**进行到一半**；抛起的东西**剪在最高点**。
- 角度变化至少 **30°**，提示词里的角度写得比想要的大（要 45° 就写正侧面）；景别也写得比想要的更近。
- 两边动作速度差得多才变速（差多少算多见 [细节](../../examples/edit/match-on-action/notes.md)）。
- 画面里有两个人时，每一镜写清各自的左右位置，防止换机位后左右互换；换到对面机位，模型会用靠镜头一侧的手做动作，要哪只手就写明。

## 生成后检查（不合格就重抽）

- 角度、景别变化够不够大（不到 30° 就是跳切）。
- 镜头有没有跟着物体上摇、后拉（机位要固定不动）。
- 人、衣服、道具前后一致。
- 运动的物体是不是连续的：每几帧停一下（一顿一顿）就重抽；这种毛病检测脚本查不出来，要逐帧看物体。
- 动作的同一阶段在 B 里确实出现（B 别先把动作做完了）。

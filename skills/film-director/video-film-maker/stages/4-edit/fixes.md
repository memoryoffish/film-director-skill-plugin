# 修补：局部重画、补小特效、遮掉、定点换镜

一句话：模型画不对、重抽也改不过来的小地方，在剪辑里修：局部重画（表盘）、补小特效（白印）、用取景框遮掉画错的东西；大一点的毛病按镜头定点修复，只换那几镜。

## 什么时候用

重抽两三次还是同一个毛病；或者后面的段已经从这一段截了参考图，不能重抽。

## 思路

1. **局部重画**：画面里一块固定的东西画错了（挂钟的时间）。选一帧当底图，抹掉画错的部分、按原来的颜色画对，逐帧把那一块换掉，亮度按周围一圈逐帧对齐；机位稳就不用跟踪。下一段要接这个画面时，用重画好的那一帧当首帧。
2. **补小特效**：手指上摘了戒指的白印、伤痕：跟着手的位置补画，几帧淡入。
3. **遮掉**：画面边上多出来的人、道具、镜子里的人，在取景框里放大、平移移出去（见 [画幅](frame.md)），或剪掉那几帧；模型在片段里自己多切出来的镜头切换，可以加一段甩镜头式的运动模糊盖住。
4. **交给剪辑做**：叠脸、水里的倒影、匹配叠化、开关灯这几种，先单独生成干净的素材，再在剪辑里做：叠脸和匹配叠化是叠加，倒影是翻转，开关灯是改亮度。
5. **定点换镜**：
   - 每处做一个两镜单元（带上相邻的一镜），成片只用要修的那一镜（见 [分镜单元](../3-generation/shot-unit.md)）；或者做一次很短的调用，要用的镜头生成得比要的长，后面接一个计划好、成片里不用的镜头（空镜或另一个人的特写），模型就会在计划的地方切走，不在要用的那一镜中间自己多切一刀；再从里面挑动作对得上的一段。
   - 要改的东西（转向、视线、面罩）写在提示词的第一句，或「本单元重点」那一行；参考图换成对应状态的那一套。
   - 换上时帧数不变、别的镜头不动；原来的声音能留就留，换了新声音，就把这一镜的音量调到和前后镜头差得不多（复刻片照原片里这几镜之间的响度差调），新声音越过这一镜结尾的那一小截里有杂音就截短。
   - 新旧成片逐帧比较，确认只改了那几帧。

```
fix(shot):
    unit = [neighbour(shot), shot]                                  # 两镜单元，只用第二镜
    unit.header += "本单元的重点在镜头2：" + what_to_fix(shot)
    unit.refs = refs_for_state(shot)
    for take in 1..TAKES: clip = generate(unit); if looks_right(clip, shot): break
    film = replace(film, shot.frames, clip[shot.range], keep_audio=True)
    assert diff(film, old_film) only inside shot.frames
```

## 好用的规则

- 先判断重抽还是修：后面已经从这一段截了参考图，就修，不重抽。
- 修过的地方逐帧看接缝前后（重画的边缘、补画的淡入）。
- 修复也会留差别：修完还对不上的写下来，不硬凑。

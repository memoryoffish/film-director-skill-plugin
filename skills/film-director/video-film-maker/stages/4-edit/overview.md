# 4-edit：剪辑与成片

照镜头表把片子剪出来，统一节奏、画面和声音，对照着查，最后给用户挑。

## 这一步交出什么

- 剪辑表：每个接缝怎么接，从镜头表「接」一列抄过来。
- 成片，和画面角上写着每段出处的标注版。
- 交片之前：剪辑表对过镜头表，成片连着看过一遍、接缝逐帧看过。见 [final-check](final-check.md)。
- 最后给用户盲选，按选择接着改；每轮结果记进 [经验账本](../../refs/practical/experience.md)。

## 什么情况用哪种做法

| 情况 | 做法 | 细节 |
|---|---|---|
| 开始剪 | 所有剪辑决定写进一张剪辑表，一个脚本照表渲染出成片和标注版；改剪辑只改表 | [edit-render](edit-render.md) |
| 单元和单元之间 | 多人、多机位的一场戏，换机位硬切，不接龙。同一个动作跨两镜，剪在动作上（剪点放在动作进行到一半）。同一个人做大动作、换了机位（视角变化 ≥ 30°）的两镜，剪在动势上 | [cut-not-chain](cut-not-chain.md)、[match-on-action](match-on-action.md)、[momentum](momentum.md) |
| 声音比画面先进来；画面切走后声音还延续；用相似的声音搭桥；用声音的反差转场 | J-cut、L-cut、声音搭桥、反差转场 | [sound](sound.md) |
| 慢动作 | 在生成时写升格，剪辑里只抽帧加速、不插帧 | [rhythm](rhythm.md) |
| 生成的片段里有不想要的配乐 | 先只把音乐分离掉，留住动作声。分不干净再重抽，或换成干净的环境声；换了环境声，要把动作声补回来 | [audio](audio.md) |
| 要配乐 | 只在一个单元里响的配乐，生成这个单元时让模型一起配。跨单元、贯穿全片的配乐，不让各单元各配，因为各配各的接不上；后期给全片加一条统一的：先让视频模型生成一段只为取配乐的片子，只用它的音轨，不满意再找现成的曲子。片子要不要配乐，开工前问用户 | [audio](audio.md) |
| 台词 | 用生成时一起出的原声，这一步只混音、加字幕；声音不对回第 3 步重抽或 [补人声](../3-generation/revoice.md) | [audio](audio.md) |
| 有原片 | 做原片和生成视频左右并排的逐镜对照，反复看；没有原片，就对着镜头表查切点 | [compare](compare.md) |
| 成片出来 | 接缝要人眼逐帧看：检查脚本报告遮挡物已经盖满画面、两段已经对上，也可能是错的；再跨镜头看一遍物理和场景讲不讲得通（门的开向、道具状态、特写前有没有交代） | [final-check](final-check.md) |
| 成片里有上白模的镜头 | 片尾几帧、黑边、环境声多几处要处理；白模、关键帧、成片三栏对照，毛病回到带进来的那一步改 | [blender_extra](blender_extra/overview.md) |
| 看完成片 | 挑出最弱的两三镜，换写法重拍再剪；关键镜头的候选能给用户挑就给用户挑 | [final-check](final-check.md)、[blind](blind.md) |
| 交片 | 给用户盲选（几版片子或关键镜头的候选），按用户的选择和评语接着改，改到用户说好 | [blind](blind.md) |

## 常见错和怎么查

- 定好的接法没做、镜头剪丢了、切点不准露出了上一镜的几帧：见 [edit-render](edit-render.md)。
- 逐镜都合格但连起来乱、讲不通的镜头留在了成片里、检查脚本报告通过其实没过：见 [final-check](final-check.md)。

## 按类型

- 动作、打斗：单元之间剪在动作上。慢动作生成时写升格，剪辑里抽帧加速；撞击前把声音整体压低；用宽银幕；调色偏冷暖对比。查动作接不接得上、谁打谁看不看得清。
- 剧情、多人对戏：台词用生成时的原声，后期混音、加字幕；台词底下的环境声调低但不断掉，跨过剪点也连着；查越轴、换人、谁看谁。
- 悬疑：声音设计做张力（静和响的反差、滴水、钟声）；画不对的道具在后期重画。
- 回忆：回忆段单独调色（褪色、偏暖）。
- 文艺、抒情、武侠：配乐常是情绪的一半；开工前问用户要不要、从哪来，要就后期给全片加一条，配乐跟着节拍进出（没人回答时见 [规矩](../common/rules.md)「没人回答时」）。
- 二维动画：接缝处 A 结尾是虚的色块、B 开头是清楚的画面（从虚变实），在剪辑里给 B 开头补一层慢慢退掉的模糊；查画风有没有中途变。
- 照电影复刻：按原片逐镜调色；逐镜对原片，切点、景别、方向一镜一镜比。

## 用了白模（blender_extra）

镜头表「空间」一栏有镜头上白模时（要有 blender-previz skill），这一步多出来的：

- **多做的**：片尾几帧、黑边、环境声多几处要处理；白模、关键帧、成片三栏对照；毛病回到带进来的那一步改。
- **多交出的**：每个上白模的镜头一行三栏对照；一份毛病清单，每条写明回到哪一步改。
- **往下走之前**：清单里能改的，预算还有就改掉。

做法在 [blender_extra/](blender_extra/overview.md)；几步都要知道的（白模管什么、不管什么）在 [common/blender_extra](../common/blender_extra.md)。

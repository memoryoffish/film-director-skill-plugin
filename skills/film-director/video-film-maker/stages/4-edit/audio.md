# 声音设计

一句话：生成出来的原声里，次声、嗡声、没要的配乐和多出来的人声都要清掉。配乐分两种：只在一个单元里的，生成这个单元时让模型一起配；跨单元、贯穿全片的，各单元各配各的会接不上，所以后期给全片加统一的一条（先让视频模型生成一段只为取配乐的片子，只用它的音轨，不满意再找现成的曲子）。片子要不要配乐，开工前问用户。清掉没要的配乐时，先只去掉音乐，留住动作声。然后用声音做节奏（撞击前把声音整体压低，高潮前留一拍安静）。台词用生成时一起出的原声，混在最上层，不后期配音，字幕后期加。接缝处交叉淡化，全片响度统一。

## 什么时候用

剪辑定稿之后。每种声音转场（搭桥、L-cut、反差、J-cut）的做法见 [声音转场](sound.md)。

## 思路

1. **清理**：
   - 原声里常有大量次声，先做低频高通；频率固定的嗡声，用窄陷波滤掉。
   - 查出的没要的配乐、持续的和弦、多出来的人声（查法见 [生成后检查](../3-generation/checks.md)），按代价从低到高处理：
     - 先试只去掉音乐：音源分离把音乐分出去，留下动作声和台词（还没实测，先听一遍分得干不干净）；
     - 分不干净，就重抽这一段，短单元重抽不贵；
     - 最后才整段换成同一段里、或同一场景别的段里干净的环境声。换了就把这一段的动作声一个个补回来（硬币、打火机、脚步），按画面里发生的那一帧放，别让这一段只剩底噪。
2. **节奏**：
   - 撞击前零点一到零点三秒把声音整体压低，撞上的那一帧，低频闷响以全音量进来；
   - 高潮前一两秒把声音调低到只剩一口呼吸，留一拍安静；
   - 铃声、钟声这类标志声用 L-cut 延到下一镜。
3. **接缝**：交叉淡化。用首帧或首尾帧和上一段接上的那一段，开头几乎没有声音：把上一段的声音跨过接缝延 0.3–0.4 秒再淡出。每镜单独生成一条的片段，或者分镜单元和单镜头的片段混着剪时，各条自带的环境声接不上；这时在全片底下垫一层同一段环境声，这段环境声取自干净的片段。
4. **响度**：各次生成的响度能差十几到二十五 dB，逐段调到一致；动作段比安静段响一些；最后全片统一响度、过限幅。
5. **台词**（怎么写、怎么查见 [台词](../3-generation/dialogue.md)）：
   - 不配音、不换声音：后期配的音色怪，和画面里的人对不上，合成语音配音尽量别用。声音不对就回生成重抽那一镜（见 [台词](../3-generation/dialogue.md)）；成片剪好才发现缺声音，用参考视频连声音重拍（见 [补人声](../3-generation/revoice.md)）。
   - 混音：台词在最上层，底下的环境声调低但不断掉，跨过剪点也连着；字幕后期加，人工校一遍。
   - 不要人声的片子，台词照旧改成动作。
6. **配乐**（开工前问用户要不要；没人回答时见 [规矩](../common/rules.md)「没人回答时」）：
   - 只在一个单元里的音乐（一段蒙太奇自己的曲子，画面里有来处的音乐：收音机、现场弹唱）：生成这个单元时让模型一起配。提示词里写声音的那段，写清乐器、情绪、速度、哪里起哪里收。它不跨出这个单元，没有接不上的问题；生成后听它是不是照写的地方起、收，有没有盖住台词。
   - 跨单元、贯穿全片的音乐：不让各单元各配，因为各配各的接不上；这些单元的提示词照旧写不要配乐。后期给全片加统一的一条：
     - 先让视频模型单独生成一段片子，只取它的声音。提示词写乐器、情绪、速度、哪里起哪里收，画面随便（空镜），写「只有音乐，没有人声和环境声」；长片分几段生成，按节拍接。
     - 不满意，再找现成的曲子加上去：看听过的人留下的评价和下载量，查许可证能不能用（只取 CC0、CC-BY 这类写明能用的，记下出处）；有 refsound skill 就照它的做法挑。用户给了曲子就用用户的。
     - 加配乐时跟着节拍进出，高潮前停一拍，有台词的地方把配乐调低。
   - 不要配乐时：情绪靠环境声和动作声撑，安静段要有东西可听（雨、钟、呼吸）。
   - 文艺、抒情、武侠这类片子，情绪常有一半在配乐里，问用户时提一句。
   - 《纸飞机》《雨停之前》用 Seedance 单独生成配乐做成了；Wan、HappyHorse 还没试。单元里让模型一起配、找现成的曲子，这两条还没实测。好不好听要用户耳朵听。

```
a = highpass(raw, LOW_CUT); a = notch(a, hum_freqs(a))
for seg in music_or_speech(a):
    seg = remove_music(seg) or regenerate(seg) or replace(seg, clean_ambience(same_scene), xfade=XF)
    place(action_hits(seg), at=impact_frames)                     # 换掉的段补回动作声
for hit in impacts: duck(a, hit - PRE, hit, DIP)                  # 撞击前收声
duck(a, before_climax, QUIET)                                     # 高潮前留一拍安静
a = keep(lines_from_generation); duck(ambience, under=lines)  # 台词：用生成时的原声，不配音
if film.wants_score: a = mix(a, duck(score_from_video_model(), under=lines), follow=beats)  # 全片配乐：视频模型单独生成，不满意找现成的
a = level(per_segment(a)); a = limiter(loudness_normalize(a, TARGET))
```

## 好用的规则

- 没要的配乐只出现在一段视频的其中几秒时，用这一段前面干净的几秒声音换掉，不重抽；后面已经从这一段截了参考图时尤其如此。换完听一遍，这一段该有的动作声还在不在。
- 借别段的环境声以前，先用语音识别把那段转成文字，确认没有人声（HappyHorse 版《纸飞机》借来的环境声里带着台词）。
- 换声音时交叉约四分之一秒；单独一声的短声交叉要短到几十毫秒，交叉太长，这一声开头那一下就听不出来。
- 剪辑工具默认加的合成音效（光晕转场带的风声、快门声），要关掉。

## 生成后检查（成片）

- 全片再查一遍生成时带进来的没要的配乐、持续的和弦、多出来的人声（后期加的、单元里写明要的配乐不算）；被换掉声音的段，动作声都补回来了；台词逐字对原文、对得上口型，字幕和台词一致。
- 接缝前后响度没有突然跳高，也没有突然塌下去一截。
- 全片响度达标（目标见 [refs/practical/config.md](../../refs/practical/config.md)）。

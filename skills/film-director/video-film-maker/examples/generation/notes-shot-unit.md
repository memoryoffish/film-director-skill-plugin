# 分镜单元：例子和细节

从 [一次调用放哪些镜头](../../stages/3-generation/shot-unit.md) 挪来的：拳馆 u05 的分镜表、伪代码、几条规则的细节、实测状态。默认值记在 [refs/practical/config.md](../../refs/practical/config.md)「分镜单元」。

## 例：拳馆 u05（有删节）

```text
本单元共 6 个镜头，剧情时长 14.60 秒……相邻镜头交界的秒数就是切点；表中没有的切点不要加，表中有的切点不能省。
14.60 秒之后直到成片结束（约 0.40 秒），延续最后一个镜头的画面与运动，不要切到新镜头。
镜头3｜2.60–4.20 秒｜机位与景别：全景，地面机位低角度仰拍，广角｜以“硬切”从上一镜头切入
  画面：他在画面左侧，抡起右臂，用全身的重量朝画面右侧的沙袋打出一记很大的右摆拳……
镜头4｜4.20–7.80 秒｜机位与景别：近景，侧面，固定，慢动作（升格，像每秒 120 帧拍摄后放慢）｜以“硬切”从上一镜头切入
  画面：沙袋从画面右侧猛地荡回来，重重撞在他的胸口……
（后面接全片共用的风格、场景设定、主要物体、人物、声音、要求）
```

## 伪代码

```
for group in split(shots, max_len=MAX_CALL):
    story = sum(s.len for s in group);  duration = ceil(story + TAIL)
    prompt = HOLD_LAST + table(group, times=cumsum(rounded to 0.01)) + SHARED_STYLE + SHARED_SCENE + SHARED_CAST + SHARED_SOUND
    clip = generate(prompt, refs=refs_for(group), duration=duration)
    check(measure_cuts(clip), group.table)                               # 见 checks.md
```

## 好用的规则

- **镜头内的动作只写先后顺序，不写时间段**：只写一个「约 X 秒」多数没事。
- **最后一镜**：后面多接一个不用的镜头（计划好的空镜、特写），剪辑时只用前面的部分。
- **修单个镜头时做成两镜单元**：带上相邻的一镜（放前放后都行，也可以是剪法里不相邻、但机位相同的一镜）就稳了。
- 一个单元常见两到八镜；单元中间放一个零点几秒的闪切也切得准（一次实测）。

## 状态

实测有效：拳馆大片版和 4 部电影复刻都用这种写法，单元内的切点基本都和表对得上（数字在各案例的「关键数字」）。「镜头内写时间段会多切」在 4 部复刻里都出现过；拳馆有两处写了时间段没多切，样本少。

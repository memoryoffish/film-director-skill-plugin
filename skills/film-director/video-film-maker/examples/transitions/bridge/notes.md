# 首尾帧过渡段：细节

从 [首尾帧过渡段](../../../transitions/bridge.md) 挪来的原文：伪代码、各处的秒数和帧数、一次实测的备用接法、苹果式三种（只从视频学来，未实测）。每次实际用的值见案例。

## 伪代码

```
c1 = generate(p_start)
c2 = generate(p_rise_and_dive_into_cloud, start_image=last(c1))        # 不给尾帧
c3 = generate(p_descend, start_image=last(c2))                          # 或 refs=人物图 + 云里叠化
for c in (c2, c3):
    if whole_frame_double_exposure(c) or not fills_with_cloud(c2.tail): retake(c)
join([c1, c2[1:], c3[1:]], speed up c3's head if it starts still)
```

## 带数字的规则和检查（原文）

- 要锁前面出现过的人：#3 用人物参考图，第一帧写「一片云」，#2 → #3 在满屏的云里叠化约 6 帧。

- #2 最后约 **0.5–1 秒满屏是云**（或雾、烟、水下气泡），下一次调用从这里接。
- 从信息少的画面生成到信息多的画面（太空 → 海滩）风险高；反过来（海滩 → 太空）稳，要「落下来」就生成「拉远」再**倒放**，时长 2–3 秒，两帧要有共享的连接件（如海岸线）。

- 过渡段没冲进满屏的云也能接：剪在镜头开始停住之前的那一帧，下一段首帧就用这一帧（一次实测）。

- #3 开头是否长时间不动（超过约 2 秒）：加速补；补不回来就换首帧那一帧。

## 苹果式三种（只从视频学来，未实测）

- **钻入式**：「镜头快速掠过 图片1 的 <物体/墙面>，来到 图片2 的场景，穿过时可以看到 <物体> 的内部视角。」可钻：格栅墙、包、钢琴、相机。
- **玩具屋**：把房间俯拍图改成微缩模型合成到物体背后，再「摄像机视角环绕到相机背后，相机背后有一个微缩房间」。要图像编辑模型。
- **空间平移**：「相机垂直向下移动穿过厚厚的地板，从二楼无缝过渡到一楼」。

# 首尾帧过渡段：案例

两地差得远时单独生成中间的运镜（升空、穿云、降落），拆成几次调用，每次用上一次的最后一帧当首帧。方法写在 [bridge.md](../../../transitions/bridge.md)。

当前推荐：[01 晨雾松林 → 升到云海之上 → 扎进云里 → 落到日出雪山顶](01-forest-cloud-peak.md)。

每篇是一次实际跑过的：视频、调用、提示词原文、剪辑数字、复现命令、生成后检查、踩的坑（在 Wan 3.0 上做的）。

- [01 晨雾松林 → 升到云海之上 → 扎进云里 → 落到日出雪山顶](01-forest-cloud-peak.md)：当前推荐。戴红头巾的登山者：#1 晨雾松林，#2 镜头升过树冠到云海之上、结尾一头扎进满屏的云，#3 从云里降到日出的雪山顶。
- [notes.md](notes.md)：从方法正文挪来的细节（不是一次实跑）：伪代码、各处的秒数和帧数、仿苹果发布会的三种无缝转场（钻入式、玩具屋、空间平移；只从一个 B 站视频学来，未实测）。

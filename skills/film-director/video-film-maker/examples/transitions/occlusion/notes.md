# 遮挡转场：细节

从 [遮挡转场](../../../transitions/occlusion.md) 挪来的原文：完整的思路、伪代码（盖满怎么判断）、带数字的规则、完整的检查清单。门槛的默认值在 [refs/practical/config-transitions.md](../../../refs/practical/config-transitions.md)「衔接检查」；每次实际用的值见各案例。

## 思路（原文）

接缝上的毛病（跳帧、刹车感、色调不一致、割裂）都出在接缝那一格。让物体暂时挡住视野，剪辑就发生在被挡住的那一刻：

原画面 → 遮挡进入 → 视野被盖满 → **切换** → 遮挡离开 → 新画面

遮挡负责藏住断点，运动负责建立连贯感。被盖满的那一格几乎没有信息，连场景检测都找不到这一刀。

1. 写 A：把最后约 2 秒写清楚：镜头往哪走、什么东西从哪一侧贴着镜头进来、盖满整个画面。
2. 在 A 的尾部找盖满的帧当剪点（模型不会停在盖满上，遮挡物会接着移走）。
3. 生成 B，两种接法：
   - **首帧接**：B 的首帧 = A 的剪点帧，B 写「镜头继续同方向走，遮挡物从另一侧移出，露出新地方」。接缝帧级一致，但 B 首帧里没有人，人物会变。
   - **参考图接**（要锁人物时）：B 不给首帧，给从 A（或第一段）截的人物参考图，提示词写「第一帧被同一种遮挡物盖满」。两边的遮挡帧不是同一帧，在遮挡帧之间叠化几帧。
4. 量接缝：方向一致吗？B 起步速度跟得上吗？慢就给 B 开头加速。
5. 拼：A 到剪点，B 从开头盖满的那几帧接；声音交叉淡化。

## 伪代码

```
prev = None
for shot in board:
    for take in 1..TAKES:
        clip = generate(shot.prompt, start_image=prev.cut_frame)    # 参考图接：refs=人物图，不给首帧
        head = covered_frames(clip, first=1.5s) if prev else []
        tail = covered_frames(clip, last=WINDOW) if not shot.last else []
        if (prev and not head) or (not shot.last and not tail): continue      # 换种子重抽
        if prev and direction(prev.clip) != direction(clip): continue
        if own_cut_near_seams(clip, head, tail): continue
        break
    r = motion(clip, after=end(head)) / motion(prev.clip, before=prev.tail[0])   # 遮挡前、后各一小段的运动快慢
    segments.add(clip, start=end(head), end=pick(tail),               # pick: 盖满段开头 + 叠化帧数
                 speed_up_head=1/r if r < SLOW else 1, over=RAMP,
                 blend_frames=min(BLEND, len(prev.tail)))
    prev = (clip, pick(tail), tail)
join(segments, audio_crossfade=XFADE)

covered(frame): 画面切成 4×8 块，每块平均颜色都离中间值很近 → 盖满（漏出天空、路面的那块会差很远）
```

## 好用的规则（原文，带数字）

- 遮挡物**最后约 2 秒**进来并盖满（13 秒的段写 11–13 秒）；剪点在尾部最后约 2 秒里找，盖满常只有 4–20 帧。
- 遮挡物要**大、深、光滑、虚焦、横穿、贴着镜头**：写「巨大、很宽、虚焦、比画面还宽」。优先柱子、墙、桥墩这类大片深色平面；车厢常被画成对焦清楚、带门闩和车轮的样子，只当备选（要用就写无窗的车厢侧面）。纹理多的（绿篱、树皮）B 会冻住；朝镜头走来的，B 里会往后退。
- 开头的遮挡物只用物体（柱子、树干、墙角），不用人。A 结尾和 B 开头写**同一种东西、同样虚焦**，不然叠化里看得到从虚变实。
- 参考图接时，在两边遮挡帧之间叠化 **4–6 帧**；A 的剪点从盖满段**开头往后、刚好留够叠化的帧数**就剪。盖满段很长时取最后一帧，画面会在墙上停一两秒。
- B 起步比 A 慢就给 B 开头加速，约 **1.2 秒**内线性降回 1 倍；这段画面几乎全是遮挡物，看不出加速。快慢比的是遮挡前、后各一小段的运动（加速的门槛和上限见 [refs/practical/config-transitions.md](../../../refs/practical/config-transitions.md)）。
- 方向一反，刹车感马上回来：全片镜头运动方向统一。
- 声音每段都写不要音乐，接缝处交叉淡化约 0.25 秒。
- **最后一段不遮挡**：人停下、镜头缓停再淡出。最后一段约 **10 秒**：中段（4–6 秒）停下，后面留 **≥ 3 秒**静止（6 秒的段停不下来）。

## 生成后检查（原文）

- A 尾部有没有连续 **≥ 4 帧**被**完全盖满**：四条边要亲眼看（底部漏一条路面、车轮时，按块比颜色也差不多）；受光、一侧亮一侧暗的遮挡物要人眼确认。
- A 的遮挡物是不是大片深色平面：带门闩、门缝、车轮、标牌的，叠化时这些细节会淡掉。第一段要在截参考图之前查完、该重抽就重抽（它一重抽，参考图和后面所有段都得重做）。
- 进遮挡前镜头一直在走：几乎不动或方向反了不合格。
- B 开头是否被**同一种**遮挡物盖满，盖满的帧数不少于要叠化的帧数；漏一条窄缝还能用（叠化里会闪一下），缝在遮挡物要移开的那一侧也放行；大片漏就重抽。
- B 开头的遮挡物和 A 剪点帧比虚实：B 的纹理明显比 A 清楚就是「从虚变实」。首帧接时重抽；参考图接时重抽也常改不过来，就在剪辑里给 B 开头加一层慢慢退掉的模糊（像跟焦），不重抽。颜色也要接近。
- B 遮挡物移开的方向和 A 进来的方向一致；B 不能停住不动或往回走。
- B 起步速度：加速补得回来就加速；B 开头冻住很久（纹理遮挡物）就重抽。
- 接缝前后约 2 秒里没有模型自带的切镜、叠化（见 [own-cuts](../../../stages/3-generation/own-cuts.md)）。
- 人物前后一致，参考图里的背景没被带进新场景；没有配乐（怎么查见 [生成后检查](../../../stages/3-generation/checks.md)）。
- 最后一段最后 2 秒几乎不动，才算停住。
- 固定机位，或 A 剪点前很早就盖满时，量出来的快慢不可信，直接看接缝前后的画面判断要不要加速。

模型的具体毛病（盖不满的写法、开头漏缝、慢起步）见 [refs/practical/wan3-notes.md](../../../refs/practical/wan3-notes.md)。

# 闪白（光晕）：细节

从 [光学类转场](../../../transitions/optical.md)「闪白」挪来的原文：完整思路、光晕的伪代码、进出回忆的帧数和声音交叉。推荐参数的出处是 [02 两档时长](02-platform-memory-two-tiers.md)；代码默认值和方法不一致的地方见 [refs/practical/config-transitions.md](../../../refs/practical/config-transitions.md) 最后一节。

## 思路（原文）

1. #1「现在」：后半段要有回到现实后的反应（抬眼、微笑）。回来时直接用 #1 的后半段，「现在 → 回忆 → 现在」三段只花两次调用。
2. #2「回忆」：用 #1 截的人物或道具当参考图锁住；回忆写得亮、暖、略过曝。
3. 剪辑：光晕 = 曝光提亮 + 高光泛开 + 向暖白的径向雾，峰值不到纯白；**调用边界藏在峰值里**：峰值处直接硬切，或只叠很少几帧（叠多了看得见两层画面）。

## 伪代码

```
光晕(A, B, 提亮帧数, 叠化帧数, 回落帧数, 峰值亮度):
    A 最后「提亮」帧: 光 0 → 峰值
    「叠化」帧:       (1-a)·光(A) + a·光(B)，光 = 峰值        # 调用边界在这里；叠化帧数可以是 0（硬切）
    B 开头「回落」帧: 光 峰值 → 0
    声音: 交叉淡化（回到现实那次交叉更长），不加合成的风声、快门声
```

## 好用的规则（原文，30 fps）

- 光晕峰值约一半亮度（不到纯白）。
- **进回忆（暗 → 亮）约 0.5–0.6 秒**：提亮约 6 帧、回落约 9 帧，峰值处硬切或只叠一两帧。峰值叠 4 帧时，在大片里看得出两层画面。
- **回到现实（亮 → 暗）约 0.9 秒**：回落 18–20 帧，声音交叉 0.6 秒。从亮回到暗时光一退就暗，看着短，所以回落要比进去慢；想更慢用约 1.5 秒（回落约 33 帧、声音交叉 1.0 秒）。
- 光晕只配原声的交叉淡化，不混合成的风声、快门声（剪辑工具默认会加，要关掉）。
- 纯白 2 帧太硬，别用。

## 生成后检查（原文）

- 光晕峰值那几帧有没有露出两层画面：露了就减少叠化帧数，或改成硬切。

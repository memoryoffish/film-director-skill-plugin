# 美术馆的风车油画活过来，成了真麦田（换种子重抽）

版本：当前推荐

#1 美术馆白墙上的风车麦田油画，镜头推近到画占满画面；#2 续写，镜头不停推进，油画变成真的麦田和风车。接缝 2.60 s，油画变实景约 8.2–10.2 s。

（示例视频：ex-media-change-01.mp4，没有放进仓库。美术馆的风车油画活过来，成了真麦田（换种子重抽）（2.2–10.2 s））

## 模型与调用

| 调用 | 方式 | 时长 | 抽了几次 |
|---|---|---|---|
| #1 m1_gallery | 文生（沿用第一版） | 6 s | 1 |
| #2 续写 | 参考视频 = #1 第 90–179 帧 | 13 s | 本轮 4 次（3 次换种子，1 次改提示词），用第 3 次（种子 1103） |

模型：Wan 3.0，720P。

## 提示词原文

调用 #1 沿用第一版，提示词见 [案例 02](02-painting-windmill-v1.md)。下面是本轮 #2 的两种写法。

**第 1–3 次（种子 1101、1102、1103）用第一版第 3 次的提示词原文，一字不改**

> 将视频1向后延长10秒。延长部分：镜头一直保持和视频1完全相同的速度，不停地笔直向前推进，从头到尾不减速、不停下。金色画框从画面四边滑出去，画面里只剩下这幅油画。从延长部分一开始，油画就活了过来：麦田开始随风起伏，风车的四片叶子开始转动，天上的云开始飘。同时，随着镜头向前推进，真实感从画面最下方的麦穗开始，一路向上蔓延：先是近处的麦穗变成真实的麦穗，接着中间的麦田和风车变成真实的木头风车，最后远处的村庄、天空和云也变成真实的蓝天白云；油画的笔触和厚厚的颜料一路向上消退。这是同一个画面里的逐渐变化，始终只有一个画面，没有两个画面叠在一起，风车始终只有一套叶片，没有重影。延长部分开始 4 秒后，画面里已经没有任何油画的痕迹，完全是一段真实拍摄的夏日金色麦田，一座真实的老木头风车立在麦田中间，叶片缓缓转动，麦浪一波一波随风起伏，镜头继续贴着麦穗上方向风车滑去。电影实拍质感，自然光，一镜到底，没有剪辑，没有叠化，没有跳变，没有文字。声音：美术馆里安静的环境声渐渐淡出，换成风吹麦田的沙沙声、风车木叶转动的吱呀声和远处的鸟叫，没有音乐，没有人声。

**第 4 次（种子 1104，`prompt_t4.txt`）。前 3 次的毛病是复述慢、叠化、没变真，所以改了提示词**

> 将视频1向后延长10秒。视频1作为首段完整呈现原内容，画面、声音和镜头推进的速度都按原内容保留。延长部分：镜头一直保持和视频1完全相同的速度，不停地笔直向前推进，从头到尾不减速、不停下。金色画框从画面四边滑出去，画面里只剩下这幅油画。从延长部分一开始，油画就活了过来：麦田开始随风起伏，风车的四片叶子开始转动，天上的云开始飘。同时，一条水平的分界线从画面最下沿出发，在 4 秒内匀速向上扫过整个画面，一直扫到画面最上沿：分界线以下的一切变成照片级真实的实景，分界线以上的部分还是厚涂油画。先是近处的麦穗变真，然后是中间的麦田和风车，整座风车连同四片叶子都变成真实的旧木头风车，最后是远处的村庄、天空和白云：天空变成真实的蓝天，云变成柔软真实的白云，不留任何笔触。这是同一个画面里的逐渐变化，始终只有一个画面，任何时候都没有两个画面半透明地叠在一起；风车始终只有一座、只有一套叶片，它的位置和大小只随镜头推进连续变化。延长部分开始 5 秒后，整个画面已经完全是真实拍摄的夏日金色麦田，没有任何油画痕迹，一座真实的老木头风车立在麦田中间，叶片缓缓转动，麦浪一波一波随风起伏，镜头继续贴着麦穗上方向风车滑去。电影实拍质感，自然光，一镜到底，没有剪辑，没有叠化，没有跳变，没有文字。声音：美术馆里安静的环境声渐渐淡出，换成风吹麦田的沙沙声、风车木叶转动的吱呀声和远处的鸟叫，没有音乐，没有人声。

## 剪辑关键数字

- 4 次续写都把 3 秒输入放慢重画，只有开头约 1 秒对得上 → #1 提前到第 107 帧结束。
- 接过去镜头不停：速度比 0.22 → 0.65。

`cut.sh`：

```bash
# media_change v2: call #1 = round 1's m1_gallery (text, push in on the painting; reused, not regenerated);
# call #2 = continuation (reference video = #1 frames 90-179), re-rolled with new seeds; TAKE picks the take.
# Wan re-drew the 3 s input more slowly than #1 (B frame 89 matches #1 frame 179 at only 12-13 dB), so #1 ends early,
# at the last frame the re-draw still matches (>= 24 dB, lag.py), and #2 starts on the next frame (extension.md step 4).
#   TAKE=m2_s1103 A0=30 A1=107 B0=31 B1=389 OUT=demo.mp4 ./cut.sh   (the delivered demo)
D=.
A=examples/media_change/clips/m1_gallery.mp4
OCCUT=scripts/occut.py
TAKE=${TAKE:-m2_s1103}; A0=${A0:-30}; A1=${A1:-107}; B0=${B0:-31}; B1=${B1:-389}; OUT=${OUT:-demo.mp4}
SEED=$(python3 -c "import json; print(json.load(open('$D/clips/$TAKE.json'))['job']['seed'])")
cd "$D"
cat > "plan_${OUT%.mp4}.json" <<JSON
[{"clip": "$A", "start": $A0, "end": $A1, "label": "Wan 调用 #1 · 文生 · 6s（第一版生成，沿用）"},
 {"clip": "$D/clips/$TAKE.mp4", "start": $B0, "end": $B1, "label": "Wan 调用 #2 · 续写（参考视频 = #1 最后 3 秒）· 13s · 种子 $SEED"}]
JSON
python3 "$OCCUT" join "plan_${OUT%.mp4}.json" "$OUT" > "${OUT%.mp4}.json"
echo "$OUT: boundary at frame $(( A1 - A0 + 1 )) = $(python3 -c "print(round(($A1 - $A0 + 1) / 30, 2))") s"
```

## 踩的坑和改法

- 4 个种子大约 1 次能成，要准备抽 4 次。
- 写「一条分界线往上扫」会变成划变（线上线下两个大小不同的风车），别这样写。
- 「视频1作为首段完整呈现原内容 + 不停推进」让推进速度接近 #1（约 1.1 倍），值得再试。
- 转动的叶片在活过来时会淡掉、回来只剩 2 片；风车约 0.7 秒两层叠着。

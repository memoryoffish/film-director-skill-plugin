# 媒介转变：案例

照片、画、屏幕里的画面活过来变成真的（或反过来），靠推近 + 续写。方法写在 [optical.md](../../../transitions/optical.md)。

当前推荐：[01 美术馆的风车油画活过来，成了真麦田（换种子重抽）](01-painting-windmill-v2.md)。

每篇是一次实际跑过的：视频、调用、提示词原文、剪辑数字、复现命令、生成后检查、踩的坑（在 Wan 3.0 上做的）。

- [01 美术馆的风车油画活过来，成了真麦田（换种子重抽）](01-painting-windmill-v2.md)：当前推荐。#1 美术馆白墙上的风车麦田油画，镜头推近到画占满画面；#2 续写，镜头不停推进，油画变成真的麦田和风车。
- [02 美术馆的风车油画活过来（第一版）](02-painting-windmill-v1.md)：旧版。同一幅风车油画，#2 续写生成了 3 次；用的是第 3 次，真实感从下往上一点点漫上去，没有整幅叠化，但天空到最后还带一点油画感。
- [03 书桌上的旧照片变成真的海港：四种调用方式对比](03-harbour-photo-four-ways.md)：四种调用方式对比（续写最好）。台灯下书桌上的旧照片，镜头推近（各版的 #1 相同），#2 分别用首帧、首尾帧、参考图、续写四种方式做照片变实景，四版连放 39.5 秒。
- [notes.md](notes.md)：从方法正文挪来的细节（不是一次实跑）：伪代码、各处的秒数、抽几次、带门槛的检查。

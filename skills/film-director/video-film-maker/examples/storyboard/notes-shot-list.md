## 伪代码

```
row   = {id, len, size, camera, move, picture, sound, cut_in, refs, note}
table = [row(s) for s in shots]                   # 一镜一行
assert sum(r.len for r in table) <= TARGET         # 见 shot-list.md「时长预算」
units = group(table, max_len=MAX_CALL)            # 见 shot-unit.md
```

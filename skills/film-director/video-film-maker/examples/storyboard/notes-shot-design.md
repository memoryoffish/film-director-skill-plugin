# 镜头设计：细节

从 [镜头设计](../../stages/1-storyboard/shot-design.md) 挪来的原文：几条的完整说法、伪代码、原来的规则和案例（含《咖啡豆》越轴）。正文只留了每条一句；要细节时来这里，再按这部片自己判断。

## 思路（完整说法）

下面是电影的通用拍法；我们自己踩过的坑在本篇最后的「案例」。

**每个镜头**

1. **景别看这一镜要看清什么**：大全景、全景交代空间和尺度；中景看动作和两人关系；近景、特写看情绪和反应；大特写只看一样东西（眼睛、拳套、计时器）。
3. **运动要有理由**：推近是靠近情绪；拉远是揭示或疏离；横移、跟拍是跟着人走；升降揭示尺度；环绕给对峙或独处；手持贴身是慌乱、喘不过气；固定是冷静、旁观。说不出为什么动，就固定。
4. **构图**：主体放在哪、朝哪看，看的那一侧多留空。前景放东西做层次（围绳、门框、肩膀、飞起的灰）。大东西要有尺度参照：远处的巨物配前景的小人、旗杆、岩石。
5. **光**：每场定好光从哪来、冷还是暖；逆光、轮廓光把人从背景里分出来。全片的光跟着节拍走（见 [节拍](../../stages/1-storyboard/script.md)）。

**镜头之间**

7. **轴线**：两人对戏、对打、追逐时，在两人之间（或沿运动方向）画一条线，机位都在同一侧；谁在左谁在右、往哪边走，一直守住。要过轴，就让观众看着镜头移过去，或者先插一个正对轴线的镜头。
8. **正反打和视线**：A 看画右、B 看画左，视线高低对上；过肩镜头里前景的肩膀定住左右。主观镜头前先给看的那个人：看 → 看见 → 反应。
9. **换机位要换得明显**：角度至少差 30°，或者景别跳过一级（中景接特写，不接近景）；只差一点点就像跳切。

**长度**

12. **跟着情绪变**：紧张、打斗切得快，情绪、揭示、余波放长；快慢交替，一直快就不快了；高潮前留一拍，高潮后镜头放长。各类镜头多长见 [节奏](../../stages/4-edit/rhythm.md)。

## 伪代码

```
for beat in beats:
    if new_space(beat): shots += establishing(beat.scene)          # 先交代空间
    for need in beat.what_to_see:                                  # 一镜一件事
        s = Shot(size=size_for(need), angle=angle_for(beat.mood),
                 move=move_with_reason(beat) or STATIC,
                 frame=composition(need, foreground, scale_ref), light=beat.scene.light)
        assert same_side_of_axis(s, prev) and eyelines_match(s, prev)
        assert angle_change(s, prev) >= 30 or size_jump(s, prev) >= 2
        s.len = length_for(beat.level)                             # 快慢交替，见 rhythm.md
        shots += s; prev = s
```

## 好用的规则（原文）

- 每场开头一个建立镜头，前景放参照物。
- 关键动作前给一个大特写，动作后给反应。
- **多人同框，每镜写清各自在画面左右**：模型换角度时常把两个人对调，轴线就断了。
- 方向写画面方向（「往画面右边走」「看向画面左侧」），不写人物自己的左右。

## 案例（原文）

- [拳馆大片版](../films/boxing-blockbuster.md)：回忆和现在都以前景有参照物的大全景开场（围绳；水洼和光柱）；英雄镜头低机位仰拍；关键动作前大特写（眼睛、拳套、计时器）；撞胸用升格；单元之间剪在出拳途中。
- 《咖啡豆》（情侣）：两人换角度时左右对调两次（c04、c08，越轴），多抽了 3 次；写明「她在画面右侧前景，他在左侧、离得远一点」才对上。
- [四种类型各做一部](../films/genre-tests.md)：《铁桥》侧面机位都在桥南侧，男左女右，全片不越轴。
- [动势剪辑 · 红大衣](../edit/momentum/02-red-coat-front-rear.md)：两个机位差不多的镜头接起来还是跳切，视角要换得明显。
- [复刻《英雄》](../films/remake-hero.md)：黑衣改看画面左侧，和蓝衣向右的视线隔着剪辑对上。
- [复刻《敦刻尔克》](../films/remake-dunkirk.md)：拆解写错的 6 处里有编队偏左偏右、视线顺序，「left」要按画面方向写。

# 4-check：查

成片对着白模查。白模是标准答案：每镜该是什么机位、谁在哪、朝哪、门往哪开、几秒切，都在里面。

## 这一步交出什么

- 每镜一行三栏对照（白模 | 关键帧 | 成片），和一份毛病清单：每条写明回到哪一步改。
- 交片之前：清单里能改的，只要预算还有就改掉，不能只写进报告。

## 推荐

- **切点对表。** 分镜单元先量实际切点（`cut.py cuts`、`split_unit`），和镜头表比：有没有少切、多切，偏了多少。剪的时候按量到的切点裁，不按表上的数。两镜都暗时把检测门槛调低（`cut.py cuts CLIP 0.12`），还量不出就逐帧看。
- **每镜三栏对照**（`cut.py trio`）：白模 | 关键帧 | 成片的头、中、尾。每一镜都跑；没有白模那一栏的对照图，不算这一步的检查。这样哪一步错的一眼分得清：白模本身就错了、关键帧画错了，还是视频跑偏了。按这个顺序看：
  1. 机位和景别对不对（高度、角度、远近）；
  2. 人数对不对，谁在左谁在右，各自朝哪，人有多大；
  3. 地方对不对：门、家具、地标在不在白模里的位置；
  4. 有没有白模的东西进了画面：人偶、纯色方块、占位块的颜色、胸牌；
  5. 镜头中间有没有跑偏：多出来的切镜、叠化、东西慢慢变形、门这类薄板变成两扇（切点检测查不出慢慢变的，要看帧）。
- **看合不合理**：门往哪开、东西大小和位置、道具状态跨镜接不接得上、动作有没有来由、特写前有没有交代。
- **首帧 + 尾帧的片子看最后几帧。** 片尾一两帧常常跳回尾帧或发虚，切点检测有时在片尾量得出一个切点，有时量不出：用 `cut.py strip` 按 0.1 秒密抽看最后几帧。
- **碰上的那一帧和那一声。** 打斗、关门这类镜头，`cut.py strip` 找到画面里碰上的那一帧，`cut.py onsets` 找到声音最尖的那一下；声音晚了，剪的时候把这一镜的声音往前挪。
- **参考视频喂出来的片子看上下黑边**（固定机位的几乎每条都有），有就裁掉放大，或换喂法。
- **参考视频喂出来的片子对路线和时刻**：`st.timeline()` 列出预演里每段走路的起止秒数和速度，和成片里同一段比。
- **同一个毛病拍了两条都出现，就不是运气。** 回到对应的一步改，不是换种子。

## 毛病和改法

| 看到的 | 多半是因为 | 改哪一步 |
|---|---|---|
| 门洞被画成一块门板、人坐在靠背上、台阶上的人悬空 | 白模里就是这样（没搭门扇、座高不对） | 搭 |
| 门往外开，或看不出往哪开 | 只给了开头一帧（单元、参考图、只给首帧） | 喂：单拍首帧 + 尾帧，尾帧里门开到底、开向对 |
| 门变成两扇、门板重影 | 门停在正好侧对机位的角度，只剩一条线 | 搭：换个开门角度，让同一面始终看得见 |
| 转头、转身的方向反了；新进画的人位置和大小不对 | 只给了开头一帧 | 看和算：这一镜出尾帧；喂：首帧 + 尾帧 |
| 背对镜头的人转过来换了一张脸 | 首帧里没有脸 | 喂：尾帧给一张带脸的关键帧（侧面最好） |
| 有人整镜一动不动 | 尾帧里他的姿势和首帧一样；或文字写了「一动不动」 | 喂：只给首帧、文字写他具体的小动作；或拆成两段首尾帧 |
| 片尾几帧跳一下 | 用了首帧 + 尾帧 | 剪：最后 2–3 帧裁掉，剪在刚到位的那一帧 |
| 跟拍里人越走越远、最后跳回来 | 首尾两帧几乎一样，用了首帧 + 尾帧 | 喂：只给首帧，文字写背景变大多少 |
| 背景逼近太快、距离不对 | 首帧给不了距离 | 喂：文字写一句看得见的话（「几秒里几乎没有变大」） |
| 撞击碰了两次 | 碰上的那一帧在两个镜头里都有 | 搭：碰上只归一个镜头 |
| 道具状态跨镜接不上（耳机、包在哪一侧、桌上的东西、手在不在门上） | 派生关键帧带回了主帧的状态，或写关键帧时改了白模里的状态 | 看和算：排状态表；喂：派生帧提示词里写明「和图 2 不同」，重画 |
| 动作没有来由（突然摘下耳机） | 状态变化放在了没有原因的镜头里 | 看和算：挪到有原因的那一镜 |
| 特写的东西观众没见过 | 中间缺一个交代的镜头 | 看和算：补一个全景，机位在白模里试 |
| 特写或近景双人被拍成全景 | 用了参考图（单元或单镜） | 喂：关键帧当首帧 |
| 暗场被画亮 | 用了参考图或参考视频 | 喂：暗关键帧当首帧 |
| 人被画大、身边的门也变大 | 关键帧把小人画大，视频照着首帧 | 喂：重画关键帧，用画面里的东西当尺子写比例，出图后量 |
| 占位块的颜色进了成片（蓝板、黄色小点、紫色方块） | 直接喂了白模；或道具在白模里就是醒目色 | 搭：道具用真颜色；喂：先转关键帧 |
| 胳膊往后反折、手伸到背后去递东西、肘或膝往反方向弯 | 白模里就是这样摆的：`hands=` 的目标点在背后或够不着，反解照样把胳膊拉过去 | 看和算：`check_bodies()` 报的改掉；做不到的补一个过渡动作（先转身、先起身、走近一步）或状态变化（东西先放到够得着的地方） |
| 人的姿势像人偶（T 字、两人坐得一模一样） | 关键帧照搬了白模的姿势 | 搭：摆不像人的只给位置、两人姿势做出差别；喂：姿势写进文字重画 |
| 首帧对了，镜头中途切到别处、东西变形、多出一个人 | 提示词里写了画外的东西，或提到了首帧边上半个人 | 喂：首帧的提示词只留动作、机位、声音 |
| 人并脚垂臂站着不动、动作一个姿势接一个姿势、步子碎、手臂僵直 | 参考视频里放了带关节的人偶，它的站姿和动作被照搬 | 喂：预演换成替身版（`Stage(stand_ins=True)`）；没什么移动的镜头不给参考视频 |
| 人站成柱子（并脚、笔直） | 参考视频里的替身静止不动 | 喂：开头的配一张带关节的首帧静帧；整镜不怎么动的不给参考视频 |
| 人像瞬移，一眨眼换了地方 | 预演里替身走得太快，起步和停下太突然 | 搭：按真人速度走（每秒 1.2–1.4 米），缓起缓停 |
| 东西悬在半空、被画成方盒子 | 参考视频里的道具方块就是那样放的 | 搭：道具放在说得通的位置上；或这一镜不给参考视频 |
| 直着身子落座、深蹲、穿过椅子 | 参考视频里替身变矮，或站位点和椅子叠在一起 | 喂：坐下、蹲下改用首帧 + 尾帧或文字；搭：替身停在椅子前面 |
| 打斗一个姿势接一个姿势摆、两人贴着停住 | 打斗喂了参考视频或白模首帧 | 喂：改用分镜单元或只用文字，白模只给站位和左右 |
| 一根半透明的柱子进了画面 | 胶囊替身在背影、人大的跟拍里没被认成人 | 喂：不给参考视频，关键帧当首帧 |
| 上下黑边 | 参考视频，固定机位的几乎每条都有 | 剪：裁掉放大；或换喂法 |
| 撞击声比画面晚 | 生成的声音没对上 | 剪：这一镜的声音往前挪 |
| 几个单元之间地方的样子不一样 | 每个单元各自凭文字想象场景 | 喂：每镜的图换成同一张主帧派生的关键帧 |
| 站位都对，就是不好看、没戏 | 不是白模的事 | 回到镜头设计和表演（video-film-maker）；同一张首帧换写法多拍一条 |

## 按类型

- 剧情、喜剧：重点查换边、同一个地方的地标、门的开向。
- 打斗：每一招之后两人的左右和距离；碰上的那一帧和那一声；撞击有没有碰两次。
- 悬疑：揭示镜头里该看见的在不在画里、不该看见的在不在画外；暗镜头之间的切点；门这类薄板有没有重影。
- 恋爱：两人的距离一档一档对不对；道具（耳机、罐子、袋子）跨镜接不接得上；有没有人被尾帧冻住。
- 科幻、大场面：尺度——人在巨物旁边有多大，量出来和白模比；同一样东西几个机位里是不是同一个样子。
- 二维动画：画风有没有被白模的立体感和占位色带偏；Seedance 的切点按量到的裁。

# 2-look：看和算

白模搭好先别急着喂。它首先是给你自己查空间用的三维模型：这场戏在空间里说不说得通、每个镜头读不读得懂、镜头和镜头接不接得上，在这一步看完、改完。这一步几乎不花钱，改一行就重跑一次。

## 这一步交出什么

- 平面图、每镜的静帧、站位描述。
- 道具和人的状态表。
- 计划里一镜一行：上不上白模、用哪种喂法、为什么；哪些镜头要尾帧。
- 往下走之前：每张静帧一眼看得懂，【要改】的警告都处理了。

## 推荐

- **先看平面图。** `st.plan(路径, t=秒)` 出这一刻的俯视图：墙、门（往哪开）、家具、每个人的位置和朝向、机位和视野。门在哪面墙、人从哪走到哪、镜头在轴线的哪一侧，一眼看完。大场景用 `region=` 分几块画。机位多时（一个地方十几个机位，视野线叠成一团）每镜单独出一张：`cams=[这一镜的机位]`，`t=` 设成这一镜开头的秒数。
- **每镜出首帧静帧，逐张看。** `st.stills(镜头表, 目录)`。看这几件：
  - 主体够不够大，头和关键动作在不在画里；
  - 谁挡住了谁，前景有没有栏杆、家具挡住人；
  - 这个动作从这个角度看不看得懂（开门要同时看见手和锁，击掌要看见两只手）；
  - 这一镜和上一镜认不认得出是同一个地方（画里有没有共同的地标）；
  - 静帧有没有歧义（这块方块像门还是像柜子）——有歧义的在提示词里点名；
  - 揭示镜头：该露的在画里，不该露的在画外（候选机位各出一张，挑）。
- **查人偶的关节、朝向和手。** 带关节的人偶给你自己看，关键帧也照它画，所以它先得是一个人做得到的样子。`st.check_bodies()` 逐个时刻查：关节有没有超出人能做到的范围（肘、膝往反方向弯，胳膊往后反折，脖子、腰扭过头），用 `hands=`、`feet=` 去够的东西是不是在身前、够不够得着，头和胸有没有穿进家具、墙、门，两个人有没有叠在一起；【要改】的都改，最要紧的是关节。再用 `st.pose_sheet(路径)` 把每个人每个姿势从正面、右侧各出一张小图，逐张看，每张写一句「在干什么、像不像人」：手在不在该在的地方，肘和膝往哪弯，重心在不在脚上，朝向对不对着要交东西、要说话的人。查出来的先改白模（站位、朝向、东西放在哪）；人确实做不到的，在剧本和镜头表里补一个过渡动作（先转过身、先站起来、先走近一步）或一个状态变化（东西先放到够得着的地方），让它做得到。比如：大妈坐在门前一米的沙发上、背对着门，剧本要她头也不回把手伸到门缝里递毛豆；目标点在她背后一米，坐着胳膊只有六十来厘米，既够不着，也伸不到背后。改成她先在沙发上转过身来面朝门缝，再伸手递。
- **让工具把位置念出来。** `st.describe(机位, 秒)` 给出「谁在画面左侧、离镜头最近、占画面高多少、侧身朝右、腰被挡住」，门的合页在哪边、往哪开；`props=[名字…]` 再报几样道具在画面哪里。`st.order()` 给出从左到右的人名。写提示词时照它写，别凭印象写左右。
- **查越轴。** `st.flips(镜头表)` 列出哪两镜之间两个人换了边（机位越过了两人的连线）。机位有意转到连线另一侧的反打（比如从屋里隔着门框往外拍）本来就会换边，这时在提示词里明写「阿杰现在在画面右边」；不是有意的就挪机位。最省事的是一开始就把所有机位放在两人连线的同一侧，正反打也在这一侧拍，两人就一直不换边。
- **查视线。** 戏靠「谁看得见谁」成立时（偷看、揭示、躲在门后、画外的东西来了），把每一条要紧的视线列出来，用 `st.sees(从, 到, t=秒)` 逐条打一条射线：从谁的眼睛到谁的头、从哪个机位到哪样东西，它返回挡在中间的东西。它只查中间挡没挡，不管目标在不在这个机位的画框里：在不在画里，看 `describe` 或那一镜的静帧。结果和距离写进计划。
- **量。** 两人之间多远（`st.gap`，恋爱戏每镜开头结尾都量），人占画面多高（`describe` 里有；占画面高不到一成的，出关键帧后要再量），走到门口要几秒，伸手够不够得着。镜头给的时间不够动作做完，就在这一步改镜头表。
- **比每镜的开头和结尾，定哪些镜头要尾帧。** `st.changes(镜头表)` 列出每镜开头和结尾哪里变了：谁换了边、谁转了身、谁进出了画、门开了多少、道具挪了多远。变了的，这一镜一般要出尾帧静帧（`stills(last=…)`），喂的时候给首帧 + 尾帧；例外见 3-feed 的 first-frame「什么时候用」里「别加尾帧」那几条，比如尾帧里有人姿势和首帧一样，他会整镜不动。
- **状态变化先有原因。** 每个变化写成「原因 → 动作 → 结果」，时间线上结果的动画关键帧不能早于原因：人还没使劲，沙发不能先动。动画关键帧之间是匀速或缓起缓停的插值，东西从前一个动画关键帧起就开始动；要让它等人发力以后才动，就拆成「停住 → 发力 → 动」三个动画关键帧。
- **排道具和人的状态表，查特写前有没有交代。** 每镜开头每样要紧的东西在哪、什么状态；观众没见过的东西别直接上特写。见 [continuity](continuity.md)。
- **理会警告，也知道哪些可以不理。** 「镜头在 X 里面」一定要改（机位在墙、柜子、实心楼梯里，画面里只有它的内壁）；【要改】「X 的头出画了」「镜头贴着或钻进了 X」默认要改；故意拍局部的特写、故意贴着人的主观镜头可以不理（警告里带着离镜头多远，自己判断）。「腰被挡住」（坐在课桌后面）只是说明。工具把门后整个看不见的人写成「在门后面，画面里看不见」，不把他算进左右顺序和越轴。
- **每镜判断一次上不上白模、怎么喂，写进计划。** 把每张静帧和「只凭文字模型会拍成什么样」比：文字拍得对的不用上白模。计划里一镜一行：上不上、用哪种喂法、为什么（白模在这一镜管的是开头写下的那两三件事里的哪一件，还是文字就拍得对）。说不出为什么的，先按不上算，拍一条小样看。见下表和 [3-feed](../3-feed/overview.md)。

## 哪些镜头值得上白模

| 镜头 | 只用文字 | 上白模 |
|---|---|---|
| 平视、两三个人、背影或侧面的常见构图 | 站位、先后、运镜方向多半对 | 不用；上了反而可能把白模的毛病带进去 |
| 高角度、俯拍、仰拍、贴地 | 常被拍成平视或斜俯 | 要 |
| 过肩、正反打（机位转到另一侧、两人要换边时） | 常不换边，或人数不对 | 要，先转成关键帧 |
| 同一个地方连着几个机位 | 每镜的门、家具、地标位置各不相同 | 要 |
| 人和道具、门的相对位置有讲究；起始间距对戏有影响 | 常错（一开头就挨着坐） | 要 |
| 揭示、视线 | 地方和左右常常全错 | 要，视线先在白模里验 |
| 人和巨物的大小比 | 说不准 | 要，出关键帧后量 |
| 特写里手和东西的位置 | 说不准 | 关键帧当首帧 |

每一行的实测在 [examples/feeding-tests.md](../../examples/feeding-tests.md) 和各片的 notes。

## 按类型

- 剧情、对戏：正反打前后各出一张，用 `flips` 核对换边；三个人以上每镜都 `order` 一遍；门的开向看一眼 `describe`。
- 打斗：每一招的「起」和「落」两张静帧连起来看，两个人的左右有没有无故对调，距离变化顺不顺；碰上的那一帧归哪一镜。
- 悬疑：把揭示要用到的视线逐条用 `sees` 验，记下距离；从角色眼睛的位置架一个机位看一眼他到底看不看得见。
- 恋爱：每镜开头结尾用 `gap` 量两人的距离，一档一档和戏对得上；视线方向看 `describe` 的朝向。
- 科幻、大场面：远景里放一个人当尺子；记下每镜人占画面多高，出关键帧后对着量；每个机位里数一数共同地标有几样。
- 二维动画：和上面写实的几类一样看；夸张的透视先在静帧里看站不站得住。

# 状态和接戏

一句话：每镜单独生成时，镜头和镜头之间没有记忆。东西在哪、什么状态、人手里拿着什么、观众见没见过它，要在白模这一步排成一张表，出关键帧和写提示词都照着它。

## 什么时候用

- 片子里有单独生成的镜头，就在出关键帧之前排这张表。
- 人偶身上没有的东西最容易丢：包在哪一侧肩上、耳机摘了哪一只、手电在手上还是挂在腰上，白模里没有，只能靠表。

## 思路

1. **列出每镜开头和结尾哪里变了**（`st.changes`）。每镜的开头和结尾各是一个状态：一镜里变了什么（门开了、人转身了、橡皮被勾回来了），尾帧就得画出变完的样子；下一镜的首帧接着这个样子。
2. **排状态表。** 一行一镜，列：每个人手里拿着什么、身上的道具在哪一侧、门开着还是关着、要紧的道具在哪。
3. **动作要有来由，状态变化放在有来由的那一镜。** 单人近景里她忽然摘下耳机，观众不知道为什么；挪到递给他的那一镜，摘和递连成一个动作，就有了来由。
4. **特写前要有交代。** 观众没见过的东西，直接上特写他认不出来（从高处的俯拍直接切到手按在一根巨大的手指上）。中间补一个全景：人走到那样东西跟前，东西在画里，下一镜的特写才接得上。
5. **出关键帧、写提示词都照表。** 状态表是关键帧的标准答案：关键帧多是从主帧（先出的那张看得最全的关键帧）派生的，主帧里的东西会被带进每一张派生帧：主帧里桌上有橡皮，片尾那一镜桌上就还有橡皮。派生时和主帧不一样的地方，以状态表为准，写进提示词。写关键帧提示词时别为了画面改掉状态：上一镜结尾他已经把手从门上拿开，这一镜就不能为了好看再写回门上。
6. **改了哪一镜的状态，后面每一镜都跟着查。**

```
changes = st.changes(shots)                 # 每镜开头结尾哪里变了 → 这些镜头出尾帧
st.stills(shots, "wm", last=set(changes))

状态表 = {                                   # 每镜开头，每样要紧的东西
  "s5": {"她": "两只耳机都戴着；罐子在两人中间的椅面上", "他": "双手空着；塑料袋在他右手边椅面上"},
  "s6": {"她": "开头两只都戴着；结尾摘下靠他那一侧的一只递出去", "他": "…"},
  …}
for 镜头 in shots:
    和主帧不同 = diff(状态表[镜头], 主帧的状态)      # 写进派生关键帧的提示词：「和图2不同：桌上已经没有橡皮」
    if 观众第一次看到某样东西 and 镜头是特写:
        在它前面补一个交代镜头                     # 机位在白模里试：那样东西在画里，下一镜的左右关系一致
```

## 检查

- 相邻两镜的接缝，对着白模的时间线查一遍：上一镜最后一帧和下一镜第一帧，人在哪、朝哪、手在哪，应当是同一个时刻的样子。
- 每张关键帧出来，对着状态表里这一镜的那一行看。

## 好用的规则

- 补交代镜头时，机位在白模里试：背景里不能有要留到后面再露的东西（巨人的手臂、躲着的人），人和那样东西的左右和下一镜的特写一致。只给首帧时镜头会自己往旁边带、把不该露的带进来，用首帧 + 尾帧把镜头固定住。
- 一镜里状态要变两次（挪过来，再摘下耳机递出去），在中间加一张关键帧，把这一镜拆成两段，各用首帧 + 尾帧：这张关键帧既是前一段的尾帧，又是后一段的首帧，两段在它上面接起来；接缝处几乎看不出。动作方向模型总挑错时（摘错了一只耳机），也用这个办法：中间那张关键帧里手已经放在对的地方。只测过一次。
- 白模里道具要藏起来（还没出场、已经拿走），挪到地板下面，别挪到很远的地方（平面图会被撑大）。
- 定妆图里人身上挂着的小道具（腰上的手电），关键帧里会再画一份；写明「只有手里这一支，腰上是空的」。

# 白模转写实关键帧

一句话：把每镜的白模静帧交给图像模型，照着它的机位和站位画成一张成片质感的画面；之后喂给视频模型的是这张画，不是白模。实测有效，但每张都要专门看：画完一张看一张，对了才往下用。

## 什么时候用

- 上白模的镜头，喂之前几乎都先做这一步；混着用几种喂法的片子，全片都先转关键帧（见 [overview](overview.md)）。
- 二维动画：同样的做法，「写实的电影画面」换成画风的描述，主帧再加一张画风基准图。

## 思路

1. **分清三样输入各管什么。** 白模图只管版式，人物和道具参考图管长相，文字说明谁是谁、这是哪、此刻各样东西是什么状态。白模和关键帧的画幅一致（16:9）。
2. **先出一张主帧**：挑看得最全的机位，带上人物和道具参考图（二维动画再带一张画风基准图），把场景的样子定下来。暗场可以单独出一张主帧，两个差别很大的地方（走廊和屋里）也可以各出一张。
3. **其余每镜从最近的一张派生**：给图像模型这一镜的白模静帧（版式）和一张已有的关键帧（样子），让它「在同一个地方，按白模这张的机位和站位重画」。用哪张已有的：
   - 同一个机位的后一刻（尾帧）：从这个机位前一刻的那张关键帧派生，只改白模里变了的东西；
   - 特写、过肩：从最近的那张更宽的派生（手的特写从「两人挨着坐」那张派生，衣服、耳机线、罐子都接得上）；
   - 某样小东西要在这一镜看清楚：从已经把它画清楚的那张派生，写明「和图 2 里同一个手轮」；主帧是大远景时，它在主帧里只有几个像素，派生不出样子。
   - 接着上一镜演的：上一镜的成片生成好以后，从它最后几帧截一张当图 2，人、道具、光照着成片接。
4. **首帧是这一镜动作开始之前的样子。** 白模这一镜开头是什么状态就画什么：门还没开，沙发还没动。动作画了一半，视频会把它从头再演一遍。
5. **提示词按固定的顺序写。** 「这张图是什么 → 沿用什么 → 版式照什么、谁是谁 → 和上一张哪里不同 → 场景里每块占位是什么 → 不要什么」；谁是谁既按颜色也按位置说（「左边的蓝色人偶」）。
6. **派生时写明两样：这个机位看不到的，和已经变了的。**
   - 看不到的：派生会把源图里的空间带过来。提示词里「沿用图 2」那一段只列这个机位看得见的东西；图 2 里有、这个机位看不到的（门外的走廊、另一面墙），写进「这个机位看不到」，不写进「沿用」。门后本该是墙角，派生帧沿用了图 2 里的走廊，这一镜就画成了走廊，视频也照着拍了。
   - 变了的：派生会把主帧里的状态带回来。主帧里桌上有橡皮，片尾那一镜派生出来桌上还有。和主帧不一样的地方，以白模和道具状态表（[continuity](../2-look/continuity.md)）为准，在提示词里明说：「和图 2 不同：他的桌上已经没有橡皮」。
7. **出完一张看一张**（见下面「出图后检查」）。没过的重画，不拿去生成视频。

```
主帧   = 图像模型([白模_主镜, 人物图…, 道具图…],
          "把图1画成写实的电影画面。图1是白模，只当版式：机位、透视、构图、每个人和东西的位置、大小、朝向、姿势照它，不加不减。
           谁是谁：左边的蓝色人偶是图2里的人（外貌…），他正在…；红色人偶是图3…；绿色方块是图4的沙发，座面朝镜头…
           场景：…（白模里每块占位的东西是什么；每一处光从哪来）   画面质感：…   不要画人偶、纯色塑料感、胸牌；没有字幕水印；没人看镜头")

派生帧 = 图像模型([白模_这一镜, 最近的关键帧, 这一镜里有的人的定妆图…],
          "图2是一张电影画面：…。图1是同一个地方另一个镜头的白模，机位换到了…。把这个新镜头画成写实的电影画面。
           沿用图2：同一个地方（墙、地、门、…）、同样的人和衣服、同样的光和质感。
           构图、站位照图1：左边的蓝色人偶是…，面朝右…；（姿势写在这里，不照人偶）
           和图2不同：…（状态表里这一镜和图2不一样的东西）
           这个机位看不到的东西明说：比如楼层号在镜头背后，画面里没有")
```

## 出图后检查（不合格就重画）

- 把每张关键帧和它的白模并排看（`cut.py pairs`），一镜一张放大了看，每张写一句「白模里有什么、这张画了什么」。
- 先看背景里的大结构（门、门洞、走廊、窗、墙角、家具的行列和朝向），再看机位、站位、朝向、人数、人有多大、道具状态、有没有人偶的痕迹。
- 门：对着白模静帧看合页和门扇各在哪一侧。
- 人的大小：对着白模量。视频会照着首帧里人的大小拍，不会再改。
- 颜色要紧的道具专门看一眼：白模里涂成醒目色的道具，偶尔会被照着画成那个颜色。
- 不对的改提示词重画那一张，别的不动；没过的不拿去生成视频。

## 好用的规则

- **每张都要专门看。** 用 gpt-image 在六个案例里出了一百多张：拍片时顺手查过，重画的多是因为状态、尺度和小道具不对；事后把一部 38 镜的片一镜一张放大了再看，有 26 张的背景或站位没照白模画。
- **出图模型会照搬人偶的姿势。** 白模里摆成两臂平伸，关键帧就是一个 T 字；两个人偶坐姿一样，关键帧里两人就一样。摆不像人的姿势，白模换成中性站姿只给位置，姿势写在文字里。
- **人偶的方块手会被画成握着东西。** 关键帧里那只手像握着一个盒子；手里没东西的，写明手是空的。
- **门的开向出图时也会画反。** 白模里门往里开，关键帧画成了往外开。写明门扇往哪边转（「门扇往里转进门洞」）。
- **小人会被画大。** 人在画面里看得清是个人、又不大时，常被画大一两成到一半多，身边的小门也跟着变大；人小到只剩一个光点时，大小反而画得对。写「只占画面高的 6%」没用；拿画面里的东西当尺子写比例（「她从头到脚只有圆环直径的三分之一高，不比液压柱的底座高」）好一些。还不行可以试白模里先把人缩小两成再出图（没测）。
- **输入图里只放这一镜里有的人。** 把有老师的那张关键帧也当输入图，学生脸上就多了一副老师的眼镜。
- **人偶身上没有的道具，每一张都写**：包挎在哪一侧肩上、手电在哪只手里、耳机戴着哪一只。定妆图上人身上挂着的小道具会被再画一份，写明「只有手里这一支，腰上是空的」。
- **写关键帧时别为了画面改掉白模里的状态**：上一镜结尾他已经把手从门上拿开，这一张就不能写回门上。
- **暗场写光从哪来**，不写「很暗」：白模里光源做成黄色的球和条，逐样写明（「黄色小球是吊着的灯泡」「地上的黄色薄片是门缝下漏出来的光」）。
- **尾帧里人背对镜头时，看不懂朝向，也没有脸**：能摆成侧面就摆侧面；要画出脸的那一张，出图时带上定妆的正面图。
- 人背对镜头时，说明看不见的东西（胸前的图案在正面，背后是素色），不然会画到背上。
- 换到反方向的机位时，说明哪些地标现在看不到；不说，模型会把它们搬进画里（反打里墙上的楼层号出现在了另一面墙）。窄空间的静帧里地标很小，把每样地标在画面哪一侧再说一遍。
- 特写里白模的形状认不出来，逐块说明：「大块棕色是门，右边深色竖条是门框，黄色方块是黄铜门锁，画面下沿的绿色是沙发靠背顶」。
- 揭示之前不能说破的东西，提示词里也别说破：四根手指的指尖写成「四根并排的粗管子」，写明不画手的形状。

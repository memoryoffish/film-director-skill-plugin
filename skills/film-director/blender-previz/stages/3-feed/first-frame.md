# 关键帧当首帧，和什么时候加尾帧

一句话：一个镜头单独生成，关键帧当第一帧；这一镜要落到某个确定的状态时，再给一张尾帧。提示词只写这一镜里动的东西、机位和声音。实测有效（Wan 3.0、Seedance 2.5）。

## 什么时候用

- **只给首帧**：单镜单独生成时的默认做法（几种喂法的对比见 [overview](overview.md)）。
- **必须加尾帧**：
  - 门开到多大、人最后停在哪、东西落在哪（推到位、砸在哪块铁皮上、甩到第几列机器）。门往哪边开，光给尾帧不够，首帧里先朝那边开一条缝。
  - 头或身子要转向一个确定的方向（回头看左后方的人）：只给首帧和文字，常被转成朝镜头。
  - 首帧里没有、后来才进画的人：只给首帧，人会从奇怪的地方冒出来，大小不对。
  - 首帧里只有后脑勺、后来要转过脸的人：首帧里没有脸，转过来就换了一个人。尾帧给一张带脸的（出图时带上定妆图），最好是侧面。
  - 运镜会露出新东西（升、摇、拉）：尾帧告诉模型画外是什么。首尾两帧差得多时，中间可能整幅叠化过去（拍过 1 条摇镜加首尾帧，在 3.2–3.6 秒整幅叠化成了尾帧）：出来以后逐帧看中段，叠了就改成只给首帧、机位不动，用光或人的动作把要露的东西带出来。
  - 机位不动、但怕镜头自己往旁边带（把该留在画外的东西带进来）：用尾帧把机位固定住。
- **别加尾帧**：
  - 首尾两帧几乎一样（跟拍、空镜）：模型当成固定机位，人越走越远，片尾一两帧跳回尾帧；首尾同一张图的空镜，几秒后镜头自己摇走。只给首帧，用文字写清运动。
  - 尾帧里有人姿势和首帧一样：他会整镜一动不动，文字写了一串反应也没用。要他动起来，就只给首帧、文字写他的反应（落点会没那么准）；或者尾帧里他也有变化（还没测）。
  - 一镜里状态要变两次：中间加一张关键帧，拆成两段首帧 + 尾帧，在这张上接起来（[continuity](../2-look/continuity.md)）。

## 思路

1. **首帧画动作之前的样子。** 首帧里已经出现的结果，这一镜就演不出来：首帧里她已经转头看着他，镜头里就没有「转过头」这一下。出派生关键帧时就按「动作之前」画；事后再重画一张，画出来的脸容易和别的镜头对不上。
2. **定加不加尾帧**（见上面）。只给首帧时，模型只知道开头，结尾它自己挑：门往外开还是往里开、人停在哪、头往左转还是往右转、新进画的人从哪出来多大、镜头动了以后画外是什么，都可能挑错。要定，就给尾帧。
3. **一开始方向就会走错的动作，首帧里先让它朝对的方向动一点。** 尾帧定的是结尾，中间怎么走它管不住：给了门往里开的尾帧，门照样先往外转出来，最后两帧跳回尾帧（拍过 1 条）。首帧里门已经往里推开一条缝，这样拍的第一条就开对了。只开一条缝，别画成开了一半：首帧里已经有的结果，这一镜就演不出来。
4. **提示词只写这一镜里动的东西、机位和声音。** 首帧已经把人、地方、光、构图都定了，文字不用再说一遍。不写：场景长什么样、人物外貌、道具外观、风格段。写：谁做什么、做到什么程度、镜头动不动、声音。
5. **同一张首帧拍两条，挑表演更好的那条。**
6. **找到动作刚到位的那一帧，再定取哪段**（`cut.py strip`）：
   - 首帧是动作前的静止样子：成片前面常有一小段起步，取靠后的一段，落在尾帧上。
   - 首帧 + 尾帧的片子，最后一两帧常常跳一下或发虚：片尾 2–3 帧一律裁掉。

```
prompt = "镜头：" + 景别、机位 + 这一镜里谁做了什么（按先后，按画面位置指认：「左边的人」）
       + "声音：…"（只写这一镜画面里有的声音）
       + "要求：全片只有这一个镜头，从头到尾机位固定（或：缓慢推近），不切镜、不换角度、不叠化；画面延续首帧的样子；没有字幕水印；人物不看镜头。"
job    = shot_job(name, 镜头文字, 声音, 首帧, seed, 时长, last_frame=尾帧或不给, camera="机位固定")
clip   = 生成(job)
到位   = strip(clip) 里动作刚到位的那一帧                  # cut.py strip：按 0.1 秒密抽，带帧号
成片段 = clip[起点 : 到位]，最后 2–3 帧一律不要
```

## 生成后检查（不合格就重抽）

- `cut.py strip` 按 0.1 秒密抽着看：动作刚到位的是哪一帧，片尾有没有跳帧或发虚。
- 首尾两帧差得多的（升、摇、拉）：逐帧看中段有没有整幅叠化成尾帧。叠了的改法在上面「必须加尾帧」那一条里。
- 镜头有没有跑偏：门一开外面多出一段楼道、切到一个全景、沙发变了方向。跑偏了先看提示词里是不是写了画面里没有的东西。
- 整套查法和毛病对应的改法见 [4-check](../4-check/overview.md)。

## 好用的规则

- 文字里每多写一样画面里没有的东西，模型就多一个理由切出去拍它。整段的场景、人物、道具描述照搬进来时，镜头会跑偏（门一开外面多出一段楼道、切到一个全景、沙发变了方向）；只留动作、机位、声音以后就不跑偏了。
- 镜头外会发生的事不提（门后有什么、楼下有谁）。首帧里已经有半个人（前景的肩膀）时，文字也别提他，不然他会整个探进来。
- **点名让身体的某个部位动，模型可能新画一个。** 写「食指抬起」，画面上方伸进来一根真人的手指。写成画面里已经有的那一个，再加一句排除别的手：「躺在甲板上的那几根白色手套的手指里，离她靴子最近的那一根，指尖翘起」「不会出现别的手」。改写后拍了 2 条，1 条对；另一条换成中景，整只手都抬了起来。
- **运镜把背景变大多少写成一句看得见的话。** 首帧给不了距离：跟拍时只写「镜头跟着她走」，闸门几秒里就逼到眼前。写「闸门还在六十米外，这几秒里闸门和圆环在画面里几乎没有变大」就对了。白模里量得出这几秒背景变大多少。
- **对画外的东西起反应：写朝画面的哪一边看，不写那样东西。** 写「公交车进站的声音从镜头这边传来」，车被画到了两人身后；写「看向镜头右侧的画外」，两人盯住了镜头。管用的写法：「两人一起把头转向画面右边，侧脸对着镜头，看着画面右边远处」。那样东西的声音单独生成一条只取声音，后期铺。「镜头这边」这个方向不能用，等于让人看镜头；那样东西从哪边来，先在白模里定好。
- **紧张写成具体的小动作，不写「一动不动」「僵直」。** 模型照字面执行，人就成了一张静帧。写余光瞥一眼、肩膀绷紧、手指收紧、咽口水。动作也要对得上此刻的情绪：刚被吓到的人写「低头长长呼出一口气」，拍出来是闭眼犯困。
- **一串有起因有结果的动作比一个动作有戏**：「双手扳手轮，扳不动」只拍出使劲；「拧不动 → 往后一坐用体重拽 → 手轮猛地松了 → 踉跄 → 回头瞪它一眼」就有了戏。白模尾帧里的姿势不用照着拍，首帧对就行。
- **名词会被当成状态。** 写「门缝下透出一条光」，门被打开了一条缝；写「门一直关着，门板纹丝不动；门板底下透出一条光」就好了。
- 声音句里只写这一镜画面里有的：把分镜单元共用的声音段照搬过来（「三个人都闭着嘴」「铅笔声」），到了画面里只有一只脚的镜头，里面提到的人和东西就都成了画外的东西。
- 首帧模式没有人物参考图：人的长相全靠首帧里的那张脸，所以关键帧里的人要先画对；中段转过来的正脸是模型照首帧、尾帧补的。
- 每镜单独生成，镜头之间的环境声不连续：拼的时候每段两端加很短的淡入淡出，后期统一铺一层环境声。
- 同一张首帧拍的两条，第一帧几乎一模一样，可以互相接：把另一条开头的一段倒放，接在这一条前面，倒放那段的结尾正好接上这一条的第一帧，开头就能多看一会儿空镜。

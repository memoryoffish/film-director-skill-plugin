# 分镜单元 + 每镜一张关键帧

一句话：一次生成里放几个镜头（一张分镜时间表），除了人物和道具的参考图，再给每个镜头一张关键帧当参考图，告诉模型这一镜开头长什么样。实测有效（Wan 3.0、Seedance 2.5）。

## 什么时候用

- **用**：亮场里两三个人连着演的段落。好处是表演连着：上一镜的反应和下一镜的动作在同一次生成里，节奏比单拍的接起来顺。
- **它管不住的**（分镜头时逐条对一遍，各条的办法写在后面）：
  - **镜头里的状态变到哪。** 每镜的图只是开头。门往外开还是往里开、人落在哪、头转向哪边，模型自己挑：开门那一镜试了三种单元喂法（每镜一张关键帧、每镜一张白模图、预演当参考视频），门都往外开或看不出往哪开，提示词里写了「往屋里推开」也一样；单拍首帧 + 尾帧才往屋里开。
  - **特写和近景双人的景别。** 参考图只告诉模型「有谁、在哪」，景别它自己挑，而它不爱挑特写：两张脸的近景、手的特写，放进单元里常被拍成全景。一场戏大半是近景的，别先试单元。
  - **暗场。** 参考图一类的喂法会把暗屋画亮，眼睛特写的背景变成亮走廊。
  - **碰上的那一帧。** 每镜时长是按表分的，动作本身只要半秒：多出来的时间被填成重复的动作（抡两次拳），撞击跨在切点上（特写一开始玻璃已经裂了）。收紧每镜时长会好一点，但又可能多切一刀。
  - **后景的小东西会串镜。** 一镜里的门垫跑到另一镜。
  - **切点在有的模型上不照表。** Wan 3.0 的切点几乎正好在表上；Seedance 2.5 不少切也不多切，但时间会挪，靠后的镜头会被挤短。要保证长度的镜头单拍，或单元时长多给两秒，按量到的切点裁（[refs/wan3.md](../../refs/wan3.md)）。

## 思路

1. **写分镜表，管时间。** 第几秒切、每镜的景别和画面内容（写法见 video-film-maker 的分镜单元）。画面里的左右、朝向照 `st.describe` 写，和图一致；反打换边的镜头明写「现在阿杰在画面右边」。
2. **每镜配一张关键帧，管空间。** 这一镜开头的机位、构图、谁在哪、朝哪；只取这一镜的第一帧。用写实关键帧（白模转的，见 [keyframes](keyframes.md)），不用白模静帧：关键帧里场景、光、人的样子几镜之间最统一，图里没有人偶，不会被画进成片；白模静帧当这张图，场景的样子全靠文字、几个单元之间不一致，占位块和人偶的颜色会进画面，暗不下来。
3. **带上人物和道具的参考图，管长相。** 参考图总数有上限，人物道具图占了几张，剩下几张，一个单元就最多放几个镜头；镜头多就拆成两个单元，拆在场景或情绪换的地方。
4. **最后用一句话给后面那几张图派活。** 放在提示词最后；说三件事：这几张图依次对应哪几镜、只用来定什么、不要画什么。
5. **单元的时长比分镜表的总时长多一点**，多出来的由最后一镜延续。同一场戏的几个单元，风格、人物、道具、场景几段逐字相同。
6. **生成，按量到的切点裁**（`cut.py split_unit`）。

```
shots  = [(开始, 结束, "机位与景别", "画面：谁在画面哪边、朝哪、做什么"), …]     # 画面里的左右照 st.describe 写
blocks = [风格, 人物, 道具, 场景, 声音]                                        # 每段一行，几个单元逐字复用
refs   = [人物图…, 道具图…]
extra  = [每镜一张关键帧]                                                       # 顺序和镜头一致
guide  = key_guide(len(refs)+1, len(shots))
job    = unit_job(name, shots, blocks, 参考图说明, refs, guide, seed, 时长, extra_refs=extra)   # Seedance 加 model="seedance-2.5"
```

## 生成后检查（不合格就重抽）

- 切点对着分镜表看，按检测到的切点裁（`cut.py split_unit`）。
- 上面「它管不住的」那几样有没有出现：门的开向和落点、特写被拍成全景、暗场被画亮、动作重复或撞击跨在切点上、后景的小东西串镜。
- 单元里哪一镜不对，把那一镜单独用首帧（或首帧 + 尾帧）重拍，别的镜头留着。
- 整套查法和毛病对应的改法见 [4-check](../4-check/overview.md)。

## 好用的规则

- 镜头里要变的东西写在文字里；要变到确定结果的，这一镜拿出来单拍首帧 + 尾帧。
- 单个镜头用参考图时用 `ref_job`（提示词里没有时间表那一套）。

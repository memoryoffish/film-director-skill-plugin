# 预演当参考视频

一句话：把白模预演（一个镜头，或按切点拼好的一个单元）当参考视频给视频模型，换来的是位置、时刻和运镜的精度。预演里的人只放没有四肢的替身：它只表示人在哪、朝哪、什么时候走到哪，怎么走交给视频模型。场景的样子和光，靠一起带上的关键帧（当参考图）。实测有效（Wan 3.0）。

## 什么时候用

- **用**：人一直在移动、文字和关键帧定不住路线、要卡全程路线和时刻的镜头：走位、跟拍、卡门窗掠过的时刻、复杂运镜（人是正面，或在画面里不大）。参考视频给的是精度：人在画面里的位置跟得更紧、入画和坐下的时刻卡得住、跟拍里人的大小不变、路线和节奏照预演。
- **用，再加一张图**：开头站定一下、然后一直在走的镜头：替身预演 + 一张带关节的首帧静帧当参考图（治开头的站姿）。
- **不用**：
  - 两三个人、常规动作的镜头：只给文字和人物图，站位、先后、运镜方向本来就对。
  - 只要落点准的镜头：首帧加尾帧就够，质感和动作都更好。
  - 站着说话、对视、吃饭、原地做动作（击掌）；几个固定机位连着拍、人不怎么走动的单元：每镜一张关键帧，或只用文字。替身不动，人就站成柱子。
  - 中途或结尾要站定、蹲、坐下：改用首尾关键帧；一定要卡全程路线时才用替身预演，多拍几条挑。
  - 人一直在走、但是背影且在画面里大：关键帧当首帧，文字写清背景变多大。胶囊会被当成场景里的一根柱子画进成片（只测过一次）。
  - 打斗、推搡这类肢体戏：照 [overview](overview.md) 用分镜单元或只用文字。只要落点的单独一拍试过替身预演 + 首帧静帧：两条里一条全程自然。
  - 要画外对（运镜新露出来的东西）：用首帧 + 尾帧。

## 思路

1. **场景脚本只写一份，开头留一个开关。** `Stage(fps=30, stand_ins=喂)`：不带开关时人是带关节的人偶，出静帧、出自己看的预演；带上开关，同一份脚本里所有人都换成没有四肢的替身，别的不变，渲要喂的那版。
2. **先在自己看的那版上把预演改对：里面错的会被照着学。** 用 `st.timeline()` 看每段走路走多快：走路每秒 1.2–1.4 米，比每秒 1.8 米快的是快走或跑，不是这场戏要的就放慢。从静止起步、走到停下的缓起缓停；开头结尾都在走的镜头用 `walk(…, ease=False)` 匀速，不然人在头尾慢下来、和镜头对不上。道具放在说得通的位置上；替身的站位点别和家具叠在一起，停在椅子前面再坐。
3. **渲替身版。** 预演和生成的视频一样长，切点、时长对齐，帧率和成片一致；画面里不加任何标注、字幕、网格。拼好的文件另起名字，每镜留下 `pv_<镜头>_capsule.mp4`，不盖掉自己看的那版。
4. **写任务，一定带上关键帧当参考图。** 预演只管路线、时刻和运镜，别的靠图：人物、道具图管长相；这一镜的关键帧（`key_guide`）管场景的样子和光。还没有关键帧就先去出（[keyframes](keyframes.md)），不拿预演加人物图单独喂。`video_guide` 写明视频只定机位、运镜、站位、路线和切点，图例说清哪个颜色的替身是谁。路线和运镜预演已经给了：文字里不再写另一套镜头运动，要写就照着预演说一遍。开头要站定的，再加一张带关节的首帧静帧（`still_guide`）。
5. **生成，对着预演看**（见下面「生成后检查」）。

```
喂 = "--feed" in sys.argv                              # 同一个场景脚本跑两遍：不带它，出静帧和自己看的预演；带上它，渲要喂的那版
st = Stage(fps=30, stand_ins=喂)                       # stand_ins=True：脚本里所有人都换成没有四肢的替身，别的不变
…搭场地、摆人、排时间线（两遍用的是同一份）…
if 喂:
    st.previz(单元的镜头, "wm/feed_U1.mp4", samples=8)  # 拼好的文件另起名字；每镜留下 pv_<镜头>_capsule.mp4，不盖掉自己看的那版
legend = "蓝色替身是阿杰，红色替身是小周，…"
guide  = video_guide(镜头数, legend)                   # 一个镜头时写 1：说法变成单镜的
图     = 每镜的关键帧                                  # 一定带，接在人物、道具图后面：场景的样子和光照它
guide += key_guide(len(refs) + 1, 镜头数)
if 开头要站定:                                        # 带关节的首帧静帧
    guide += still_guide(len(refs) + len(图) + 1, legend);  图 += [首帧静帧]
job = unit_job(name, shots, blocks, 参考图说明, refs, guide, seed, 时长, extra_refs=图, video="wm/feed_U1.mp4")
  或 ref_job(name, 镜头文字, blocks, 参考图说明, refs, guide, seed, 时长, extra_refs=图, video="wm/pv_s3_capsule.mp4")   # 单镜
```

## 生成后检查（不合格就重抽）

- 路线和时刻：`st.timeline()` 列出预演里每段走路的起止秒数和速度，和成片里同一段比。
- 人有没有站成柱子（两脚并拢、身子笔直）：替身静止的段落会这样。开头的可以用首帧静帧治，中间和结尾的还没有治法；改说明没用，换种子有时行。
- 上下黑边：固定机位喂参考视频的几乎每条都有（各 40–60 像素），镜头在动的也出过。裁掉再放大，或换喂法。
- 白模的东西有没有进画面：布景里的占位块、被画成柱子的替身、悬着的道具。
- 整套查法和毛病对应的改法见 [4-check](../4-check/overview.md)。

## 好用的规则

- **预演里的人只放没有四肢的替身。** 带关节人偶的预演喂进去，人偶怎么站、每秒走几步、手举在哪、哪一拍不动，成片都照着来：人并脚垂臂站着，动作成了一个姿势接一个姿势；提示词里写「人偶不提供肢体动作」拦不住。替身只滑动、转向、变矮，走路是模型自己演的。带关节的人偶留着自己看、出静帧。
- **替身不动，人就站成柱子。** 替身静止的拍子，人并脚直立；替身变矮会被照成深蹲、僵硬的落座，蹲得太低会被当成出画。坐下、蹲下交给文字或首尾关键帧。
- **预演本身得是一条好的预演。** 替身走得太快、起步和停下太突然，成片里的人像瞬移；道具方块悬在半空，成片里的东西也悬着。
- **替身要被认成人。** 正面能看见脸牌、或者人在画面里不大时，胶囊替身被认成人；背影跟拍、人在画面里又大时认不出来。
- **参考视频只管路线，不管画外。** 运镜新露出来的部分照样靠编（升起来以后闸门上半截发白）；只带人物图时，场景也是模型自己想的，和别的镜头不像。要画外对，用首帧 + 尾帧。
- **带上这一镜的关键帧当参考图，场景和光就照关键帧。** 同一条替身预演、固定机位、两人交叉走过：只带人物图的两条，墙和窗是模型自己想的，上下都有黑边；再带上关键帧的两条，墙、灯、地面、窗外都照关键帧，没有黑边，路线和时刻照样跟预演（一镜，各两条）。
- 布景里的占位块会进成片（见 [做多细](../1-build/fidelity.md)）；暗场会被画亮。
- 预演比生成的视频短时，预演一放完模型就另起一镜。
- 匀速可以用：人和镜头都匀速的后退跟拍没有滑步。
- 两套镜头运动（预演一套、文字另一套）不一样时，模型同时收到两个互相矛盾的指令（调研里别人的经验，我们没单独测过）。
- 门洞、窗洞要搭上门扇、窗框和后面的空间，不然被画成一块板。
- 门、窗后面搭出了空间，模型可能往里放路人；不要就在文字里写明外面没有人（这句没测）。
- 参考视频的秒数和成片的秒数一起计费，接口对总长有上限（[refs/wan3.md](../../refs/wan3.md)）。
- 渲染：`previz(samples=8)` 当参考视频够用（Mac 上比默认快三倍左右，GPU 服务器上约 1.5 倍）；只改了几镜时用 `only=[…]` 重渲那几镜（还没渲的镜头也会一起渲），渲到一半停了、要接着渲时用 `missing=True`。长片怎么渲得快见 [scripts/overview.md](../../scripts/overview.md)「长片的预演」。
- 别人的经验（多在别的模型上）：没有四肢、正面有标记的粗替身比带骨骼的假人稳；给小人做了迈腿的动画，成片走路反而僵，去掉动画只平移就自然；替身长什么样关系不大，要紧的是按真人速度走、起停有缓动。和我们在 Wan 3.0 上测到的一致。出处见 [refs/research.md](../../refs/research.md)。

# 1-build：搭

把一场戏搭成一个 Blender 场景：场地、门窗、家具、人偶、机位、时间线。用 [scripts/blocking.py](../../scripts/overview.md) 把场景写成一个 Python 文件（`scene.py`），改一行就重跑一次，几秒就出图。

## 这一步交出什么

- `scene.py`：一个场景、一条时间线，所有镜头的机位都架在里面。
- 往下走之前：出一张平面图和几张静帧，开头写下的那两三件最容易错的事，在这些图里都看得出来。

## 推荐

- **先写下这场戏空间上最容易错的两三件事，白模就为这几件事搭。** 比如：门往哪边开、它开着的时候挡住谁；两个人蹲在岛台对角互相看不见；俯拍里两人绕着同一样东西转。搭多细、架几个机位、出几张图，都从这几件事倒推；和它们无关、文字本来就拍得对的镜头，不为它多搭东西。
- **一场戏一个场景，一条时间线。** 所有镜头共用同一个场地和同一批人偶，镜头表就是 `[(镜头名, 机位, 开始秒, 结束秒), …]`。这样反打、切特写之后，门、楼梯、沙发还在原来的地方。拍到一半要补一镜时，把它的动作排在时间线的最后，在镜头表里把它放到片中该在的位置；这样前面排好的动画关键帧都不用挪。
- **尺寸用真的（米）。** 门、台阶、家具、人的身高、镜头高度和焦距都按现实填；模型按比例读画面，尺寸假了，人和东西的大小关系就假。常用尺寸见 [fidelity](fidelity.md)。
- **先搭会被照搬的东西。** 墙、门（门框 + 门扇 + 门后的空间）、窗（墙上的洞 + 框）、台阶、栏杆、主要家具。认地方用的地标，挑「别的机位也看得见」的：要让几个机位拍出来认得出是同一个地方，靠的是每个机位里都有两三样共同的东西。只在一个镜头里出现的陪衬交给文字。
- **门在搭的时候就定好合页在哪一侧、往哪边开**（`door(…, into=…)`）。门往外开还是往屋里开，模型不会替你想对。门、柜门这类薄板，别让它在某个机位里停在正好侧对镜头的角度（门板在画面里只剩一条线时会被画成两扇）；换个角度，让同一面始终看得见。楼上、平台上的门，把门所在的高度写进合页坐标 `hinge=(x, y, z)`：只写 (x, y) 时，合页常落在地板边上、两块地板的接缝上，工具查不到下面的地板，门就会掉到地面高度（出图前工具会报错，并写出该改成的 hinge）。
- **窗开着还是关着对戏有影响，就把窗扇搭出来。** `window` 只有窗框；用一块薄板（`box`）搭窗扇，关着就立在框里，开着就搭成推开的角度。只留一个空框，出图时多半被画成关着的玻璃。门也一样：每镜开头门是开着还是关着，都在时间线里排上（`door.open`）。
- **楼的正面、楼梯间每层一扇窗：搭一面整高的墙**，在 `windows` 里同一个位置（离墙起点一样远）上下写几扇，每扇的窗台高都从墙底量起，不用把墙按层分成几段。
- **封闭空间要盖顶、补光。** 盖了天花板的走廊、屋子不会变黑，而是墙、地、顶一片同样的灰，窄的走廊和屋子的静帧就看不懂；所以 `ceiling()` 自带一组弱的无影补光。几十米高的大机库，不加灯静帧也看得懂（只测过一次）；要加灯时别开太亮，一下子就整片发白。从上面往下拍的那一镜，把天花板、门上那截墙、门楣藏起来（`camera(…, hide=[…])`）；墙外面空的地方用一块黑色实心块堵住，不然模型会编出隔壁。
- **人偶用身份色，道具用真颜色。** 每人一种醒目的纯色（蓝、红、黄、紫），再加一两个标记（眼镜、帽子、长发）和真实的身高差；提示词里按颜色点名：「蓝色人偶就是阿杰」。道具不一样：颜色要紧的道具（白橡皮、红袜子、白毛巾）白模里就涂成它真的颜色，涂成醒目色会被照着画。
- **姿势摆「起」和「落」两个时刻，摆到看得出在干什么。** 这一下开始时（拳已经收到耳后、人已经扑出去）和结束时（碰上、坐定、落地）各摆一组动画关键帧；中间怎么动交给文字（带关节人偶的预演只给自己看，不当参考视频：见 [ref-video](../3-feed/ref-video.md)）。工具里现成的姿势摆得像人的（收拳、蹲、弯腰、坐）就摆；摆不像人的（被撞飞、摔、扭在一起）白模只给位置和朝向，姿势写在文字里——摆出来的怪姿势会被出图模型照搬。两个人别摆成一模一样的姿势（同样坐正、膝盖并拢、手放腿上），成片里会像摆出来的。
- **会动的都在时间线上排动画关键帧。** 人走位（`walk`）、门开合（`door.open`）、被推动的道具（`st.key`）、镜头运动（`camera_key` 匀速、`camera_move` 缓起缓停）。从静止起步、走到停下的用 `walk` 的缓起缓停；镜头开始和结束时人都在走的用 `walk(…, ease=False)` 匀速。走路按每秒 1.2–1.4 米算时长，镜头时间不够就改镜头表，不要让人滑过去。
- **白模摆不出来的，只给位置。** 人偶只有十几个关节，复杂的肢体和接触（拥抱、扭打、手平放在东西上）摆不出来；人和东西较劲（抬着沙发斜上楼梯、卡在门框里、拔出来、放倒）也摆不出来。这类镜头白模只定之前和之后人和东西各在哪，接触本身写在文字里：谁的哪只手抓在哪、往哪边使劲、东西怎么动。一镜里状态要变两次的，拆成两段（见 [continuity](../2-look/continuity.md)）。
- **大件道具在一镜里竖起、翻转、转半圈（比如沙发），不交给白模演。** 白模只摆开头和结尾两个状态，中间的过程拆成两镜，或用首帧 + 尾帧，怎么转写在文字里。
- **弯的、软的、自然的东西只能占位。** 场地是方块拼的，树、布、水、人群搭不出来，船体的曲面也只能用圆柱、锥台、球拼个大概；没搭出形状的大件会被画成最省事的样子（长方体的船成了一面墙），所以巨物至少要拼出船头船尾这样的大形（见下面按类型）。
- **碰上的那一帧，只放在一个镜头里。** 拳头砸上玻璃、手碰到手：宽镜头里砸上了，下一镜特写里又砸一次，就成了两下。搭时间线时就定好碰上的那一刻归哪一镜，别的镜头停在碰上之前或之后。
- **先按镜头表写的景别架机位，出了静帧再挪。** 平视镜头高 1.4–1.6 米，焦距 27–45mm；关键动作（手和锁、两张脸）要在画里，前景别让栏杆、家具挡住人。窄空间里机位只能放在空间里面，过肩和特写容易把人切出画，多出几张静帧来挑。
- **楼梯间：上面那段楼梯搭成底下空的。** `stairs()` 默认是实心的楔子，搭在地面上的一段没问题；从平台往上的那段也会是一整块平底的实心块，压在下面那段楼梯的头顶上，下面的机位只看见一块灰板。底下要放机位、要走人的那段楼梯写 `solid=False`（搭成一层 0.15 米厚的梯段板）。机位要是放进了实心的东西里，`describe` 会报【要改】「镜头在 X 里面」。

## 按类型

- 剧情、喜剧：门（开向、合页在哪边）、家具、楼梯这些人要打交道的东西要准；一个地方多个机位。
- 打斗：一块够大的空地 + 一排数得出来的参照物（第几列机器、第几根柱子），落点用它定；每一招一组「起」和一组「落」的动画关键帧；所有机位架在两人连线的同一侧。
- 悬疑：走廊、门、拐角的长度和间隔；封闭空间盖顶补光；光源做成黄色的球或条占位；揭示的东西放在哪、从哪个点才看得见。
- 恋爱：两人的距离按戏分几档（各坐一头 → 挪过来 → 肩挨肩），每档量一下；两人的姿势做出差别；首尾呼应的两个镜头用同一个机位。
- 科幻、大场面：巨物和人按真实比例搭（人 1.7 米，舱门 2 米，船体几十米）；巨物要搭出它的形状（船头船尾、曲面）；人身边放几样按人的尺寸做的东西（小门、梯子、油桶、车）当尺子。
- 二维动画：和写实一样搭；镜头可以更夸张（贴地、俯拍）。颜色要紧的小道具用真颜色。

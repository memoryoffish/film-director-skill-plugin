# 白模做多细

一句话：会被模型照搬的几何和颜色做准，正对镜头、要一眼认出来、后面别的机位还要看见的东西搭出形状，其余占位或不搭；两种人偶各有用处：带关节的给自己看、出静帧，没有四肢的替身放进当参考视频的预演。

## 四档

| 档 | 是什么 | 做法 |
|---|---|---|
| 做准 | 墙和门的位置、门的合页在哪边和往哪开、台阶、栏杆、人要坐要推要靠的家具、人的身高差、人和东西的间距、镜头高度和焦距、颜色要紧的道具的颜色 | 按真实尺寸和真颜色填；出静帧核对 |
| 搭出形状 | 窗、椅子这类正对镜头、要一眼认出来的东西；后面还有别的机位要看见、要靠它认地方或认大小的东西；巨物本身（船头船尾、曲面） | 窗是墙上的洞加一圈框、中间一根竖的窗梃（`wall(windows=…)`）；椅子是座面、四条腿、靠背（`chair()`）。不拿纯色平板或实心方块代替 |
| 占位 | 楼层号、招牌、桌上的关键道具、远处的建筑、斜着看过去成排的窗、光源 | 一块颜色不同的方块、圆柱或球；转关键帧时逐样说明它是什么。形状别和真东西差太远（手轮搭成圆环加十字，不是一块圆盘） |
| 不搭 | 材质、花纹、小摆设、表情、手指、头发衣服的细节、只在一个镜头里出现的陪衬 | 交给参考图、关键帧和文字 |

- 少搭的代价是模型自己编：没搭门，那面墙上可能没有门，也可能门在别处；没搭的梯子、油桶由模型找地方放，下一个机位就对不上。多搭的代价是多余的形状也会被照着画。
- **占位块直接喂给视频模型，会被照着画出来，在提示词里说明它是什么也不管用**：正对镜头的一块浅蓝色平板成了墙上一块蓝板，实心方块椅子成了木墩，紫色方块留在了真自行车旁边。占位块只在「先转成关键帧」这条路上安全（出图模型看得懂提示词里的说明），即便这样，方块家具仍可能被画成方墩。
- **颜色会被照着画。** 人偶的身份色转关键帧以后不进成片；道具的颜色会：拿黄色方块当白橡皮，直接喂时成片里的橡皮是黄的，转关键帧时也偶尔画成黄的；白模里那堆衣服是什么颜色，关键帧和成片就倾向什么颜色。颜色要紧的道具用真颜色；非用醒目色不可时，在图例里逐件点名，出图后专门看这一件。
- 空的门洞会被画成一块关着的门板。门要搭门框、门扇（哪怕开着）和门后的地面、墙。
- 座高、台阶高错一点，人就会坐到靠背上、踩在半空。坐姿的人偶放上去以后看一眼侧面的静帧。
- 人走过去坐下：站位点停在椅子前面，不放在椅子的位置上。人和椅子叠在一起的那几帧，会被照成穿过椅子或侧着身子硬坐。
- 封闭空间：盖顶后补光（`ceiling()` 自带），从上面看时把顶藏掉；见 [overview](overview.md)。
- 白模是亮的。夜戏的暗全靠出关键帧时的文字：白模里把光源做成黄色的球或条占位，文字里写明每一处光从哪来。

## 两种人偶

| | 带关节的人偶（`kind="jointed"`，默认） | 胶囊替身（`kind="capsule"`；`Stage(stand_ins=True)` 把脚本里所有人都换成它） |
|---|---|---|
| 样子 | 头、躯干、四肢，十几个关节可摆；胸牌、鼻子、脚尖标正面 | 一根圆柱加一个头，没有四肢；脸牌和鼻子标正面 |
| 用来 | 自己看：站位、朝向、遮挡、姿势、预演的节奏；出静帧当参考图、转关键帧 | 放进当参考视频的预演：只表示人在哪、朝哪、什么时候走到哪 |
| 当静帧（参考图、转关键帧） | 用它。姿势看得懂；关键帧会照着白模里的姿势画，所以摆成这一镜开头真该有的样子 | 不用：看不出姿势（坐、蹲只是变矮） |
| 当参考视频 | 不用。人偶怎么站、怎么动、哪一拍不动，成片都照着来：人并脚垂臂站着，动作成了一个姿势接一个姿势，手举在嘴边停着；提示词里写「不提供肢体动作」也拦不住 | 用它。替身动起来时，人怎么动是模型自己演的。静止时人会并脚直立；替身变矮会被照成深蹲、僵硬的落座，或者干脆出画 |
| 要小心 | 它的预演只给自己看，不喂 | 替身不动的镜头不给参考视频；背影、人占画面大时被当成一根柱子画进成片（只测过一次）；开头要站定时配一张带关节的首帧静帧 |

- **人偶感是从参考视频里带进成片的。** 人偶、胸牌、纯色身体、身份色，在先转关键帧以后都不进成片；带关节人偶的预演当参考视频时，它的站姿、步子、停顿都会被照搬。所以参考视频里只放没有四肢的替身：同一个场景脚本用 `Stage(stand_ins=True)` 再渲一遍。
- 颜色：身份色（蓝、红、枣红、黄、紫）和衣服颜色分开，图例里写「蓝色人偶 = 林夏（穿什么见人物图）」。把人偶涂成衣服的颜色时出过朝向错；身体全灰、只留眼镜帽子胸牌的人偶，和身份色人偶比，在两个高矮差一头的人上没测出差别。
- 标记：眼镜、帽子（正戴、反戴）、卷发、长发，两种人偶都有；短裤只有带关节的人偶有。够把两个人分开就行。
- 人偶身上没有的东西（包、手电、耳机）不搭也行，但它在身体哪一侧、在不在手上，要写进每一张关键帧的文字。
- 人背对镜头时胸牌和鼻子都看不见：文字里要写明「背对镜头」；定妆要有一张背面图。
- 身高和体型：`height`、`build` 按人设填；高矮差在画面里要看得出来。

实测的条数和量出来的数在 [examples/fidelity](../../examples/fidelity/notes.md)、[examples/feeding-tests](../../examples/feeding-tests.md)、[examples/scifi-tenth](../../examples/scifi-tenth/notes.md)。

| 东西 | 尺寸 |
|---|---|
| 人 | 身高 1.55–1.85；肩宽约 0.45；走路每秒 1.2–1.4 米、每秒 1.4–1.8 步（步长 0.7–0.9）；快走每秒 1.8 米；跑每秒 3–5 米 |
| 门 | 宽 0.8–0.9，高 2.0；入户门锁离地约 1.0 |

| 房间 | 层高 2.8；走廊宽 1.2–1.8；老楼的楼梯平台约 2.4 × 3.2 |

## 没测完的

- 胶囊替身静止的那段，人站成柱子的样子怎么治：改说明没用；没试过把预演里静止的头尾裁掉、让静止的替身带一点重心晃动。
- 带关节人偶的走路循环只有两个姿势、膝盖弯得很少；侧面看成片的腿也直。四个姿势的循环会不会更像，没测。
- 预演里坐下的时刻挪一挪，成片跟不跟着挪（出拳挪了 1 秒，跟了；坐下只测了一个时刻）。
- 人偶不动的那几拍，成片里人也不动，怎么治：加一点上下晃动没用（椅子前只停 0.25 秒，成片也直挺挺站了一下）；没试过给换重心的小动作。
- 快走、跑的步频该配多少；手上的细活、多回合的打斗交给人偶行不行。
- 灰人偶用在参考视频喂法上、用在两个长得像的人身上，行不行。
- 背影跟拍里胶囊成柱子、带关节人偶对，只各拍过一条。

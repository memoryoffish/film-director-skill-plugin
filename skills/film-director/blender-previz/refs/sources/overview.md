# sources：调研的原件

2026-11-17 那次调研「别人怎么用 Blender 白模管 AI 视频」留下的全部文字，照原样放在这里，没有改写。上一层的 [research.md](../research.md) 是从这里整理出来的摘要，平时先看摘要，要原话、要出处、要核对许可证时再来这里。

- [research.md](research.md)：完整调研。每条结论带原话和出处，分主线做法、各模型官方文档、提示词写法、翻车点、工具几节。
- [sources.md](sources.md)：读过的全部链接。每行写标题、链接、平台、讲了什么、有没有用；没用上的、没读成的也列了。
- [assets.md](assets.md)：免费资产的候选表和许可证核对。每一行写了打开看过的页面和许可原句。
- [notes/models_notes.md](notes/models_notes.md)：各家视频模型官方文档的底稿。
- [notes/tools_notes.md](notes/tools_notes.md)：白模相关工具的底稿。

底稿里有几处提到 video-film-maker 的 `refs/models.md`，写的是调研当时的路径（现在是 `refs/practical/models.md`），只是出处记录，用这份 skill 不需要去读它们。

# blender-previz

一句话：一场戏先在 Blender 里搭成白模，自己先看明白这场戏在空间里是怎么回事，再把白模变成视频模型用得上的参考，成片对着白模查。拍片本身（剧本、定妆、衔接、后期）看 video-film-maker skill；这里只管「空间」。这个 skill 也可以单独用：手里有一张镜头表（每镜几秒、什么景别、谁在哪做什么）就能开始。文中的路径都相对于本目录。

## 核心思路

1. **白模先是给你自己看的。** 一场戏只搭一个场景，所有镜头的机位都架在这同一个场景里。谁在画面左边、谁看得见谁、反打以后换没换边、门往哪开、两人隔多远、要几秒走到，都从白模里量出来，不靠想。白模静帧看不懂的，成片也不会拍对。
2. **白模换来的是精度。** 两三个人、平视、常规动作的镜头，只给文字和人物图本来就拍得对。白模管的是文字说不准的东西：特殊角度、几镜认得出是同一个地方、间距和落点、视线、尺度、时刻。不是每个镜头都值得上白模：先写下这场戏空间上最容易错的两三件事，再一镜一镜判断上不上白模、怎么喂，连同理由写进计划。
3. **白模其次才是给视频模型的参考，几样输入各管各的。** 白模管位置、朝向、机位、构图；人物和道具的参考图管长相；文字管表演、光、声音。白模先转成写实关键帧（照着白模的机位和站位画成的一张成片质感的画面）再喂给视频模型，提示词里写明每张图干什么用。带参考图、参考视频的喂法（r2v），一定带上关键帧当参考图：白模静帧和预演只给位置和路线，不带关键帧，场景的样子是模型自己编的。
4. **白模里有什么，成片里就有什么。** 白模里的空门洞会被画成门板，座高错了人会坐到靠背上，占位块的颜色会被照着画，白模里没搭的东西模型会自己编。要做准的是会被照搬的几何和颜色。
5. **白模里的人分两种用。** 带关节的人偶给你自己看、出静帧转关键帧：站位、朝向、遮挡、姿势都看得懂，转成关键帧以后人偶的样子不进成片。当参考视频的预演里只放没有四肢的替身：它只表示人在哪、朝哪、什么时候走到哪，怎么走、手上做什么交给视频模型和文字。带关节人偶的预演不喂：人偶怎么站、怎么动、哪一拍不动，成片都照着来。没什么移动的表演镜头不给参考视频。
6. **一镜里状态要变到一个确定的结果，就给尾帧。** 门往哪开、人落在哪、头转向哪边、谁进画、露出什么新东西——只给开头一张图，模型会自己挑一个结果，常常挑的是错的那个。尾帧只定结尾，管不住中间怎么走：门的开向这种一开始就会走错的，首帧里就先让门朝对的方向开一条缝。
7. **成片对着白模查，也查合不合理。** 站位、朝向、机位、切点对着白模看；再看门的开向、东西的大小、道具跨镜接不接得上、动作有没有来由。

## 四步

开工前先定 Blender 在哪台机器上跑：出静帧、渲预演（把白模按镜头表渲成视频）是重活（两分钟的片渲一遍预演约 30 分钟），用户有服务器就把 `scene.py` 和 `scripts/` 放到服务器上跑，本机只看图。没人回答时（非交互地跑）：用户事先给了服务器就放服务器，没给就在本机跑、预演用 `previz(samples=8)`，并写进报告（见 video-film-maker 的 [规矩](../video-film-maker/stages/common/rules.md)「没人回答时」）。

1. **搭**：按真实尺寸搭场地，摆人偶，架机位，排时间线。[stages/1-build](stages/1-build/overview.md)
2. **看和算**：出平面图、每镜静帧、站位描述，查越轴、遮挡、视线、间距、每镜首尾哪里变了、道具状态、人偶的关节和手（够不够得着、是不是在身前），改到每张静帧一眼看得懂；定每镜怎么喂。[stages/2-look](stages/2-look/overview.md)
3. **喂**：白模转写实关键帧，每张出完先和它的白模静帧并排看、对了才往下用；再按镜头挑一种喂法：关键帧当首帧、首帧 + 尾帧、分镜单元（一次生成里按时间表切几个镜头）+ 每镜一张关键帧、只放替身的预演（白模按镜头表渲出来的视频）当参考视频 + 这一镜的关键帧当参考图。[stages/3-feed](stages/3-feed/overview.md)
4. **查**：切点、站位、白模痕迹、合理性；按毛病回到对应的一步改。[stages/4-check](stages/4-check/overview.md)

## 每种类型的戏，白模管什么

- **剧情、喜剧、多人对戏**：同一个地方的几个机位、正反打时人在画面哪一边、人和道具和门的相对位置、门往哪边开。
- **悬疑**：地方和视线——谁从哪里看得见什么、隔多远；揭示镜头里该露的在画里，不该露的在画外。
- **打斗**：白模只定每一招「起」和「落」时两人在哪、什么架势（用场景里数得出来的东西定，比如第几根柱子），两人左右全程不变；这些写进提示词。不拿白模关键帧当首帧，打斗和连续肢体戏用分镜单元或只用文字：用白模首帧一招拍一条，拍出来动作僵、镜头乱。
- **恋爱**：两人的距离一档一档怎么变，和「同一个地方」——开头结尾用同一个机位，只有人的位置变了；所有机位放在两人连线的同一侧，两人的视线方向自然就对得上。
- **科幻、大场面**：共同地标和尺度——每个机位里都留着别的机位也看得见的东西；人和巨物的大小比，出关键帧后量。
- **二维动画**：白模只用来出关键帧（构图、站位、地标、贴地和俯拍这类角度），不直接喂给视频模型。

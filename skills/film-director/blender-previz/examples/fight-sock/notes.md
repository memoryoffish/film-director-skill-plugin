# 《一只袜子》：打斗，一招一条

深夜的自助洗衣店。大刘（一米九的光头壮汉）一脚踢飞小满（一米六，黄卫衣，马尾）的洗衣篮，一只红袜子落在她脚边。三个回合：他两次把拳头砸在机器上（玻璃门、铁皮），她借他的劲把他甩到他自己打裂的那台烘干机下面。她捡起袜子扔进洗衣机，在他旁边坐下，滚筒转起来。

Wan 3.0，720P，写实。成片 27.27 秒，14 个镜头，30 fps，没有台词和配乐；白模预演和成片同样 818 帧。视频生成 31 条，出图 32 张（定妆 2、关键帧 30）。成片和中间文件没有放进仓库；本目录的 [scene.py](scene.py) 是当时的白模脚本。

## 白模管了什么

- **左右全程不乱。** 14 个机位都架在两人连线的南侧，大刘永远在画左、小满永远在画右；`st.flips()` 返回空。31 条生成里每一镜开头和结尾的左右都对，包括斜侧机位、过肩、五种单元喂法和纯文字那一条。唯一的例外是甩人那半秒两人转了半圈，模型自己的甩法。
- **距离和每一招的落点，用「第几列机器」定。** 北墙 9 列上下两层机器，落点数得出来，关键帧和成片里都数得出来：
  - 第一回合在第 5、6 列跟前，两人相距 0.72 米（摆拳的距离），拳头落在第 5 列上层烘干机的门上；
  - 她一拳之后他退开，两人拉开 1.3 米；
  - 第二回合他把她顶退 1.45 米到第 8 列，第二拳落在第 7、8 列之间的铁皮上，在她左耳边 0.3 米；
  - 第三回合她把他甩回第 5 列，正是第一拳打裂的那台下面；结尾他坐第 5 列前、她坐第 7 列前，中间是她那台洗衣机。
- **被打坏的东西当连续性的锚。** 裂了的烘干机门从 s05 起在每个看得见它的镜头里都在，最后衣服从它里面掉出来。
- **姿势只摆「起」和「落」。** 每一招的开头（拳已经收到耳后、人已经扑出去）和结尾（碰上、被压在机器上、滑坐）各一组关键帧，自己补了 19 个姿势；中间怎么抡、怎么甩只写在文字里。

## 喂法对照：第一回合（摆拳 → 砸玻璃 → 还一拳）

计划切点 1.8 / 3.0 秒。

| 喂法 | 实测切点 | 结果 |
|---|---|---|
| 单元 + 每镜一张关键帧 | 1.80 / 2.97 | 左右、机位对；1.8 秒的第一镜里他抡了两次，拳没在这一镜落下；特写一开始玻璃已经是裂的 |
| 单元 + 每镜一张白模图 | 1.80 / 2.97 | 同上；裂了的门没带到第三镜；没有人偶进画 |
| 单元 + 只有文字（站位照 describe 写） | 1.80 / 2.97 | 左右对；第三镜变斜侧过肩；三镜的机器长得不一样 |
| 单元 + 胶囊预演当参考视频 | 1.77 / 2.97 / 4.93 | 开头 0.5 秒站着；她一蹲就出画（胶囊只会变矮）；第三镜机位漂成斜侧；预演 5 秒、生成 6 秒，预演放完多切一刀 |
| 单元 + 带关节人偶预演当参考视频 | 1.77 / 2.97 / 4.93 | 前 0.5 秒照着姿势走，人偶停住的那段被填成再抡一拳；第三镜成了仰拍斜构图；同样多切一刀 |
| 单元，每镜时长收紧到 1.1 / 0.9 / 1.6 秒 | 1.10 / 1.97 / 2.80 | 只抡一次了，特写里玻璃从好到裂；但第三镜中间多切一刀 |
| 单镜，首帧 = 拳已经收到身后 | — | 第 1 帧就出手，0.7 秒打完 |
| 单镜，首帧 = 两人只是站着（中性白模） | — | 前 0.9 秒站着蓄力，拳是软的 |
| 单镜，首帧 + 尾帧（拳在玻璃上） | 1.97（片尾） | 0.57 秒砸上、玻璃裂，之后停着；最后一帧跳到尾帧 |
| 撞击特写，首帧 = 拳离玻璃一巴掌 | — | 0.2 秒碰上，裂纹一圈圈铺开，碰得实 |
| 同上 + 尾帧 | 0.47 | 碰上了，但裂纹是一帧之内变出来的 |
| 还一拳，首帧 / 首帧 + 尾帧 | — / 1.97（片尾） | 两条都看得懂；加尾帧的落点更准 |

结论：一招一条，首帧是招已经起了的那一刻，要落到某处的加尾帧，剪在刚到位的那一帧。单元管得住在哪、几秒切，管不住第几帧碰上；参考视频两种替身都把动作时间拍错。首尾帧的片尾跳帧：14 条里 8 条在最后一帧量得出切点，2 条最后几帧发虚。

只给首帧和加尾帧的对照：s09 只给首帧，拳头停在她耳朵边上没砸到铁皮，加尾帧砸出一个坑；s07 只给首帧两人原地推搡没有后退，加尾帧顶着她退了一米半；s11 只给首帧，甩完画面里冒出一个墙角。

## 改过的地方

| 看到的 | 原因 | 改法 |
|---|---|---|
| 结尾一镜塞了五件事拍不出来 | 一条里动作太多 | 拆成 s13（近景，三件事）和 s14（全景，坐下） |

| s04 → s05 玻璃碎了两次 | 宽镜头里已经砸上，特写又砸一次 | s04 剪在拳头到玻璃的前一帧，让特写来碰这一下 |

## 还剩的毛病

- s04 只有 0.53 秒，摆拳一闪就过。
- s06 那一拳分量不够；s06 → s07 少了「直起身、吼一声」的一拍，有点跳。
- s08 几乎是静的；s09 写了慢动作，出来接近常速。
- s11 撞上机器后约 0.3 秒的 T 字，是全片唯一的人偶感（来路是关键帧照搬了白模的姿势）。
- s12 → s13 他腿的朝向和身上的衣服接不上。
- 声音只看了频谱，没有人听过。

## scene.py 里自己补的函数

`ponytail` → 现在 `marks=("hair_long",)` 在带关节人偶上也有（旧脚本两样都画会多一块头发）；`Capsule.LOW.update(…)` 照旧可用，也可以 `place(…, low=)`；`hold`（同一个状态保持到下一镜前一帧）和 `disc`（机器的圆门）是这场戏自己的。

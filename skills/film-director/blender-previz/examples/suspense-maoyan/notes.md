# 《猫眼》：悬疑，一条走廊、视线和暗场

深夜下雨，林夏回到老楼顶层走廊尽头的家。有人隔着猫眼看她一路走近；她以为是邻居 405 门后的人——直到她站到那只猫眼跟前掏出钥匙：那是她自己家的门。门里的男人退到门后的墙角，门开了，门扇正好挡在两人中间。

Wan 3.0，720P，写实。成片 37.6 秒（36.2 秒戏 + 黑场），10 个镜头，30 fps。视频生成 30 次（出片 29 条，1 条被内容审核拦下），出图 21 张（定妆 3、关键帧 18）。成片和全部中间文件没有放进仓库；本目录的 [scene.py](scene.py) 是当时的白模脚本。

## 白模管了什么

这场戏的揭示是视线问题，不是站位问题：猫眼后面的人在她自己家里，观众看得见他、她看不见。

- **三次猫眼视角真的从尽头那扇门看出去。** 机位架在门外侧猫眼的位置（高 1.53 米，14mm），量出来她离猫眼 12.1 米 → 2.7 米 → 0.5 米；三次都看得见她，也看得见 405 的门缝光。405 在侧墙上，从它的猫眼只能看到对面的墙——「公平的线索」成立。
- **结尾门扇挡在两人中间。** 合页放西边、门开 78 度停住、墙角留 1.3 米宽、男人站在 (−0.28, 11.52)：从她的眼睛到男人的头、胸各打一条线，都被门扇（或门外侧的福字）挡住；从镜头到男人的头没有遮挡。这几个数随便改一个，她就看得见他。
- **正着看、反着看是同一条走廊。** 往北看自行车在右、消火栓箱在左；猫眼视角往南看，左右全反过来。左右是渲染出来的，14 张关键帧、10 个镜头里地标没有一处放反。只用文字的对照里，走廊变短、楼梯跑到左边、自行车在错的一侧、福字贴到了邻居门上。
- **正俯拍。** 一扇 5 厘米厚的门两边各一个人、相距不到一米，文字写不出这个角度；白模转关键帧一次成。
- **时间。** 她从 405 走到家门口 1.45 米给 2.5 秒；男人挪到墙角 1.13 米给 2.6 秒。

不归白模管的：她攥紧包带、钥匙第一下没对准、男人退开的那一下，写在文字里。

## 搭了什么

- 走廊 1.7 × 11 米、层高 2.8 米，西墙三扇门、东墙两扇（`wall(doors=[…])`），楼梯口平台在南；尽头北墙正中是她家的门（宽 0.9，合页在西，往屋里开）；门里一间比走廊宽的屋，门东边墙上一个开关，北墙一扇窗。
- 地标：东墙边的自行车（紫色方块）、西墙上的消火栓箱（红）、走廊口的安全出口灯（绿）、楼梯间的窗（浅蓝）、三只灯泡（黄球）、门垫、门上的福字和猫眼（挂在门扇上，跟着门转：`door.attach`）、405 门缝下的一条光（黄色薄片）和两块脚影（黑）。
- 天花板 + 走廊里六盏、屋里三盏弱的无影补光（每盏 12–14 瓦）。不补光时墙、地、顶是一片同样的灰。
- 正俯拍那一镜藏掉天花板、门上方那截墙和门楣（`camera(…, hide=[…])`）；走廊西墙外面用一块黑色实心块堵住，免得模型编出邻居家。机位转 90 度，北在画面右边（`roll=90`）。
- 人偶：林夏蓝色 1.63 米，男人红色 1.78 米（身份色，衣服是黄雨衣和黑衣）。

## 喂法对照

| 喂法 | 条数 | 结果 |
|---|---|---|
| 关键帧当首帧（瘦提示词） | 12 条，9 个镜头 | 6 个镜头第一条就可用，机位、地标、暗的程度都守住；pov1、pov3 要加尾帧，gap 是措辞 |
| 首帧 + 尾帧 | 5 条 + 1 条首尾同图的空镜 | 5 条都可用。空镜那条 5 秒后镜头自己摇到一扇不存在的窗上，只用了开头 1.5 秒和它的雨声 |
| 分镜单元 + 每镜一张关键帧 | 3 | 走廊里的两个单元站位和切点对（差 0.03 秒以内），色调偏冷，门垫串到了别的镜头；暗屋那个单元坏了：眼睛特写的背景成了亮走廊，福字贴到门里面，换了一间亮屋 |
| 分镜单元 + 每镜一张白模静帧 | 2 | 站位和切点对；紫色、黄色方块和黄条上的黑块被照着画进去；整段是亮的 |
| 分镜单元 + 胶囊预演当参考视频 | 1 | 切点和正俯拍的几何对；整段是亮的，男人戴上了白面具，福字在门里面 |
| 单镜 + 预演当参考视频（wide 的跟拍） | 1 | 运镜跟上了；上下有黑边，紫色方块留在真自行车旁边，多出窗和栏杆 |
| 只用文字 + 人物图 | 2 | 一条地方全错（见上）；一条被内容审核拦下 |

暗的程度（平均亮度 0–255，首帧 → 成片）：eye 33.7 → 30.1，top 27.7 → 25.0，in 38.4 → 34.6。

什么时候必须加尾帧，这部片给了三个例子：pov1 空走廊当首帧，文字写「她从最远处的楼梯口走出来」，她从走廊中段的墙边冒出来、太大，加一张她站在楼梯口的尾帧就对了；pov3 首帧是她回头的后脑勺，转回来是另一张脸，尾帧给一张带脸的关键帧（出图时带定妆图）就对上了；in 门开到哪、人停在哪，靠尾帧。

## 改过的地方

| 看到的 | 原因 | 改法 |
|---|---|---|
| 正俯拍看不见门 | 被门楣、墙顶、天花板盖住 | 这一镜藏掉它们 |
| keys、eye 机位太紧，人被切出画 | 窄走廊里机位只能在里面 | 各挪一次机位 |
| pov2 结尾她离镜头只有 0.8 米 | 少打了一个「停住」的关键帧 | 补关键帧 |
| gap 里门被打开了一条缝 | 提示词写「门缝下透出一条光」 | 改成「门一直关着，门板纹丝不动；门板底下透出一条光」 |
| pov2 开头半秒一段很响的带谐波的怪声 | 声音句写了「很近的呼吸声变得急促」 | 去掉这句 |
| in 里门变成两扇（一条暗的窄边旁边又一块亮门板） | 门开 85 度时从这个机位看门扇只剩一条线 | 白模里门改成开 78 度停住，同一面始终看得见；重出尾帧、重拍两条，0.1 秒一帧放大看没有重影 |
| in 里她闭着眼低头，像犯困 | 文字写了「低头长长地呼出一口气，肩膀松下来」，和刚被吓到的情绪对不上 | 尾帧画成神情紧张、动到一半的样子，文字改掉 |
| in 结尾她背对镜头、面朝走廊，看不懂在干什么 | 尾帧画的是她背对镜头够开关 | 白模里终点改成侧面对镜头，中间加一下回头看走廊；尾帧带定妆正面图重画 |
| top 里帆布包挂到了右肩（别的镜头在左肩） | 白模人偶没有包，关键帧文字没写哪一侧 | 每张关键帧写明包在左肩 |
| top 开头男人又双手按在门上（上一镜结尾已经退开） | 写关键帧时为了画面把他写回了门上，白模里他是退开半步站着的 | 照白模重画首尾帧、重拍 |
| 两条 in 结尾开关自己亮了 | 模型加的 | 剪在亮之前，切黑场 |

后期：三个猫眼镜头加桶形畸变和圆形遮罩（ffmpeg 的 `blend=multiply` 要先把两路转成 `gbrp`，在 YUV 上相乘会发绿），声音低通；全片铺一条单独生成的「只有雨声」的空镜当底声（各镜底噪差到 17 dB）。

## 还剩的毛病

- 声音没有人听过；pov2 开头 0.9 秒没有脚步声，pov3 自己没有钥匙声。
- in 里男人笔直站着五秒不动，只有头跟着她转了一点，像一尊立着的像。
- 暗镜头平均亮度只有 30/255 上下，正俯拍里男人是暗地上一团更暗的影子。
- wide 偏冷，往南看的几镜偏暖。
- in 里她的头发比走廊几镜干；门扇画得比白模的 78 度更窄，接近一条线，但只有一扇。

## scene.py 里自己补的函数，现在在 blocking.py 里

`wall_doors` → `wall(doors=[…])`；`fill_light` → `ceiling()` / `fill_light()`；`hide_during` → `camera(…, hide=[…])`；`on_leaf` → `door.attach()`；`sees` → `st.sees()`；`walk_flat`（门洞里会飞上门楣）→ `ground()` 已经不量墙；`eyelines` 是这场戏自己的视线清单，照着它用 `st.sees` 写。

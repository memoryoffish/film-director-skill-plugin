# 《十分之一》：科幻，三百米的场景和尺度

勘探员林一个人穿过荒原，走向一艘横躺的巨船，扳开闸门脚下一扇两米高的小舱门，钻进漆黑的机库。手电照到几根圆木一样粗的东西——是一只手套的手指，和她自己手上那只一模一样，只是大了十倍。她抬起头：一个穿同一款宇航服的巨人靠墙坐着。她是十分之一。

Wan 3.0，720P，写实，没有台词和配乐。成片 39.5 秒，11 个镜头，30 fps；白模预演同样 1185 帧。视频生成 26 条，出图 22 张（定妆 2、关键帧 20）。成片和中间文件没有放进仓库，成片见[画廊](https://memoryoffish.github.io/films/)；本目录的 [scene.py](scene.py) 是当时的白模脚本。每种喂法多数只拍了一条，下面是「这次看到的」。

## 白模管了什么

- **一个场景按真实米数搭。** 荒原、船 300 × 70 × 56 米、闸门 44 × 34 米、橙色圆环直径 18 米、小舱门 1.1 × 2.1 米、检修梯、三个油桶、一辆 4.5 米的车、船肚子里 90 × 70 × 40 米的机库、靠墙坐着的巨人（站直 16 米，是她的 9.5 倍，同一个人偶类放大）、林 1.68 米。11 个机位从 200 米外到手边 1 米都架在这一个场景里。
- **从远到近认得出是同一扇门。** 每个机位里都留着别的机位也看得见的两三样东西（门缝、圆环、梯子、小舱门、油桶、车）。只搭三块板的最粗白模加同一段文字，图一样好看，但没搭的梯子、油桶、车由模型自己找地方放，圆环被画大一半，后面的机位对不上。
- **尺度是量出来的。** 每镜「人占画面多高」从白模里算（s1 6%、s3 尾 6%、s6 4%、s10 12% → 9%），出关键帧后对着量。读得出尺度靠的是人身边那些人的尺度的东西（小舱门、梯子横档、油桶、车）；只有人和一面大墙时读不出墙有多大。
- **反打、俯拍、仰拍。** 机库里往外反打时门扇往哪开、她站在门洞哪一侧（机位一开始被门扇挡住了人，挪到了门的另一侧）；14.6 米的俯拍和 0.5 米的仰拍。
- **能不能走到。** 从小舱门走到巨人手边 65 米要 50 秒，镜头里走不完：俯拍只拍她往里走，下一镜直接到手边。
- **找「背景里不能有某样东西」的机位。** 补的交代镜头不能提前露出巨人：在白模里把 9 个候选机位各出一张静帧，一眼看出哪些方向背景里有手臂、腿，哪个高度被膝盖挡住，最后只剩一个方向、一个高度（见下）。

## 尺度：关键帧把人画大

人占画面高：

| 镜 | 白模 | 关键帧 | 成片 |
|---|---|---|---|
| s1 | 6%（43 像素） | 写百分比 9.5%；拿圆环当尺子写比例 7.8% | 9.6% → 8.1% |
| s2 | 37% | 51% | 和关键帧一样 |
| s3 尾 | 6% | 7.8% | 7.8% |
| s6 | 4%（29 像素） | 4.3% | 4.2% |
| s10 | 12% → 9% | 17% | 约 15% |

人只剩一个光点时对；看得清是个人时被画大 1.25–1.6 倍，身边的小门跟着变大（s3 尾帧里门连门框有她 1.7 倍高，白模里是 1.25 倍）；巨物本身基本照白模。视频照着首帧，不会再改。

## 运镜的喂法对照

**升镜头 s3**（镜头从 1.3 米升到 11.5 米、后拉到 30 米，人从 24% 缩到 6%）：

| 喂法 | 结果 |
|---|---|
| 首帧 + 尾帧 | 最好：连续升起后拉，落在尾帧上，圆环是漆在门上的 |
| 只给首帧 + 文字 | 升了，但画外靠编：圆环成了凸出门面的立体拱，梯子斜靠在门上 |
| 胶囊预演当参考视频 | 路线、节奏、人的位置照预演；新露出来的闸门上半截发白 |
| 带关节人偶预演当参考视频 | 同上，另带上下各 42 像素黑边 |
| 三镜一个单元 + 每镜关键帧 | 切点 3.97 / 7.47（表上 4.0 / 7.5）；第三镜靠文字也升起来，幅度小 |

**跟拍 s2**（镜头跟在她右后方一起走，画面内容几乎不变；人占画面 37%，背影）：

| 喂法 | 结果 |
|---|---|
| 首帧 + 文字（写明背景变多大） | 成片用的：步子自然，闸门慢慢变大（8–11%）；不写时 5 秒变大 28%，白模里只该 7–10% |
| 首帧 + 尾帧 | 失败：当成固定机位，她越走越远，最后两帧跳回尾帧（相邻帧差最后两帧 6.5、7.0，其余不到 1.5） |
| 胶囊预演当参考视频 | 失败：蓝色胶囊被画成一根半透明的柱子，旁边另画了一个更大的林；上下 20 像素黑边 |
| 带关节人偶预演当参考视频 | 位置、大小、速度照预演，没有东西进画；手臂贴着身子不摆，脚被下沿切掉（预演里就这样），上下 29 像素黑边 |

预演当参考视频的镜头开头结尾人都在走，用的是匀速走法（当时自己写的 `stride`，现在 `walk(…, ease=False)`），没有滑步。

## 改过的地方

| 看到的 | 原因 | 改法 |
|---|---|---|
| s1 人被画大 | 关键帧把小人画大 | 拿圆环当尺子写比例 + 像素数重画；没完全解决 |
| 手轮一张是实心黄圆盘、一张是辐条小手轮，视频里中途变形 | 主帧是大远景，手轮只有几个像素，每个机位各画各的 | 从已经画出辐条手轮的那张派生，写明「同一个手轮」 |
| 方块船被画成一面平墙 | 没搭出船的形状 | 没改（还剩的毛病） |
| s4、s5 守规矩但没戏 | 文字只写了一个动作 | 同一张首帧换成一串有起因有结果的动作，各多拍一条 |
| s5 第一条进门后两腿并着站了 1.4 秒 | 动作写少了 | 换写法 |
| s9 只给首帧时巨人的头盔换了样子 | 画外靠编 | 首帧 + 尾帧 |
| s10 结尾平 | 只有构图 | 同一张首帧加一件小事（头盔转过来一点、肩上落灰） |
| s8 原声里有一段长音带八度，是配乐 | 模型加的 | 两个窄陷波去掉 |
| 俯拍直接切到手按在指尖上的大特写，观众没见过她走到了什么东西跟前 | 缺一个交代的镜头 | 补 s6b（见下）；s6 剪到 2.5 秒，s1、s3 各短半秒 |
| 成片比预演短 7 帧 | 按秒裁、源片尾巴不够时少一两帧 | 按整帧裁（现在的 `cut.piece`） |
| 机库里加的灯整片发白 | 有顶的机库不黑（环境光照得进来），一盏 26 万瓦太亮 | 降到每盏 2500 瓦；其实不加灯也读得出 |

**补的交代镜头 s6b**：巨人的左手平放在甲板上，手指朝南；她从南边走来，跪在指尖的东南。朝北、朝西看的机位，背景里都是巨人的小臂、躯干或腿；从东往西看，她在画左、手指在右，和 s7 正好反过来。剩下从西往东看：背景是空机库，但西边是巨人的左腿，机位只能架在两腿之间、左膝上方（离地 2.05 米，28mm，俯 22°），再低被膝盖挡，视线再往北偏 2° 小臂就进画。手掌和手臂是被取景裁在画外的，白模里什么都没藏。她走进来时占画面高 56%，跪下以后 33%；手指粗 19 厘米，和她的大腿差不多。

提示词里只叫它「四根并排的粗管子」，写明不画手的形状。只给首帧、换一种演法的那条，镜头自己往左带，管子越露越长，像四根长手指；首尾帧把机位和画外都钉住了。定妆图里她胯上挂着手电，白模里手上拿着手电，第一张首帧画了两支，写明「只有手里这一支」后重出。这一镜在白模时间线上放在最后（40–44 秒），镜头表里排在 s6 和 s7 之间，前面的关键帧不用挪。

## 还剩的毛病

- 人还是偏大（s1 8.1% 对 6%，s10 约 15% 对 12% → 9%），巨物因此显得小一点；s10 里巨人坐着是她的 4.7 倍高，白模里是 6 倍。
- s10 镜头几乎没后拉；巨人转头幅度小。
- 巨人的手 s7 里四指并拢平放，s9、s10 里微微张开扣着地；小舱门大小在几镜之间不稳。
- s6b 那四个圆头细看能猜到是指尖；s6b 结尾她离圆头大半步，s7 里膝盖已经贴着指尖。
- 船不像船；没有配乐；声音没有人听过。

## scene.py 里自己补的函数

`stride`（匀速走）→ `walk(…, ease=False)`；`plan_big`（按范围出几张、跳过高处的东西）→ `st.plan(…, region=…)`；`scale_note`（人占画面多高）→ `describe` 里有「占画面高」；`lamp` → `st.fill_light`；巨人坐到地上要的座高缩放现在在 `place` 里。`hcyl`（横放的圆柱）、`dune`（沙堆）、`suit_up`（头盔背包手电）、`wheel`（门扇上的手轮，现在可用 `door.attach`）是这场戏自己的。
